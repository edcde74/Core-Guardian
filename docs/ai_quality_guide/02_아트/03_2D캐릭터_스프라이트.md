# 아트 / 2D 캐릭터·스프라이트

> 범위: 원화를 게임용 스프라이트(정지 이미지, 방향별 이미지)로 만드는 작업. 프레임 애니메이션은 [07_2D애니메이션](07_2D애니메이션.md), 도트는 [04_픽셀아트](04_픽셀아트.md).
> 함께 볼 파일: [02_2D원화_컨셉](02_2D원화_컨셉.md), [10_셰이더_테크아트](10_셰이더_테크아트.md)

## 1. 이 파트에서 AI 티가 나는 이유
원화는 크게 보는 그림이고 스프라이트는 작게 보는 그림이다. AI 원화를 그대로 줄이면 디테일이 뭉개지고, 외곽선 두께가 들쭉날쭉하고, 캐릭터마다 크기 기준이 다르다.
방향별 이미지를 따로 생성하면 같은 캐릭터인데 색과 비율이 달라진다.

## 2. AI 티 패턴
| 패턴 | 왜 티가 나나 | 대신 이렇게 | 출처 |
|---|---|---|---|
| 외곽선이 어딘 없고 어딘 두꺼움 | 생성 이미지를 축소만 함 | 외곽선 두께를 숫자로 정하고 후처리로 통일 | `[영상]` |
| 방향마다 색·비율이 다름 | 방향별로 따로 생성 | 턴어라운드 원화를 기준으로 같이 생성, 색은 팔레트로 고정 | `[실무]` |
| 캐릭터마다 크기 기준이 다름 | PPU·캔버스 규칙 없음 | 캔버스, PPU, 발 위치 규칙 고정 | `[실무]` |
| 반투명 가장자리와 흰 테두리 | 배경 제거가 깔끔하지 않음 | 알파 임계값 처리, 가장자리 1px 정리 | `[실무]` |
| 그림자가 이미지에 구워져 있음 | 생성 모델이 바닥 그림자를 같이 그림 | 그림자는 별도 오브젝트로 | `[실무]` |
| 너무 매끈한 렌더 | 사람 손맛 없음 | 디테일 줄이기, 외곽선 흔들림 | `[영상]` |

## 3. 작업 전에 정할 것 (프로젝트 설정값)
- PPU(Pixels Per Unit): 예) 100 또는 32/16(도트) `[실무]`
- 캐릭터 기준 높이: 예) 일반 캐릭터 128px, 보스 256px `[실무]`
- 캔버스 크기와 여백: 예) 192×192, 외곽 여백 최소 8px `[실무]`
- 피벗: 발 중앙 하단 (0.5, 0) 또는 몸 중심 (0.5, 0.5). 게임 전체에서 하나로 `[실무]`
- 방향 수: 1(측면 반전), 4방향, 8방향 `[실무]`
- 외곽선: 두께 px, 색, 안쪽/바깥쪽
- 명도 대비: 배경과 캐릭터의 평균 명도 차 최소 25% 이상 `[실무]`
- 파일 이름 규칙: `chr_{이름}_{방향}_{상태}.png`

## 4. 작업 규칙
1. 확정 원화와 턴어라운드를 기준으로 쓴다. 원화 없이 스프라이트를 바로 생성하지 않는다. `[실무]`
2. 표시 크기로 줄인 뒤 다시 다듬는다. 줄였을 때 사라지는 디테일은 지우고, 중요한 형태는 키운다. `[실무]`
3. 외곽선은 후처리로 두께를 통일한다. 셰이더로 넣는다면 원본에는 외곽선을 넣지 않는다. `[영상]`
4. 색은 팔레트에 맞게 양자화한다. 팔레트 밖 중간색을 없앤다. `[영상]`
5. 배경 제거 후 가장자리를 확인한다. 알파 0/255 외의 값이 외곽에 남았는지 스크립트로 센다. `[실무]`
6. 모든 캐릭터를 같은 캔버스에 나란히 놓아 크기와 발 위치를 비교한다. `[실무]`
7. 실제 게임 배경 위에 올려 대비와 가독성을 본다. `[영상]`
8. 방향별 이미지는 같은 기준선 위에 겹쳐 비율 차이를 본다. `[실무]`

## 5. 금지
| 금지 | 이유 | 예외 |
|---|---|---|
| 원화를 축소만 해서 사용 | 디테일 뭉개짐, 외곽선 불균일 | 고해상도 일러스트 모드 |
| 스프라이트마다 다른 PPU·피벗 | 배치·충돌이 어긋남 | 없음 |
| 이미지에 그림자·글로우 굽기 | 게임 조명·연출과 충돌 | 의도된 정적 연출 |
| 방향별로 독립 생성 | 같은 캐릭터로 안 보임 | 없음 |

## 6. 요청서 예시
```
[목표] 플레이어 캐릭터 4방향 정지 스프라이트
[맥락] 탑다운. 화면 1080p에서 높이 96px로 보임
[레퍼런스] concept/player_turnaround.png, palette_v1.gpl
[숫자 스펙] 캔버스 128×128, 캐릭터 높이 96px, 피벗 (0.5, 0) 발 중앙,
           PPU 100, 외곽선 2px #2B1D14 바깥쪽, 팔레트 외 색 0개
[금지] 바닥 그림자, 글로우, 반투명 가장자리
[검증] 4방향을 같은 기준선에 겹친 이미지, 실제 배경 위 합성 스크린샷,
       외곽 반투명 픽셀 개수 리포트
[산출물] chr_player_{down,up,left,right}_idle.png
```
```
지금 캐릭터 스프라이트 12종을 같은 캔버스에 나란히 놓은 비교 시트를 만들어줘.
각 캐릭터 아래에 높이(px), 피벗 좌표, 외곽선 두께, 팔레트 외 색 수를 적어줘.
규칙(높이 96px, 피벗 (0.5, 0), 외곽선 2px)에서 벗어난 항목은 빨간 박스로 표시.
```

## 7. 검증 체크리스트
- [ ] 캔버스·PPU·피벗이 규칙과 같다
- [ ] 팔레트 외 색이 0개다
- [ ] 외곽선 두께가 전 방향 동일하다
- [ ] 가장자리 반투명 픽셀이 규칙 이하다
- [ ] 다른 캐릭터와 나란히 봤을 때 크기 기준이 맞다
- [ ] 실제 배경 위에서 명도 대비가 충분하다
- [ ] 사람이 게임 화면에서 확인했다
- [ ] 파일 이름이 규칙과 같다
