> 범위: HUD, 메뉴, 버튼, 패널, 아이콘의 비주얼 디자인. 엔진에서 조립·레이아웃 구현은 [개발 02_UI구현](../03_개발/02_UI구현.md), 해상도 검사는 [QA 02_시각_해상도](../06_QA/02_시각_해상도.md).
> 함께 볼 파일: [01_아트디렉션_스타일가이드](01_아트디렉션_스타일가이드.md), [기획 07_UX_온보딩](../01_기획/07_UX_온보딩.md), [텍스트 01_UI문구_툴팁](../05_텍스트/01_UI문구_툴팁.md)

## 1. 이 파트에서 AI 티가 나는 이유
AI가 가장 많이 학습한 UI는 웹과 앱이다. 게임 UI를 부탁해도 카드 그리드, 사이드바, 설명 패널 같은 웹 구조가 나온다. `[영상]`
게임 UI는 행동을 유발해야 해서 게임 스타일을 더 강하게 반영해야 한다. `[영상]`
"미래적", "예쁘게"라고 하면 보라색 네온, 그라데이션, 발광 띠, 이모지가 나온다. 증강 선택 카드 같은 곳에서 특히 티가 난다. `[영상]`

## 2. AI 티 패턴
| 패턴 | 왜 티가 나나 | 대신 이렇게 | 출처 |
|---|---|---|---|
| 보라 네온, 그라데이션, 발광 띠 | "미래적/예쁘게"의 기본값 | 팔레트 고정, 글로우 금지 | `[영상]` |
| 카드 테두리 발광, 이모지 아이콘 | 증강·보상 UI의 흔한 AI 패턴 | 세계관 재질(금속, 나무, 종이)로 프레임 디자인 | `[영상]` |
| 카드 그리드, 사이드바, 설명 패널 | 웹·앱 레이아웃 학습 | 목업으로 게임 레이아웃을 먼저 정함 | `[영상]` |
| 버튼마다 크기·모서리·여백이 다름 | 화면별로 따로 생성 | 실제 스크린샷 위에 구조도를 그려 지시 | `[영상]` |
| 둥근 모서리 + 그림자 카드 | 모바일 앱 기본값 | 모서리 반경, 그림자 사용 여부를 규칙으로 | `[실무]` |
| 아이콘 선 두께·시점이 제각각 | 아이콘별 독립 생성 | 아이콘 그리드와 선 두께 고정 | `[실무]` |
| 화면 전체 UI를 이미지 한 장으로 | 수정·해상도·인터랙션 불가 | 9-slice 프레임 + 개별 아이콘 + 폰트 | `[영상]` |
| 이미지 안에 글자를 박음 | 현지화·수정 불가 | 글자는 폰트로 얹음 | `[영상]` |

## 3. 작업 전에 정할 것 (프로젝트 설정값)
- 기준 해상도와 지원 비율: 1920×1080 기준, 16:9 / 16:10 / 21:9 / 4:3 `[영상]`
- 안전 영역: 화면 가장자리 여백 예) 상하좌우 3~5% `[실무]`
- 최소 터치·클릭 크기: PC 32px 이상, 모바일 약 44~48dp 이상 `[실무]`
- 버튼 규격: 높이, 모서리 반경(0/4/8px), 테두리 두께, 상태별 색(기본/호버/누름/비활성) `[실무]`
- 아이콘 그리드: 예) 64×64 캔버스, 안쪽 여백 4px, 선 두께 3px, 시점 정면 `[실무]`
- 아이콘 실루엣 규칙: 32px로 줄여도 구분되는 형태 `[실무]`
- 명도 대비: 텍스트와 배경 대비 4.5:1 이상(본문), 3:1 이상(큰 글자) `[실무]`
- 색의 의미: 빨강=위험, 초록=회복 등 의미 고정, 색만으로 정보 전달 금지 `[실무]`
- 프레임 재질: 세계관에 맞는 재질 1~2개

## 4. 작업 규칙
1. 레이아웃 목업부터 만든다. 버튼 배치, 정보 우선순위를 그림으로 정한다. 이미지 생성이나 위젯 목업을 써도 된다. `[영상]`
2. 실제 게임 스크린샷 위에 구조도를 그려서 넘긴다. 버튼 일관성이 크게 올라간다. `[영상]`
3. 컨셉에 꼭 필요하지 않으면 네온·그라데이션·이모지를 금지하고 메모리에 넣는다. `[영상]`
4. 프레임은 9-slice로 만든다. 모서리와 가장자리를 분리해 크기가 바뀌어도 깨지지 않게 한다. `[실무]`
5. 아이콘은 한 세트를 같은 그리드·선 두께·광원으로 같이 만든다. `[실무]`
6. 글자는 이미지에 넣지 않는다. 텍스트 없이 만들고 폰트로 얹는다. `[영상]`
7. 사람 손맛: 프레임 선 흔들림, 약한 질감, 아이콘 비대칭을 의도적으로 넣는다. `[영상]`
8. 실제 게임 화면에 올려 여러 해상도에서 스크린샷을 찍고 비교한다. `[영상]`

## 5. 금지
| 금지 | 이유 | 예외 |
|---|---|---|
| 의미 없는 네온·그라데이션·발광 띠 | AI 티 `[영상]` | 네온 컨셉 게임 |
| 장식용 이모지 | 세계관을 깸 `[영상]` | 의도된 캐주얼 SNS 톤 |
| 웹 레이아웃 그대로 | AI가 웹을 가장 많이 학습 `[영상]` | 장르상 실제로 필요할 때 |
| 이미지에 글자 굽기 | 현지화 불가 `[영상]` | 로고 |
| 색만으로 상태 구분 | 색각 이상 사용자 | 형태·아이콘 병행 시 |

## 7. 검증 체크리스트
- [ ] 레이아웃이 목업·구조도와 같다
- [ ] 버튼 크기·모서리·여백이 규격과 같다
- [ ] 아이콘이 같은 그리드·선 두께다, 32px에서 구분된다
- [ ] 이미지 안에 글자가 없다
- [ ] 텍스트 대비가 기준 이상이다
- [ ] 네온·이모지·그라데이션이 없다(예외 확인)
- [ ] 여러 비율 스크린샷을 사람이 확인했다
