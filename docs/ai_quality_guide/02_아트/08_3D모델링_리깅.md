# 아트 / 3D 모델링·리깅

> 범위: AI 3D 생성 모델, 리깅, 웨이트, 3D 애니메이션 적용. 3D를 2D로 렌더해 쓰는 경우도 포함. 셰이더는 [10_셰이더_테크아트](10_셰이더_테크아트.md).
> 함께 볼 파일: [07_2D애니메이션](07_2D애니메이션.md), [개발 04_최적화](../03_개발/04_최적화.md)

## 1. 이 파트에서 AI 티가 나는 이유
AI 3D 생성은 형태는 그럴듯하지만 토폴로지가 엉망이고 텍스처에 조명이 구워져 있다.
리깅에서는 시작과 끝 루프가 맞지 않거나 메시가 뒤틀린다. 메시 뒤틀림은 뾰족한 해결책이 없고 결국 손으로 고치는 게 가장 낫다. `[영상]`

## 2. AI 티 패턴
| 패턴 | 왜 티가 나나 | 대신 이렇게 | 출처 |
|---|---|---|---|
| 관절에서 메시가 뒤틀림 | 자동 웨이트 품질 한계 | 수작업 웨이트 수정, 부위 분리 제작 | `[영상]` |
| 루프 애니메이션 시작·끝 불일치 | 순환 고려 없음 | 첫·마지막 포즈 일치 검사 | `[영상]` |
| A포즈 생성 시 다리 쪽에 손 자국 같은 얼룩 무늬 | 손이 몸에 가까워 텍스처가 섞임 | T포즈로 생성 | `[영상]` |
| 텍스처에 조명·그림자가 구워짐 | 사진 기반 학습 | 알베도만 생성, 조명은 엔진에서 | `[실무]` |
| 폴리곤이 무작위 삼각형 덩어리 | 생성 메시 특성 | 리토폴로지 또는 데시메이트 + 정리 | `[실무]` |
| 캐릭터마다 스케일·원점 다름 | 생성마다 단위가 다름 | 단위·원점·전방 축 통일 | `[실무]` |

## 3. 작업 전에 정할 것 (프로젝트 설정값)
- 생성 포즈: T포즈 권장 `[영상]`
- 체형 통일: 같은 등급 캐릭터는 같은 체형·본 구조·본 가중치 기준 `[영상]`
- 동작 스펙: 예) 점프 0.11초, 착지 시 무릎 90도처럼 숫자로 `[영상]`
- 폴리곤 예산: 예) 일반 캐릭터 3~8k 삼각형, 보스 15k 이하(모바일은 더 낮게) `[실무]`
- 텍스처: 해상도 512~2048, 텍셀 밀도 통일 `[실무]`
- 단위·축: 1 unit = 1m, Y-up, 정면 +Z(엔진에 맞춤), 원점 발 중앙 `[실무]`
- 본 이름 규칙과 휴머노이드 매핑 `[실무]`
- 본 수 상한, 정점당 영향 본 최대 4개 `[실무]`

## 4. 작업 규칙
1. T포즈로 생성한다. A포즈는 팔·다리 사이 텍스처 오염이 생기기 쉽다. `[영상]`
2. 몸을 부위별로 나눠 만든다(몸통, 머리, 장비). 뒤틀림 범위가 줄고 교체가 쉽다. `[영상]`
3. 체형과 본 가중치를 통일해 같은 애니메이션을 여러 캐릭터에 그대로 적용한다. `[영상]`
4. 동작 길이·각도를 숫자로 고정한다. 하나가 잘 되면 재사용할 수 있다. `[영상]`
5. 생성 메시는 정리한다: 비다양체·겹친 정점 제거, 법선 통일, 리토폴로지 또는 감축. `[실무]`
6. 웨이트는 어깨·팔꿈치·무릎·골반을 극단 포즈로 돌려 확인하고 손으로 고친다. `[영상]`
7. 루프 애니메이션은 첫·마지막 프레임 포즈 차이를 수치로 확인한다. `[영상]`
8. 엔진에 넣어 실제 카메라 거리·조명에서 본다. `[실무]`

## 5. 금지
| 금지 | 이유 | 예외 |
|---|---|---|
| A포즈 생성 후 그대로 리깅 | 텍스처 오염 `[영상]` | 정리 후 사용 |
| 자동 웨이트를 검사 없이 사용 | 관절 뒤틀림 `[영상]` | 없음 |
| 조명이 구워진 텍스처 | 엔진 조명과 충돌 | 의도된 핸드페인트 스타일 |
| 캐릭터마다 다른 체형·본 구조 | 애니메이션 재사용 불가 | 특수 체형(명시) |
| 폴리곤 예산 초과 | 성능 | 컷신 전용 |

## 6. 요청서 예시
```
[목표] 인간형 적 3종 3D 모델 + 공통 리그
[맥락] 쿼터뷰 액션, 카메라 거리 10m, 화면 높이 약 120px
[숫자 스펙] T포즈, 삼각형 6k 이하, 텍스처 1024 알베도만, 1 unit = 1m, Y-up, 원점 발 중앙,
           공통 휴머노이드 리그, 정점당 본 4개 이하
[작업] 몸통/머리/무기 부위 분리. 공통 걷기(1.0초 루프), 공격(0.6초) 3종 모두 적용
[금지] 구워진 조명, 무작위 스케일, 자동 웨이트 그대로
[검증] 극단 포즈 4종 스크린샷(어깨·팔꿈치·무릎·골반), 루프 첫·끝 포즈 차이 수치,
       엔진 실제 카메라 스크린샷
```
```
공통 리그를 쓰는 캐릭터 3종에 같은 공격 애니메이션을 적용하고,
각각 타격 프레임의 손 위치 차이(cm)와 관절 뒤틀림 여부를 표로 만들어줘.
뒤틀린 부위는 스크린샷에 표시하고, 수작업 웨이트 수정이 필요한 정점 그룹을 적어줘.
```

## 7. 검증 체크리스트
- [ ] T포즈, 단위·축·원점이 규칙과 같다
- [ ] 폴리곤·텍스처 예산 안이다
- [ ] 비다양체·겹친 정점이 없다
- [ ] 극단 포즈에서 메시 뒤틀림이 없다
- [ ] 루프 첫·끝 포즈가 일치한다
- [ ] 같은 체형 캐릭터에 애니메이션이 그대로 적용된다
- [ ] 엔진 실제 카메라에서 사람이 확인했다
