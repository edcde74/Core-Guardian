# 아트 / 2D 원화·컨셉

> 범위: 캐릭터·몬스터·배경·소품의 컨셉 원화와 일러스트. 게임에 바로 들어가는 스프라이트 가공은 다루지 않는다.
> 함께 볼 파일: [01_아트디렉션_스타일가이드](01_아트디렉션_스타일가이드.md), [03_2D캐릭터_스프라이트](03_2D캐릭터_스프라이트.md)

## 1. 이 파트에서 AI 티가 나는 이유
이미지 생성 모델은 한 장으로 볼 때 멋진 그림을 잘 낸다. 문제는 디테일 과잉, 여러 번 고칠 때 쌓이는 이상한 패턴, 장마다 달라지는 화풍이다. `[영상]`
원화는 이후 모든 에셋의 기준이 되므로 여기서 생긴 AI 티가 게임 전체로 퍼진다.

## 2. AI 티 패턴
| 패턴 | 왜 티가 나나 | 대신 이렇게 | 출처 |
|---|---|---|---|
| 머리카락·장식에 의미 없는 복잡한 디테일 | 여러 턴 수정하며 불쾌한 골짜기 패턴이 쌓임 | 업스케일러(예: 애니 업스케일러)를 한 번 통과시켜 정리 | `[영상]` |
| 수정할수록 그림이 탁해짐 | 수정 모델로 반복 편집 | 수정 턴 수 상한을 두고, 넘으면 새로 생성 | `[영상]` |
| 손가락·장비 구조가 틀림 | 모델이 구조를 이해하지 못함 | 구조가 중요한 부위는 사람이 수정하거나 부위별 생성 | `[실무]` |
| 배경 흐림과 얕은 피사계 심도 | 사진식 기본값, 게임 화면과 안 맞음 | 게임 카메라 시점과 초점 규칙을 명시 | `[실무]` |
| 모든 캐릭터가 같은 얼굴형·비율 | 모델 기본 얼굴 | 머리 대 몸 비율, 얼굴형을 캐릭터별로 숫자로 지정 | `[실무]` |
| 의미 없는 문양과 글자 비슷한 무늬 | 생성 모델의 잡음 | 문양은 세계관 규칙으로 직접 정함 | `[실무]` |
| 과하게 매끈한 렌더 | 사람 손맛 없음 | 디테일을 줄이고 붓 자국·노이즈를 일부러 넣음 | `[영상]` |

## 3. 작업 전에 정할 것 (프로젝트 설정값)
- 메인 레퍼런스와 대상별 중간 레퍼런스(캐릭터, 몬스터, 기계, 자연물)
- 시점: 정면, 3/4, 탑다운, 쿼터뷰 중 게임 카메라와 같은 것
- 머리 대 몸 비율: 예) 1:2.5(SD), 1:5, 1:7
- 실루엣 규칙: 캐릭터마다 구분되는 형태 요소 1개 이상(모자, 무기, 꼬리 등) `[실무]`
- 색 개수 상한: 캐릭터 1명당 주색 3개 + 보조색 2개 `[실무]`
- 디테일 밀도: 게임 내 표시 크기 기준으로 결정(64px로 줄였을 때 사라지는 디테일은 넣지 않음) `[실무]`
- 수정 턴 상한: 예) 3회
- 산출 해상도: 예) 2048px 이상, 투명 배경 PNG

## 4. 작업 규칙
1. 실루엣부터 정한다. 검은색으로 채워도 누구인지 알아봐야 한다. 썸네일 64px에서 테스트한다. `[실무]`
2. 레퍼런스 이미지를 모든 생성에 같이 넣는다. 긴 프롬프트보다 레퍼런스 한 장이 낫다. `[영상]`
3. 대상이 기존 레퍼런스와 크게 다르면 중간 레퍼런스를 먼저 만든다. 예) 배경 레퍼런스로 자동차를 그리면 깨진다. `[영상]`
4. 색이 레퍼런스와 크게 다른 대상(파란 톤 레퍼런스로 갈색·빨강 대상)도 중간 레퍼런스를 만든다. `[영상]`
5. 여러 턴 수정한 이미지는 업스케일러를 통과시켜 이상 패턴을 정리한다. `[영상]`
6. 디테일을 일부러 줄이고, 비대칭과 붓 자국을 남긴다. `[영상]`
7. 후보를 3~4개 만들고 실제 게임 화면 크기로 줄여 같이 비교한다. `[영상]` (A/B 비교)
8. 확정 원화는 정면·측면·후면 턴어라운드와 색 지정표를 같이 만든다. 이후 스프라이트 작업의 기준이다. `[실무]`
9. 확정과 버린 안을 결정 기록에 남긴다. `[실무]`

## 5. 금지
| 금지 | 이유 | 예외 |
|---|---|---|
| 같은 이미지를 수정 모델로 끝없이 고치기 | 이상 패턴이 쌓인다 `[영상]` | 업스케일러로 정리 후 확인 |
| 표시 크기에서 안 보이는 디테일 추가 | 줄였을 때 지저분해짐 | 일러스트·키아트 전용 |
| 실제 작가·작품 이름으로 화풍 지정 | 저작권·윤리 문제, 개성 없음 | 없음 |
| 출처 없는 이미지를 레퍼런스로 사용 | 권리 문제 | 직접 만든 레퍼런스 |
| 모든 원화를 완전 대칭으로 | AI 티 `[영상]` | 의도된 문장(紋章)형 디자인 |

## 6. 요청서 예시
```
[목표] 적 몬스터 컨셉 원화 3안
[맥락] 탑다운 디펜스. 화면에서 48~64px로 보임. 느리고 단단한 돌격형
[레퍼런스] refs/monster_mid.png (생물 중간 레퍼런스), style_board_v1.png
[숫자 스펙] 머리 대 몸 1:2, 주색 3 + 보조색 2, 외곽선 2px, 셰이딩 2단, 광원 좌상단
[금지] 글로우 눈, 네온 무늬, 복잡한 머리카락 디테일, 완전 대칭
[검증] 64px 실루엣(검정 채움) 버전 같이 출력. 기존 적 2종과 나란히 놓은 비교 이미지
[산출물] monster_tank_A/B/C.png
```
```
이 원화를 3번 수정했더니 머리카락과 장식이 지저분해졌어.
1) 애니 업스케일러로 한 번 정리한 버전
2) 원본 레퍼런스로 처음부터 다시 생성한 버전
두 개를 만들고, 64px로 줄인 비교 이미지와 함께 보여줘.
디테일은 줄이고 붓 자국은 남기는 방향으로.
```

## 7. 검증 체크리스트
- [ ] 64px 실루엣에서 다른 캐릭터와 구분된다
- [ ] 색 수가 상한 이하다
- [ ] 수정 턴이 상한을 넘었다면 업스케일러로 정리했다
- [ ] 손·장비·관절 구조가 맞다
- [ ] 의미 없는 문양·가짜 글자가 없다
- [ ] 게임 화면 크기로 줄여 기존 에셋과 같이 봤다
- [ ] 사람이 후보 중 하나를 골랐다
- [ ] 턴어라운드와 색 지정표가 있다
