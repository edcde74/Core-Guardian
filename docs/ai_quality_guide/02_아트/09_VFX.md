# 아트 / VFX(이펙트)

> 범위: 타격, 투사체, 스킬, 폭발, 버프·디버프, 환경 파티클. 이펙트용 셰이더 작성은 [10_셰이더_테크아트](10_셰이더_테크아트.md), 성능 예산은 [개발 04_최적화](../03_개발/04_최적화.md).
> 함께 볼 파일: [기획 03_전투](../01_기획/03_전투.md), [사운드 02_SFX](../04_사운드/02_SFX.md)

## 1. 이 파트에서 AI 티가 나는 이유
AI에게 이펙트를 부탁하면 "멋진" 기본값이 나온다. 강한 글로우, 보라·청록 네온, 그라데이션 궤적, 과한 파티클이다.
이펙트가 화풍 규칙(외곽선, 셰이딩 단계, 팔레트)을 따르지 않아 캐릭터·배경과 따로 논다.
이 패턴 대부분은 [실무] 기준이며, 네온·글로우 금지와 화면 위 검증은 영상의 공통 원칙을 적용한 것이다.

## 2. AI 티 패턴
| 패턴 | 왜 티가 나나 | 대신 이렇게 | 출처 |
|---|---|---|---|
| 모든 이펙트에 강한 글로우·블룸 | "멋지게"의 기본값 | 글로우 금지 또는 역할별 상한 | `[영상]` (네온·글로우 금지 원칙) |
| 보라·청록 네온 색 | AI 기본 팔레트 | 게임 팔레트 안의 색만 | `[영상]` |
| 화풍과 다른 사실적 이펙트 | 화풍 규칙 미적용 | 외곽선·셰이딩 단계를 이펙트에도 적용 | `[실무]` |
| 이펙트가 캐릭터·적을 가림 | 크기·밀도 규칙 없음 | 화면 점유율 상한 | `[실무]` |
| 효과 종류가 모양으로 구분 안 됨 | 색만 다르게 함 | 효과별 고유 형태 언어(원, 가시, 물결 등) | `[실무]` |
| 파티클 수 과다 | 성능 고려 없음 | 동시 개수·오버드로 예산 | `[실무]` |
| 너무 매끈한 디지털 궤적 | 사람 손맛 없음 | 손그림 느낌 프레임, 끊긴 궤적 | `[영상]` (사람 손맛 원칙) |

## 3. 작업 전에 정할 것 (프로젝트 설정값)
- 이펙트 역할 분류: 타격 / 투사체 / 범위 / 상태이상 / 환경, 역할별 우선순위 `[실무]`
- 효과별 색과 형태: 예) 화상=주황+위로 솟는 불꽃 형태, 둔화=하늘색+아래로 처지는 물결 `[실무]`
- 수명: 타격 0.1~0.3초, 범위 표시 0.5~1.0초 등 `[실무]`
- 크기와 화면 점유율: 타격 이펙트는 대상 크기의 1~1.5배 이내 `[실무]`
- 동시 최대 개수와 파티클 상한: 예) 화면 내 파티클 500개 이하 `[실무]`
- 오버드로 상한: 반투명 겹침 레이어 3~4장 이하 `[실무]`
- 글로우·블룸 사용 여부와 강도 상한 `[영상]`
- 플립북 프레임 수: 6~16, 시트 해상도 `[실무]`

## 4. 작업 규칙
1. 이펙트도 스타일가이드를 따른다. 팔레트, 외곽선, 셰이딩 단계를 똑같이 적용한다. `[실무]`
2. 컨셉상 필요하지 않으면 네온·글로우를 금지하고 규칙 파일에 넣는다. `[영상]`
3. 효과마다 형태 언어를 정한다. 색을 빼도 어떤 효과인지 알아봐야 한다. `[실무]`
4. 동작 단계를 나눈다: 시작(예비) → 정점 → 소멸. 정점이 가장 짧고 강하다. `[실무]`
5. 실제 전투 화면에서 최대 물량으로 재생해 가림·혼잡을 본다. 단독 재생만으로 확정하지 않는다. `[영상]` (화면 위 검증)
6. 사운드와 타이밍을 맞춘다. 정점 프레임과 타격음 시작을 일치시킨다. `[실무]`
7. 손맛: 플립북 프레임을 일부러 적게(예: 8프레임) 하거나 손그림 텍스처를 쓴다. `[영상]` (사람 손맛 원칙)
8. 후보는 같은 장면에서 A/B 비교 영상으로 본다. `[영상]`

## 5. 금지
| 금지 | 이유 | 예외 |
|---|---|---|
| 의미 없는 글로우·네온 | AI 티 `[영상]` | 네온 컨셉 게임 |
| 대상을 완전히 가리는 이펙트 | 플레이 정보 손실 | 연출 컷신 |
| 색만으로 효과 구분 | 색각 이상, 혼잡 시 구분 불가 | 없음 |
| 파티클·오버드로 예산 초과 | 프레임 하락 | 일회성 연출(측정 후) |
| 단독 재생으로만 확정 | 실전 혼잡 문제를 못 봄 | 없음 |

## 6. 요청서 예시
```
[목표] 화상 상태이상 이펙트
[맥락] 2D 디펜스, 적 크기 64px, 동시에 적 30마리까지 화상 가능
[레퍼런스] style_board_v1.png, vfx/hit_existing.gif
[숫자 스펙] 플립북 8프레임 12fps 루프, 크기 적 높이의 60%, 팔레트 주황 2색 + 진갈 외곽선 1px,
           글로우 없음, 적 1마리당 파티클 6개 이하
[형태] 위로 솟는 짧은 불꽃 3가닥, 회색조에서도 '불꽃'으로 보여야 함
[금지] 블룸, 네온 주황, 그라데이션 궤적
[검증] 적 30마리 동시 화상 스크린샷, 회색조 버전, 기존 둔화 이펙트와 나란히 비교
```
```
현재 이펙트 전부를 회색조로 바꾼 전투 스크린샷을 만들어줘.
효과 종류별로 형태만으로 구분되는지 표시하고, 서로 헷갈리는 쌍을 적어줘.
같은 장면의 파티클 수와 오버드로 겹침 수도 같이 줘.
```

## 7. 검증 체크리스트
- [ ] 팔레트·외곽선 규칙을 따른다
- [ ] 회색조에서 효과 종류가 구분된다
- [ ] 수명·크기가 스펙 안이다
- [ ] 최대 물량에서 대상이 가려지지 않는다
- [ ] 파티클·오버드로 예산 안이다
- [ ] 타격음과 정점 타이밍이 맞다
- [ ] 실제 전투 영상을 사람이 봤다
