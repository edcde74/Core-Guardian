# 아트 / 픽셀아트(도트)

> 범위: 도트 스타일 스프라이트·타일·아이콘의 생성과 후처리. 일반 2D 스프라이트 규칙은 [03_2D캐릭터_스프라이트](03_2D캐릭터_스프라이트.md).
> 함께 볼 파일: [05_2D배경_타일](05_2D배경_타일.md), [07_2D애니메이션](07_2D애니메이션.md)

## 1. 이 파트에서 AI 티가 나는 이유
픽셀아트의 묘미는 칼같이 찍힌 픽셀이다. AI가 만든 도트는 픽셀이 뭉개져(보간되어) 경계와 외곽선이 애매하다. `[영상]`
색과 색 사이에 중간색이 끼어 "진짜 도트" 느낌이 안 난다. 예) 수박의 빨강과 흰색 사이 분홍, 초록과 흰색 사이 연두. `[영상]`
그래서 픽셀아트는 코드로 하는 후처리가 필수다. `[영상]`

## 2. AI 티 패턴
| 패턴 | 왜 티가 나나 | 대신 이렇게 | 출처 |
|---|---|---|---|
| 픽셀이 뭉개지고 경계가 흐림 | 생성 모델은 연속 이미지로 그림 | 그리드에 맞춰 다운샘플 + 양자화 | `[영상]` |
| 색 경계에 중간색이 낌 | 안티에일리어싱 | 팔레트를 정하고 픽셀 양자화로 중간색 제거 | `[영상]` |
| 외곽선이 어딘 없고 두껍고 얇음 | 외곽선 규칙 없음 | 외곽선 1px로 통일 | `[영상]` |
| 픽셀 크기가 섞임(믹셀) | 해상도가 다른 요소를 합침 | 모든 에셋 같은 픽셀 단위 | `[실무]` |
| 의미 없는 디더링 노이즈 | 그라데이션을 억지로 도트화 | 디더링은 규칙(패턴, 사용 위치)으로만 | `[실무]` |
| 회전·확대된 도트 | 엔진에서 비정수 배율 | 정수 배율, 픽셀 퍼펙트 카메라 | `[실무]` |
| 외곽선 계단이 들쭉날쭉(재기) | 곡선을 무작위로 끊음 | 1-1-2-2-3 같은 규칙적 계단 | `[실무]` |

## 3. 작업 전에 정할 것 (프로젝트 설정값)
- 기준 해상도: 예) 320×180 또는 480×270(1080p 정수 배율) `[실무]`
- 타일·캐릭터 크기: 예) 타일 16×16, 캐릭터 16×24 또는 32×32 `[실무]`
- PPU: 타일 크기와 같게(16 또는 32) `[실무]`
- 팔레트: 8색, 16색, 32색 중 하나와 HEX 목록 `[영상]`
- 외곽선: 1px, 색(검정 또는 대상별 어두운 색) `[영상]`
- 디더링 허용 여부와 패턴
- 셰이딩 단계: 대상당 2~4단 `[실무]`
- 안티에일리어싱: 수동 AA만 허용, 자동 AA 금지 `[실무]`

## 4. 작업 규칙
1. 팔레트를 먼저 정한다. 색 수를 숫자로 고정한다. `[영상]`
2. 생성은 고해상도로 받고, 목표 그리드 크기로 최근접 이웃(nearest) 방식으로 줄인다. `[실무]`
3. 팔레트로 픽셀 양자화를 한다. 각 픽셀을 가장 가까운 팔레트 색으로 바꾼다. `[영상]`
4. 외곽선을 1px로 다시 그리거나 스크립트로 통일한다. 이중 외곽선, 끊긴 외곽선을 찾는다. `[영상]`
5. 고립 픽셀(주변과 다른 색 1개)을 찾아 정리한다. 의도된 하이라이트만 남긴다. `[실무]`
6. 결과를 정수 배율(×3, ×4)로 키워 확인한다. 비정수 배율로 보면 판단이 틀린다. `[실무]`
7. 엔진 임포트 설정: 필터 Point, 압축 없음, 밉맵 끔. `[실무]`
8. 원본 크기와 게임 배율 두 가지로 사람에게 보낸다.

후처리 스크립트 순서 예:
```
1) 배경 제거 → 알파 임계값 128로 0/255 이진화
2) nearest 다운샘플 → 목표 크기
3) 팔레트 양자화 (색 거리: 지각 기반 거리 권장)
4) 고립 픽셀 리포트
5) 외곽선 검사: 투명과 맞닿은 픽셀이 외곽선 색인지
6) 사용 색 수 / 팔레트 외 색 수 리포트
```

## 5. 금지
| 금지 | 이유 | 예외 |
|---|---|---|
| 생성 결과를 후처리 없이 사용 | 가짜 도트 `[영상]` | 없음 |
| 팔레트 외 색 | 통일감 붕괴 | 개정된 팔레트 |
| 바이리니어 필터, 텍스처 압축 | 픽셀 번짐 | 없음 |
| 서로 다른 픽셀 크기 섞기 | 믹셀 | 의도된 UI 레이어(명시) |
| 비정수 스케일·회전 | 픽셀 깨짐 | 회전 전용 고해상도 스프라이트 |

## 7. 검증 체크리스트
- [ ] 이미지 크기가 그리드와 정확히 같다
- [ ] 팔레트 외 색이 0개다
- [ ] 알파가 0 또는 255만 있다
- [ ] 외곽선이 1px이고 끊김·이중선이 없다
- [ ] 의도하지 않은 고립 픽셀이 없다
- [ ] 엔진에서 Point 필터, 압축 없음이다
- [ ] 정수 배율로 게임 화면에서 봤다
