# 아트 / 2D 배경·타일

> 범위: 스테이지 배경, 타일맵, 장식 오브젝트, 길·지형. 원화 단계는 [02_2D원화_컨셉](02_2D원화_컨셉.md).
> 함께 볼 파일: [01_아트디렉션_스타일가이드](01_아트디렉션_스타일가이드.md), [04_픽셀아트](04_픽셀아트.md), [기획 04_레벨디자인](../01_기획/04_레벨디자인.md)

## 1. 이 파트에서 AI 티가 나는 이유
AI는 배경을 "한 장의 멋진 그림"으로 만든다. 게임 배경은 캐릭터와 UI를 받쳐야 하고, 이어 붙여야 하고, 수정할 수 있어야 한다.
배경 한 장을 통으로 생성하면 수정이 어렵고 해상도 문제가 생기며 이상 패턴이 남는다. `[영상]`
테마가 다른 스테이지로 넘어가면 기존 UI·캐릭터와 갑자기 안 어울린다. `[영상]`

## 2. AI 티 패턴
| 패턴 | 왜 티가 나나 | 대신 이렇게 | 출처 |
|---|---|---|---|
| 화면 전체를 이미지 한 장으로 | 수정·인터랙션·해상도 대응 불가 | 레이어·타일·오브젝트로 분리 | `[영상]` |
| 스테이지마다 화풍이 다름 | 테마별 해석이 다름 | 테마 간 중간 레퍼런스 | `[영상]` |
| 배경이 캐릭터보다 화려함 | 디테일·채도 과다 | 배경 채도·대비 상한 | `[실무]` |
| 타일 이음새가 보임 | 반복 경계를 고려하지 않음 | 경계 픽셀 일치 검사, 타일 변형 추가 | `[실무]` |
| 같은 장식이 격자처럼 반복 | 무작위성 없음 | 배치 규칙 + 회전·반전·크기 변형 | `[실무]` |
| 원근이 게임 카메라와 다름 | 사진식 원근 기본값 | 게임 시점(탑다운/측면/쿼터)을 명시 | `[실무]` |
| 길과 바닥이 구분 안 됨 | 명도 차 부족 | 이동 가능 영역과 불가 영역 명도 차 규칙 | `[실무]` |

## 3. 작업 전에 정할 것 (프로젝트 설정값)
- 카메라 시점과 각도: 탑다운 90도, 쿼터뷰(2:1 아이소메트릭), 측면 `[실무]`
- 타일 크기와 PPU: 예) 64×64, PPU 64 `[실무]`
- 레이어 구조: 원경 / 중경 / 플레이 영역 / 전경, 각 레이어 채도·명도 범위 `[실무]`
- 배경 채도 상한: 예) 플레이 영역 40% 이하 `[실무]`
- 길·바닥 명도 차: 예) 최소 15~20% `[실무]`
- 장식 밀도: 타일 10칸당 장식 1~3개 `[실무]`
- 테마별 중간 레퍼런스 목록(숲, 물, 불, 실내 등) `[영상]`
- 사람 손맛: 노이즈 질감 강도, 경계 흔들림 여부 `[영상]`

## 4. 작업 규칙
1. 배경은 레이어와 오브젝트로 나눠 만든다. 통 이미지 한 장은 쓰지 않는다. `[영상]`
2. 새 테마를 시작할 때 중간 레퍼런스를 먼저 만들고, 기존 캐릭터·UI를 올린 시안으로 확인한다. `[영상]`
3. 플레이 영역은 회색조로 바꿔 길·장애물·배치 가능 영역이 구분되는지 본다. `[실무]`
4. 타일은 4방향 경계 픽셀이 맞는지 스크립트로 검사한다. 반복 패턴이 보이면 변형 타일을 2~4개 추가한다. `[실무]`
5. 장식은 회전·반전·크기(90~110%) 변형과 배치 규칙으로 반복감을 줄인다. `[실무]`
6. 배경에 아주 약한 노이즈를 넣어 디지털 매끈함을 줄인다. `[영상]`
7. 배경 위에 실제 캐릭터, 적, UI를 올린 스크린샷으로 평가한다. 배경만 따로 보고 확정하지 않는다. `[영상]`
8. 후보는 같은 화면에서 A/B로 비교한다. `[영상]`

## 5. 금지
| 금지 | 이유 | 예외 |
|---|---|---|
| 화면 전체 통 이미지 배경 | 수정·해상도·이상 패턴 문제 `[영상]` | 정지된 일러스트 화면(타이틀 등) |
| 플레이 영역에 고채도·고대비 디테일 | 캐릭터·적이 묻힘 | 위험 지역 표시 |
| 배경만 보고 확정 | 합쳤을 때 안 어울림 `[영상]` | 없음 |
| 이동 불가 영역과 가능 영역이 비슷한 명도 | 플레이 혼란 | 없음 |

## 6. 요청서 예시
```
[목표] 불 테마 스테이지 바닥 타일 세트
[맥락] 탑다운 디펜스. 기존 숲 테마와 같은 게임으로 보여야 함
[레퍼런스] style_board_v1.png, refs/theme_mid_fire.png (숲→불 중간 레퍼런스)
[숫자 스펙] 타일 64×64, PPU 64, 기본 타일 1 + 변형 3, 길 타일 명도가 바닥보다 20% 높게,
           플레이 영역 채도 40% 이하, 노이즈 불투명도 4%
[금지] 용암 글로우 전면 사용, 그라데이션, 통 이미지
[검증] 10×6 타일 반복 배치 이미지, 회색조 버전, 기존 캐릭터·적·UI를 올린 합성 스크린샷,
       경계 픽셀 불일치 리포트
[산출물] tile_fire_base_00~03.png
```
```
숲 스테이지와 불 스테이지 스크린샷을 나란히 놓고, 같은 게임으로 안 보이는 지점을 찾아줘.
비교 항목: 채도 평균, 명도 분포, 외곽선 두께, 노이즈 질감, UI와의 대비.
차이가 큰 항목은 중간 레퍼런스에 반영할 수정안으로 정리해줘.
```

## 7. 검증 체크리스트
- [ ] 레이어·타일·오브젝트로 분리돼 있다
- [ ] 타일 경계 불일치가 0이다
- [ ] 반복 배치에서 격자 패턴이 눈에 띄지 않는다
- [ ] 회색조에서 길·장애물·배치 영역이 구분된다
- [ ] 다른 테마 스테이지와 같은 게임으로 보인다
- [ ] 캐릭터·UI를 올린 화면에서 확인했다
- [ ] 사람이 A/B 중 골랐다
