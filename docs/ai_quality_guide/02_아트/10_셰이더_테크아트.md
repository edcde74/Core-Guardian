# 아트 / 셰이더·테크아트

> 범위: 외곽선, 피격 번쩍임, 디졸브, 후처리 등 화면 표현용 셰이더와 아트 파이프라인 자동화(후처리 스크립트, 임포트 규칙). 일반 성능 작업은 [개발 04_최적화](../03_개발/04_최적화.md).
> 함께 볼 파일: [04_픽셀아트](04_픽셀아트.md), [09_VFX](09_VFX.md), [개발 03_에디터툴_자동화](../03_개발/03_에디터툴_자동화.md)

## 1. 이 파트에서 AI 티가 나는 이유
셰이더는 화면 전체 인상을 정한다. AI가 짜는 셰이더는 수학적으로 완벽하다. 일정한 두께의 외곽선, 균일한 블룸, 부드러운 그라데이션이 나온다. 이 완벽함이 디지털 느낌을 만든다.
반대로 일부러 불완전하게 만들면 사람이 그린 느낌이 난다. 아웃라인 셰이더를 펜으로 그린 것처럼 삐뚤빼뚤하게 만들자 사람이 그린 것 같다는 피드백이 늘고 AI 티 지적이 줄었다는 사례가 있다. `[영상]`

## 2. AI 티 패턴
| 패턴 | 왜 티가 나나 | 대신 이렇게 | 출처 |
|---|---|---|---|
| 완벽하게 균일한 외곽선 | 수학적 기본값 | 노이즈로 두께·위치를 흔든 손그림 외곽선 | `[영상]` |
| 블룸·글로우 후처리 기본 적용 | "멋지게"의 기본값 | 후처리는 목적별로 켜고 강도 상한 | `[영상]` (글로우 금지 원칙) |
| 화면 전체 색수차·비네트·필름 그레인 과다 | 템플릿 후처리 | 효과마다 이유와 강도 숫자 | `[실무]` |
| 너무 매끈한 그라데이션 셰이딩 | 연속 조명 계산 | 단계형(툰) 셰이딩, 단계 수 지정 | `[실무]` |
| 픽셀아트에 바이리니어·비정수 스케일 | 엔진 기본 설정 | Point 필터, 픽셀 퍼펙트 | `[실무]` |
| 효과마다 다른 셰이더·재질 난립 | 요청마다 새로 짬 | 공통 셰이더 + 파라미터 | `[실무]` |

## 3. 작업 전에 정할 것 (프로젝트 설정값)
- 외곽선 방식: 스프라이트 원본 / 셰이더 / 후처리 중 하나 `[실무]`
- 외곽선 수치: 두께 px, 흔들림 진폭(예: 두께의 ±20~30%), 노이즈 주기, 갱신 주기(정지 또는 초당 8~12회 끓는 선) `[실무]`
- 셰이딩 단계 수와 경계 부드러움 `[실무]`
- 피격 번쩍임: 색, 지속 시간(예: 60~100ms), 곡선 `[실무]`
- 후처리 목록과 각 강도 상한(블룸 사용 여부 포함) `[실무]`
- 성능 예산: 셰이더 변형 수, 텍스처 샘플 수, 모바일 대응 여부 `[실무]`
- 아트 후처리 스크립트: 양자화, 외곽선 검사, 알파 정리 단계 `[영상]` (코드 후처리 원칙)

## 4. 작업 규칙
1. 셰이더 효과마다 "왜 필요한지"를 한 줄로 적는다. 이유가 없으면 넣지 않는다. `[실무]`
2. 손맛이 필요한 곳은 일부러 불완전하게 만든다. 외곽선 흔들림, 종이 질감, 선 끊김을 파라미터로 둔다. `[영상]`
3. 흔들림은 과하면 지저분하다. 강도를 3단계로 만들어 실제 화면에서 A/B 비교한다. `[영상]` (A/B 비교)
4. 아트 생성 결과의 후처리(팔레트 양자화, 외곽선 통일, 알파 정리)는 스크립트로 만들어 모든 에셋에 같게 돌린다. `[영상]`
5. 공통 셰이더 하나에 파라미터를 두고 재질별로 값만 바꾼다. `[실무]`
6. 셰이더 변경은 전후 스크린샷과 성능 수치를 같은 조건으로 남긴다. `[실무]`
7. 최저 사양 기기에서 확인한다. `[실무]`

## 5. 금지
| 금지 | 이유 | 예외 |
|---|---|---|
| 이유 없는 블룸·글로우·색수차 | AI 티, 성능 | 컨셉상 필요(명시) |
| 수학적으로 완벽한 외곽선을 기본으로 | 디지털 느낌 `[영상]` | 깔끔한 벡터 스타일이 컨셉 |
| 에셋마다 손으로 다른 후처리 | 일관성 붕괴 | 없음 |
| 성능 측정 없이 셰이더 추가 | 프레임 하락 | 없음 |

## 6. 요청서 예시
```
[목표] 손그림 느낌 외곽선 셰이더
[맥락] 2D 스프라이트 게임. 펜으로 그린 듯한 선이 화풍 핵심
[숫자 스펙] 기본 두께 2px, 두께 흔들림 ±25%, 위치 흔들림 0.5px, 노이즈 주기 화면 40px,
           선 갱신 초당 8회(끓는 선) 또는 정지(파라미터), 색 #2B1D14
[변형] 흔들림 강도 약/중/강 3안
[검증] 같은 장면 3안 비교 스크린샷과 5초 영상, 적용 전후 GPU 시간
[금지] 블룸, 외곽선 글로우
```
```
아트 후처리 스크립트를 만들어줘. 입력 폴더의 PNG를 모두 처리한다.
순서: 알파 이진화(임계값 128) → 팔레트 양자화(palette_v1.gpl) → 외곽선 두께 검사 → 리포트
리포트에는 파일별 팔레트 외 색 수, 반투명 픽셀 수, 외곽선 규칙 위반 위치를 적는다.
원본은 건드리지 말고 결과는 별도 폴더에 저장한다.
```

## 7. 검증 체크리스트
- [ ] 각 효과의 필요 이유가 적혀 있다
- [ ] 손맛 파라미터 강도를 A/B로 비교했다
- [ ] 공통 셰이더 + 파라미터 구조다
- [ ] 후처리 스크립트가 모든 에셋에 같게 적용됐다
- [ ] 전후 스크린샷과 성능 수치가 같은 조건이다
- [ ] 최저 사양에서 확인했다
- [ ] 사람이 실제 화면을 보고 승인했다
- [ ] 파라미터 기본값과 범위가 문서로 남아 있다
