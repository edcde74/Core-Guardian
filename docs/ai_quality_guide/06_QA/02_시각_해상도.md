# QA / 시각·해상도

> 범위: 화면에 보이는 결과물의 품질 검사(넘침, 겹침, 잘림, 일관성, 해상도 대응, 가독성). 기능 동작은 [01_기능_회귀](01_기능_회귀.md)에서 다룬다.
> 함께 볼 파일: [03_개발/02_UI구현](../03_개발/02_UI구현.md), [02_아트/01_아트디렉션_스타일가이드](../02_아트/01_아트디렉션_스타일가이드.md)

## 1. 이 파트에서 AI 티가 나는 이유
AI가 만든 게임의 화면 문제는 대부분 아무도 실제 화면을 보지 않아서 생긴다. 코드 기반 검증은 글자가 카드를 넘거나 버튼이 겹치는 것을 잡지 못한다. 기준 해상도 한 개에서만 맞추고, 따로 만든 에셋을 마지막에 합쳐서 화면 안 스타일이 어긋난다. `[영상]`

## 2. AI 티 패턴
| 패턴 | 왜 티가 나나 | 대신 이렇게 | 출처 |
|---|---|---|---|
| 글자 넘침·잘림 | 코드 기반 검증만 함 | 비전 기반 검증 | `[영상]` |
| 한 해상도에서만 정상 | 기준 해상도만 확인 | 16:9, 4:3, 21:9 스모크 테스트 | `[영상]` |
| 요소별로는 괜찮은데 합치면 어색 | 따로 만들고 마지막에 합침 | 실제 화면에 올려 비교 | `[영상]` |
| 스테이지마다 화풍이 다름 | 대상별 레퍼런스 부족 | 중간 레퍼런스, 스테이지별 나란히 비교 | `[영상]` |
| 외곽선 두께가 제각각 | 수치 기준 없음 | 외곽선 px 측정 | `[영상]` |
| 비전 검사 통과했는데 사람 눈에 이상 | AI 판정의 한계 | 마지막엔 사람에게 스크린샷 | `[영상]` |
| 색약·작은 화면 고려 없음 | 기본 화면만 확인 | 흑백·색약 시뮬레이션, 최소 크기 확인 | `[실무]` |

## 3. 작업 전에 정할 것 (프로젝트 설정값)
- 검사 해상도 목록(예: 1920x1080, 1440x1080, 2560x1080, 1280x720, 3840x2160)
- 안전 영역, 최소 글자 크기
- 검사할 화면 목록(타이틀, HUD, 각 팝업, 결과 화면, 스테이지별)
- 스크린샷 저장 경로·이름 규칙(화면_해상도_날짜)
- 비교 기준 이미지(승인된 화면) 경로

## 4. 작업 규칙
1. **화면 목록 × 해상도 목록으로 스크린샷을 찍는다.** 자동화한다. `[영상]`
2. **비전 기반으로 검사한다.** 스크린샷을 보고 넘침·겹침·잘림·안전 영역 침범을 찾는다. 기준선, 안전 영역, 바운딩 박스를 기준으로 판단하게 한다. `[영상]`
3. **최악 조건을 넣는다.** 가장 긴 문자열, 최대 적 수, 이펙트가 가장 많은 순간.
4. **승인 화면과 나란히 비교한다.** A/B 비교 이미지로 만들어 사람은 판정만 하게 한다. `[영상]`
5. **스테이지·테마를 나란히 놓는다.** 한 화면에 모아보면 스타일 불일치가 바로 보인다. `[실무]`
6. **가독성을 따로 본다.** 흑백 변환, 축소(50%) 상태에서 중요한 정보가 구분되는지.
7. **최종 판정은 사람이 한다.** 스크린샷을 사람에게 보낸다. `[영상]`

## 5. 금지
| 금지 | 이유 | 예외 |
|---|---|---|
| 스크린샷 없는 시각 QA 완료 | 근거 없음 | 없음 |
| 기준 해상도만 검사 | 비율 문제 누락 | 고정 해상도 게임 |
| 비전 판정만으로 최종 승인 | 사람 눈에 보이는 문제 누락 | 없음 |
| 요소 단독 이미지로 판단 | 합쳤을 때 문제 누락 | 에셋 단계 사전 확인 |

## 6. 요청서 예시
```
[목표] HUD 개편 시각 QA.
[대상] 전투 HUD, 업그레이드 팝업, 결과 화면.
[해상도] 1920x1080, 1440x1080, 2560x1080, 1280x720.
[조건] 가장 긴 포탑 이름, 최대 골드 자릿수, 적 최대 수 순간.
[검사] 넘침·겹침·잘림·안전 영역 침범을 바운딩 박스 기준으로 표시한 이미지.
       승인 화면과 나란히 놓은 비교 이미지. 모두 나에게 보내라.
```

## 7. 검증 체크리스트
- [ ] 화면 × 해상도 스크린샷 전체
- [ ] 문제 위치를 표시한 이미지
- [ ] 최악 조건 스크린샷
- [ ] 승인 화면과의 A/B 비교
- [ ] 흑백·축소 가독성 확인
- [ ] 사람이 최종 판정
