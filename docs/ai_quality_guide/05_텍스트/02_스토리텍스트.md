## 1. 이 파트에서 AI 티가 나는 이유
AI는 지적으로 보이려는 듯 번역투 문장을 쓴다. 뜻은 통하지만 시험 지문처럼 한 번 머릿속에서 풀어야 읽힌다. 또 분위기를 내려고 같은 상투구("조용히", "멈췄다")를 반복하고, 캐릭터마다 말투가 비슷해진다. `[영상]`

## 2. AI 티 패턴
### 번역투 `[영상]`
| 패턴 | 예 (요약) | 대신 이렇게 |
|---|---|---|
| 피동 겹치기 | "~에 의해 발생되어진다고 볼 수 있다" | "~로 생긴다" |
| 소유격 대명사 반복 | "그는 그의 칼을 쥐었다" | "그는 칼을 쥐었다" |
| "~라고 할 수 있다" | 판단 유보 습관 | 단정하거나 뺀다 |

### 상투구·문형
| 패턴 | 왜 티가 나나 | 대신 이렇게 | 출처 |
|---|---|---|---|
| "조용히 ~했다" | 분위기용 습관 | 구체적인 행동으로 | `[영상]` |
| "~하다가 멈췄다" | 긴장 연출 습관 | 멈춘 이유를 보여준다 | `[영상]` |
| "A가 아닌 B", "단순히 ~가 아니라" | 대조 강조 습관 | B만 쓴다 | `[영상]` |
| "찌르다", "축", "경계" 비유 | 맥락과 무관하게 반복 | 세계관에 맞는 말 | `[영상]` |
| "핵심은 ~" | 설명문 말투 | 캐릭터 말투로 | `[영상]` |
| 문장마다 감각 묘사 3개 나열 | 과잉 묘사 | 하나만, 가장 중요한 것 | `[실무]` |
| 모든 캐릭터가 같은 어휘·문장 길이 | 개성 없음 | 캐릭터별 말버릇 시트 | `[실무]` |
| 감정을 직접 말함("그는 슬펐다") | 보여주지 않고 설명 | 행동·대사로 | `[실무]` |
| 문단 끝마다 교훈·요약 | AI 마무리 습관 | 장면에서 끝낸다 | `[실무]` |
| 엠대시·말줄임표 남발 | 기호 티 | 쉼표, 마침표 | `[영상]` |

### 영어 `[실무]`
| 패턴 | 대신 이렇게 |
|---|---|
| "a testament to", "a tapestry of", "echoes of" | 구체적인 사실 |
| "In a world where..." 도입 | 장면으로 바로 시작 |
| "little did they know" | 복선으로 |
| "The air was thick with..." | 감각 하나만 짧게 |

## 3. 작업 전에 정할 것 (프로젝트 설정값)
- 서술 시점과 시제
- 캐릭터별 말투 시트: 존댓말 여부, 문장 길이, 자주 쓰는 말, 절대 안 쓰는 말
- 텍스트 종류별 길이 (대사 한 줄, 아이템 설명, 도감)
- 세계관 고유어 목록 (용어집)
- 금지 상투구 목록

## 4. 작업 규칙
1. 세계관 요약, 캐릭터 말투 시트, 용어집을 같이 넘긴다.
2. 장면 정보를 준다. 누가, 어디서, 무엇을 원하고, 무엇이 막고 있는지.
3. 초안을 받으면 **번역투 → 상투구 → 기호** 순서로 고친다. 번역투 교정 스킬로 한 번 초벌하고, 단어·문형 목록은 따로 검색한다. `[영상]`
4. 소리 내어 읽는다. 입에 안 붙는 문장은 고친다.
5. 캐릭터 이름을 가리고 읽어도 누구 대사인지 알 수 있는지 확인한다.
6. 게임 화면(대화창, 툴팁)에 넣어 길이와 줄바꿈을 확인한다.

## 5. 금지
| 금지 | 이유 | 예외 |
|---|---|---|
| 위 번역투·상투구 | AI 티 | 캐릭터 말버릇으로 의도한 경우 |
| 용어집에 없는 고유명사 즉석 생성 | 설정 충돌 | 용어집에 먼저 등록 |
| 실존 작품 문장·설정 가져오기 | 저작권 | 없음 |
| 대화창 길이 넘는 대사 | 넘김·잘림 | 컷신 전용 |

## 6. 요청서 예시
```
[목표] 2스테이지 몬스터 도감 설명 6개, 각 60자 이내
[맥락] 숲을 지키던 정령이 오염돼 적이 된 세계. 도감은 정찰병이 쓴 기록 말투
[말투] 짧은 관찰 기록체, 반말 평서문, 감정 표현 최소
[용어] 첨부 용어집만 사용, 새 고유명사 금지
[금지] 번역투 피동, "조용히", "멈췄다", "A가 아닌 B", 엠대시, 말줄임표
[검증] 금지 문형 검색 결과 0개 표 첨부
```

## 7. 검증 체크리스트
- [ ] 번역투 피동·소유격 반복 없음
- [ ] 금지 상투구 개수 0
- [ ] 금지 기호 개수 0
- [ ] 용어집 밖 고유명사 0
- [ ] 이름을 가려도 캐릭터 구분 가능 (사람 판단)
- [ ] 소리 내어 읽어 어색한 곳 없음 (사람 판단)
- [ ] 게임 화면에서 길이·줄바꿈 정상
