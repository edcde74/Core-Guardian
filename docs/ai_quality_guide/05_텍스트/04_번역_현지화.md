# 텍스트 / 번역·현지화

> 범위: 게임 텍스트의 다국어 번역, 문화 현지화, 언어별 UI 대응, 이미지 속 글자 처리. 원문 작성은 [01_UI문구_툴팁](01_UI문구_툴팁.md), [02_스토리텍스트](02_스토리텍스트.md)에서 다룬다.
> 함께 볼 파일: [03_용어집](03_용어집.md), [03_개발/02_UI구현](../03_개발/02_UI구현.md), [07_출시마케팅/01_스토어페이지](../07_출시마케팅/01_스토어페이지.md)

## 1. 이 파트에서 AI 티가 나는 이유
AI 번역은 문장 단위로는 자연스러워 보여도 용어가 흔들리고, 말장난과 라임이 사라지고, 문화적으로 어색한 표현이 남는다. AI 콘텐츠 반감이 큰 북미·유럽·일본 시장에서는 어색한 번역이 곧 "AI 게임"이라는 인상이 된다. `[영상]`

## 2. AI 티 패턴
| 패턴 | 왜 티가 나나 | 대신 이렇게 | 출처 |
|---|---|---|---|
| 용어가 문장마다 다르게 번역됨 | 규칙 혼동 | 용어집 기반 번역 | `[영상]` |
| 라임·말장난이 번역에서 사라짐 | 원문 재미가 없어짐 | 로마자 발음까지 확인하게 하고, 목표 언어로 새 라임을 만든다 | `[영상]` |
| 원문 어순을 그대로 따른 문장 | 직역투 | 목표 언어 기준으로 다시 쓴다 | `[실무]` |
| 존댓말·말투 단계가 섞임 | 캐릭터성 붕괴 | 언어별 말투 규칙을 정한다 | `[실무]` |
| 영어 AI 단어(delve, embark, unleash) | 영어권에서 AI 티로 유명 | 평범한 단어 | `[실무]` |
| 이미지에 구운 글자를 이미지째 재생성 | 글자 깨짐, 화풍 변함 | 글자 없는 이미지 + 폰트로 얹기 | `[영상]` |
| 문화 맥락 무시 (숫자, 색, 손동작, 종교) | 현지 플레이어 불쾌 | 현지 검수 | `[실무]` |

## 3. 작업 전에 정할 것 (프로젝트 설정값)
- 지원 언어와 우선순위
- 언어별 말투 규칙 (영어 캐주얼/포멀, 일본어 です・ます 여부 등)
- 언어별 폰트와 글리프 범위 (한중일 폰트 포함)
- 글자 수 허용 폭 (원문 대비 최대 몇 % 길어져도 되는지)
- 숫자·날짜·단위 표기 규칙
- 현지 검수자 유무

## 4. 작업 규칙
1. 원문을 먼저 확정한다. 확정 안 된 원문은 번역하지 않는다.
2. 용어집, 말투 규칙, 화면 글자 수 제한, 문맥(어디에 뜨는 글인지)을 같이 넘긴다. `[영상]`
3. 문자열마다 문맥 메모를 붙인다. "버튼", "툴팁 제목", "보스 대사" 같은 정보가 없으면 같은 단어도 틀리게 번역된다.
4. **역번역 검수**를 한다. 번역문을 다시 한국어로 번역해 원문 의미와 비교한다. 의미가 달라진 곳만 사람이 본다. `[영상]`
5. 라임·말장난 문구는 로마자 발음 표기를 같이 내게 해서 소리가 살아 있는지 확인한다. `[영상]`
6. 이미지 속 글자는 글자 없는 이미지를 만들고 게임에서 폰트로 얹는다. 언어마다 이미지를 다시 만들지 않는다. `[영상]`
7. 가장 긴 언어로 UI 스크린샷을 찍어 넘침을 확인한다. 독일어, 프랑스어, 러시아어가 보통 길다. `[실무]`
8. 출시 언어는 가능하면 원어민이 한 번 플레이하며 확인한다. `[실무]`

### 문자열 파일 구성 `[실무]`
| 열 | 내용 |
|---|---|
| Key | 문자열 ID |
| 원문 | 확정된 한국어 |
| 문맥 | 화면 위치, 화자, 앞뒤 상황 |
| 최대 길이 | 글자 수 또는 픽셀 폭 |
| 변수 | {0}, {name} 같은 자리표시자 설명 |
| 언어별 번역 | |
| 역번역 | 검수용 |
| 상태 | 번역 / 검수 / 확정 |

### 자리표시자와 복수형 `[실무]`
- 변수 순서는 언어마다 바뀔 수 있으니 번호가 아니라 이름을 쓴다 ({count}, {target}).
- 복수형 규칙이 다른 언어(영어, 러시아어 등)는 단수·복수 문자열을 따로 둔다.
- 문장을 조각내서 이어 붙이지 않는다. 언어마다 어순이 다르다.

### 자주 하는 실수
- 원문을 고친 뒤 번역이 옛 버전으로 남는다. 원문이 바뀌면 상태를 "번역"으로 되돌린다.

## 5. 금지
| 금지 | 이유 | 예외 |
|---|---|---|
| 용어집 없이 번역 | 용어 흔들림 `[영상]` | 없음 |
| 문맥 메모 없는 문자열 일괄 번역 | 오역 | 없음 |
| 이미지 속 글자를 이미지째 번역 | 깨짐, 화풍 변화 `[영상]` | 로고 |
| 역번역 없이 출시 | 의미 변형을 놓침 | 없음 |
| 폰트 글리프 확인 없이 언어 추가 | 네모 글자(tofu) | 없음 |

## 6. 요청서 예시
```
[목표] 업적 문구 20개를 영어, 일본어로 번역
[자료] 용어집, 언어별 말투 규칙, 문자열별 문맥 메모 첨부
[제한] 제목은 원문 대비 140% 이내 길이
[라임] 라임이 있는 7개는 로마자 발음 표기를 같이 내고, 목표 언어에서 라임이 살아 있는지 표시
[검증] 역번역 결과와 원문을 나란히 놓은 표, 의미가 바뀐 줄 표시
[금지] delve, embark, unleash, tapestry
```

## 7. 검증 체크리스트
- [ ] 용어집 단어만 사용 (언어별 검색)
- [ ] 역번역 비교에서 의미 변형 줄을 모두 확인했다
- [ ] 라임 문구는 로마자 표기로 확인했다
- [ ] 가장 긴 언어로 UI 넘침 없음 (스크린샷)
- [ ] 폰트 글리프 누락 없음
- [ ] 이미지 속 글자는 폰트로 얹었다
- [ ] 현지 문화상 문제 표현 없음 (사람 판단)
