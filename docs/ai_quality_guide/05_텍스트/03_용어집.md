# 텍스트 / 용어집

> 범위: 게임 안에서 쓰는 고유명사, 효과·상태이상, 자원, 시스템 용어의 정의와 언어별 표기. 문장 작성법은 [01_UI문구_툴팁](01_UI문구_툴팁.md), [02_스토리텍스트](02_스토리텍스트.md)에서 다룬다.
> 함께 볼 파일: [04_번역_현지화](04_번역_현지화.md), [01_기획/08_데이터테이블](../01_기획/08_데이터테이블.md)

## 1. 이 파트에서 AI 티가 나는 이유
AI는 같은 말을 반복하지 않으려고 동의어로 바꿔 쓴다. 소설에서는 장점이지만 게임에서는 규칙이 흐려진다. 예를 들어 '화상' 상태이상을 어떤 곳에서는 "불에 덴다", 다른 곳에서는 "뜨거운 것에 닿는다"로 쓰면, 플레이어는 같은 효과인지 다른 효과인지 알 수 없다. 용어집이 이걸 막는다. `[영상]`

## 2. AI 티 패턴
| 패턴 | 왜 문제인가 | 대신 이렇게 | 출처 |
|---|---|---|---|
| 같은 효과를 문장마다 다른 말로 | 규칙 혼동 | 용어집 단어 하나만 | `[영상]` |
| 번역할 때 용어가 언어마다 흔들림 | 언어권별로 다른 게임처럼 됨 | 용어집 기반으로 번역 | `[영상]` |
| 문맥 없이 즉석으로 만든 고유명사 | 설정 충돌, 어색한 조어 | 용어집에 등록 후 사용 | `[실무]` |
| 비슷한 이름 두 개 (예: '빙결'과 '동결') | 구분 불가 | 하나로 합치거나 확실히 다른 이름 | `[실무]` |
| 데이터 ID와 표시 이름이 따로 놂 | 수정 시 누락 | ID와 표시 이름을 같은 표에 | `[실무]` |

## 3. 작업 전에 정할 것 (프로젝트 설정값)
- 용어집 파일 위치와 형식 (CSV/스프레드시트 권장)
- 열 구성 (아래 표준 열 참고)
- 용어 분류 (효과, 상태이상, 자원, 유닛, 지역, 시스템, UI)
- 지원 언어
- 새 용어 등록 절차 (누가 확정하는지)

## 4. 작업 규칙
1. 표준 열로 만든다.

| 열 | 설명 |
|---|---|
| ID | 데이터 테이블과 같은 키 |
| 분류 | 효과/상태이상/자원/유닛 등 |
| 한국어 | 표시 이름 |
| 정의 | 게임 규칙상 의미 한 줄 |
| 쓰면 안 되는 말 | 흔한 동의어 (예: 화상 → "불에 덴", "그을림") |
| 영어 / 일본어 / ... | 언어별 표기 |
| 발음 | 보이스용 표기 |
| 상태 | 제안 / 확정 |
| 비고 | 아이콘, 색 등 연결 정보 |

2. "쓰면 안 되는 말" 열을 꼭 채운다. AI가 바꿔 쓸 만한 동의어를 미리 막는다.
3. 모든 텍스트 생성과 번역 요청에 용어집을 같이 넘긴다. `[영상]`
4. 생성 후 "쓰면 안 되는 말" 목록으로 검색해 0개인지 확인한다.
5. 새 용어가 필요하면 먼저 용어집에 "제안"으로 등록하고, 사람이 확정한 뒤에 쓴다.
6. 용어 이름을 바꾸면 용어집 → 데이터 테이블 → 모든 텍스트 순서로 일괄 반영한다.
7. 아이콘과 색을 용어와 1:1로 맞춘다. 같은 효과는 어디서나 같은 아이콘.

### 항목 예 `[실무]`
| ID | 분류 | 한국어 | 정의 | 쓰면 안 되는 말 | 영어 | 상태 |
|---|---|---|---|---|---|---|
| ST_BURN | 상태이상 | 화상 | 일정 시간 동안 초마다 피해 | 불에 덴, 그을림, 화염 피해 | Burn | 확정 |
| ST_SLOW | 상태이상 | 둔화 | 이동 속도 감소 | 느려짐, 감속, 지연 | Slow | 확정 |

### 이름 짓기 기준 `[실무]`
- 한 단어, 가능하면 2~3글자. 툴팁과 아이콘 옆에 들어가야 한다.
- 같은 분류 안에서 첫 글자가 겹치지 않게 한다.
- 장르에서 흔히 쓰는 이름(화상, 둔화, 기절)은 그대로 쓰는 편이 배우기 쉽다. 독창성은 세계관 고유명사에서 낸다.

### 자주 하는 실수
- 기획서와 게임 텍스트가 서로 다른 이름을 쓴다. 기획서도 용어집을 따른다.
- 번역가에게 용어집 없이 문자열만 넘긴다.

## 5. 금지
| 금지 | 이유 | 예외 |
|---|---|---|
| 용어집 밖 효과 이름 사용 | 규칙 혼동 | 없음 |
| 확정 전 용어를 번역 | 재작업 | 없음 |
| 같은 분류 안에서 비슷한 이름 | 구분 불가 | 의도한 상위·하위 관계 |
| 용어집 없이 번역 맡기기 | 언어별 용어 흔들림 `[영상]` | 없음 |

## 6. 요청서 예시
```
[목표] 신규 상태이상 3개의 용어집 항목 제안
[맥락] 기존 용어집 첨부. 기존 이름과 헷갈리지 않아야 한다
[열] ID / 분류 / 한국어 / 정의 / 쓰면 안 되는 말 / 영어 / 일본어 / 발음
[규칙] 이름 후보는 2개씩, 기존 용어와 첫 글자 겹침 피하기. 상태는 모두 "제안"
[검증] 기존 용어와의 유사도 비교표 첨부
```

## 7. 검증 체크리스트
- [ ] 모든 효과·상태이상에 ID와 정의가 있다
- [ ] "쓰면 안 되는 말" 열이 채워져 있다
- [ ] 전체 텍스트에서 "쓰면 안 되는 말" 검색 결과 0
- [ ] 언어별 표기 칸이 비어 있지 않다 (지원 언어 기준)
- [ ] 용어와 아이콘이 1:1이다
- [ ] 확정 용어만 게임에 들어갔다
