# 사운드 / 보이스

> 범위: 캐릭터 대사, 내레이션, 짧은 기합·리액션 음성의 생성(TTS·음성 합성)과 편집. 대사 문장 자체는 [05_텍스트/02_스토리텍스트](../05_텍스트/02_스토리텍스트.md)에서 다룬다.
> 함께 볼 파일: [02_SFX](02_SFX.md), [05_텍스트/04_번역_현지화](../05_텍스트/04_번역_현지화.md)

## 1. 이 파트에서 AI 티가 나는 이유
합성 음성은 억양이 평평하고, 문장 끝이 늘 같은 방식으로 내려가고, 숨소리와 망설임이 없다. 대본 자체가 번역투면 더 부자연스럽게 들린다. 또 실제 사람의 목소리를 닮게 만드는 것은 권리 문제가 크다. `[실무]`

## 2. AI 티 패턴
| 패턴 | 왜 티가 나나 | 대신 이렇게 | 출처 |
|---|---|---|---|
| 모든 문장 끝 억양이 같음 | 낭독 기계처럼 들림 | 문장 유형별(질문, 감탄, 혼잣말) 억양 지시 | `[실무]` |
| 숨, 쉼, 망설임이 없음 | 사람 말투가 아님 | 쉼 표시와 짧은 숨을 대본에 넣는다 | `[실무]` |
| 감정 강도가 처음부터 끝까지 같음 | 장면 흐름이 안 느껴짐 | 대사마다 감정 강도를 1~5로 적는다 | `[실무]` |
| 번역투 대본을 그대로 읽힘 | 귀로 들으면 더 어색함 | 대본을 먼저 입말로 고친다 | `[영상]` |
| 캐릭터마다 목소리 질감이 비슷함 | 구분이 안 됨 | 캐릭터별 음역, 속도, 말버릇을 정한다 | `[실무]` |
| 발음이 이상한 고유명사 | 세계관 몰입 깨짐 | 발음 표기를 용어집에 넣는다 | `[실무]` |

## 3. 작업 전에 정할 것 (프로젝트 설정값)
- 캐릭터별 보이스 시트: 나이대, 음역(높음/중간/낮음), 말 속도, 말버릇, 감정 기본값
- 고유명사 발음 표기 (용어집과 연동)
- 대사 최대 길이 (초)
- 음량 기준, 앞뒤 무음 길이
- 사용할 합성 도구와 상업 이용 조건
- 지원 언어별 보이스 여부

값은 [프로젝트 설정](../00_공통/03_프로젝트설정_템플릿.md)에 적는다.

## 4. 작업 규칙
1. 대본을 입말로 고친다. 소리 내어 읽어서 숨이 차거나 어색한 곳을 자른다. 번역투 교정은 [05_텍스트/02](../05_텍스트/02_스토리텍스트.md)를 따른다.
2. 대사마다 감정, 강도, 속도, 쉼 위치를 표시한다.
3. 고유명사 발음을 용어집에서 가져와 적용한다.
4. 캐릭터 보이스 시트를 모든 생성에 같이 넘긴다.
5. 같은 대사를 2~3개 버전으로 만들어 장면에 붙여 듣고 고른다.
6. 앞뒤 무음을 기준에 맞추고, 숨소리가 과하면 줄인다.
7. 실존 인물(성우, 유명인)의 목소리를 흉내내는 생성은 하지 않는다. 사람 성우를 쓰면 계약에 AI 학습·합성 사용 범위를 명시한다.
8. 현지화 음성은 원문과 길이 차이를 확인해 립싱크나 자막 타이밍을 맞춘다.

### 대본 표기 예 `[실무]`
```
ID: TUT_003 / 화자: 정비공 / 감정: 귀찮음 2 / 속도: 빠름
대사: 거기 말고. (쉼 0.3) 바로 옆 칸.
메모: "옆 칸"에 힘을 준다. 끝은 내리지 말고 짧게 끊는다.
```

### 짧은 음성(기합·리액션) `[실무]`
- 공격 기합, 피격, 사망 리액션은 대사보다 자주 나므로 변형을 3개 이상 만든다.
- 길이는 0.5초 안팎으로 짧게 하고 효과음과 대역이 겹치지 않는지 확인한다.
- 반복 재생해도 거슬리지 않는지 실제 전투 물량에서 듣는다.

### 자주 하는 실수
- 문장 단위로 따로 생성해 이어 붙여서 문장마다 목소리 톤이 달라진다. 한 장면은 한 번에 생성한다.
- 대본을 고친 뒤 음성은 옛 버전이 남는다. 대본 ID와 음성 파일 이름을 맞춘다.
- 자막과 음성 내용이 다르다. 대본을 고치면 자막도 같이 고친다.

## 5. 금지
| 금지 | 이유 | 예외 |
|---|---|---|
| 실존 인물 목소리 복제 | 퍼블리시티권·계약 문제 | 본인 동의와 계약이 있는 경우 |
| 번역투 대본 그대로 합성 | 부자연스러움이 커짐 | 없음 |
| 감정 표시 없는 일괄 생성 | 평평한 억양 | 시스템 안내 음성 |
| 상업 이용 조건 미확인 도구 | 출시 후 문제 | 없음 |

## 6. 요청서 예시
```
[목표] 튜토리얼 안내 캐릭터 대사 12줄
[캐릭터] 노련한 정비공, 40대, 낮은 음역, 말 빠름, 문장 끝을 짧게 끊음
[대사 표시] 대사마다 (감정/강도1~5/쉼 위치) 표기
[발음] 고유명사는 용어집 발음 표기 사용
[숫자 스펙] 한 줄 최대 4초, 앞 무음 0.05초, 뒤 무음 0.2초
[금지] 과장된 애니 톤, 문장 끝 올림 반복
[검증] 튜토리얼 화면에 붙인 영상으로 제출
```

## 7. 검증 체크리스트
- [ ] 대본을 소리 내어 읽어 어색한 곳이 없다
- [ ] 고유명사 발음이 용어집과 같다
- [ ] 줄 길이, 무음 길이가 기준 이내다
- [ ] 캐릭터끼리 목소리가 구분된다
- [ ] 장면에 붙여 들었을 때 감정 흐름이 맞다 (사람 판단)
- [ ] 도구 이용 조건과 성우 계약 범위를 확인했다
