# 개발 / 에디터 툴·자동화

> 범위: 에디터 확장, 에셋 처리 스크립트, 반복 작업 자동화, 에이전트로 에디터를 조작하는 워크플로. 빌드 자동화는 [05_빌드_배포](05_빌드_배포.md), 테스트 자체는 [06_QA](../06_QA/01_기능_회귀.md)에서 다룬다.
> 함께 볼 파일: [00_공통/02_AI협업_프로세스](../00_공통/02_AI협업_프로세스.md), [02_아트/04_픽셀아트](../02_아트/04_픽셀아트.md)

## 1. 이 파트에서 AI 티가 나는 이유
AI가 만든 툴은 한 번 돌아가면 끝이다. 실행 취소가 없고, 실패해도 조용히 넘어가고, 어떤 에셋을 바꿨는지 기록이 없다. 범용 툴을 만들려다 옵션 창이 거대해지기도 한다. 반대로 정말 자동화해야 할 반복 잡일은 손으로 계속 하고 있는 경우가 많다. `[실무]`

## 2. AI 티 패턴
| 패턴 | 왜 티가 나나 | 대신 이렇게 | 출처 |
|---|---|---|---|
| 실행 취소 없는 일괄 수정 | 되돌릴 수 없음 | `Undo.RecordObject`, 변경 전 백업·커밋 | `[실무]` |
| 무엇을 바꿨는지 로그 없음 | 결과 검토 불가 | 변경 목록·건수 출력 | `[실무]` |
| 드라이런 모드 없음 | 실행 전 영향 확인 불가 | 미리보기 → 확인 → 적용 | `[실무]` |
| 쓰지 않는 옵션 가득한 창 | 범용 툴 욕심 | 지금 필요한 1~2개 기능만 | `[실무]` |
| 씬·프리팹 텍스트 직접 수정 | 참조·GUID 손상 | 에디터 API 사용 | `[실무]` |
| 잡일은 수작업, 콘텐츠만 AI | 효율 낮은 곳에 AI 투입 | 잡일 자동화부터 | `[영상]` |

## 3. 작업 전에 정할 것 (프로젝트 설정값)
- 툴 메뉴 위치와 이름 규칙(예: `Tools/<프로젝트명>/...`)
- 에디터 전용 코드 폴더·어셈블리
- 일괄 처리 전 백업 방식(Git 커밋 / 복사본)
- 에이전트가 에디터를 조작할 때 허용 범위(Play 진입, 설정 변경, 씬 저장 등)

## 4. 작업 규칙
1. **반복 잡일 목록을 먼저 만든다.** 일주일에 세 번 이상 하는 손작업이 자동화 후보다. `[실무]`
2. **우선순위는 잡일 → 검증 → 콘텐츠.** `[영상]`
   - 출시 잡일: 스토어 설명 입력, 스크린샷 비율 맞추기
   - QA 잡일: 업데이트 후 에디터를 조작해 확인, 스크린샷 찍기, 코드 확인
   - 테스트: 훅과 테스트 프레임워크로 자동화 테스트 구축 → 구현 속도 상승
3. **드라이런 → 적용 순서로 만든다.** 대상 목록과 바뀔 값을 먼저 보여준다.
4. **되돌릴 수 있게 만든다.** Undo 등록 또는 작업 전 커밋.
5. **결과를 기록한다.** 처리 건수, 실패 목록, 걸린 시간.
6. **후처리는 코드로 고정한다.** 픽셀 양자화, 팔레트 정리, 이미지 비율 맞추기처럼 매번 같은 처리는 스크립트로 만든다. `[영상]`
7. **에이전트 조작은 범위를 정한다.** Play 진입·종료, 프로파일러, 설정 변경은 사람이 허락한 것만 한다. `[실무]`

## 5. 금지
| 금지 | 이유 | 예외 |
|---|---|---|
| 백업 없는 일괄 수정 | 복구 불가 | 없음 |
| 실패 무시하고 계속 진행 | 일부만 바뀐 상태로 남음 | 실패 목록을 끝에 출력 |
| 툴이 런타임 빌드에 포함 | 빌드 오류·용량 증가 | 없음. Editor 폴더/asmdef 분리 |
| 사람 허락 없는 무거운 진단 실행 | 에디터 멈춤 | 승인된 범위 |

## 6. 요청서 예시
```
[목표] Sprites/Monsters 폴더의 PNG 임포트 설정을 일괄 정리하는 에디터 메뉴.
[숫자 스펙] PPU 32, Filter Point, Compression None, Max Size 512.
[규칙] 1) 드라이런: 바뀔 파일과 현재값→새값 표를 콘솔에 출력. 2) 확인 후 적용. 3) Undo 등록.
[금지] 다른 폴더 접근, 옵션 창, 런타임 어셈블리 포함.
[검증] 처리 건수와 실패 목록 출력. 샘플 3개 임포트 설정 스크린샷.
```

## 7. 검증 체크리스트
- [ ] 드라이런 결과가 실제 적용 결과와 일치
- [ ] Undo 또는 커밋으로 되돌리기 확인
- [ ] 처리 건수·실패 목록 출력
- [ ] 런타임 빌드에 에디터 코드 미포함
- [ ] 자동화 전후 작업 시간 비교
- [ ] 사람이 결과 샘플을 직접 확인
