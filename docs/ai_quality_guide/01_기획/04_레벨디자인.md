# 기획 / 레벨디자인

> 범위: 맵 구조, 경로, 배치, 난이도 곡선, 스테이지 흐름. 맵 아트는 [../02_아트/05_2D배경_타일](../02_아트/05_2D배경_타일.md), 수치 곡선은 [05_밸런스_경제](05_밸런스_경제.md)에서 다룬다.
> 함께 볼 파일: [02_컨텐츠](02_컨텐츠.md), [07_UX_온보딩](07_UX_온보딩.md), [../06_QA/03_재미지표_플레이테스트](../06_QA/03_재미지표_플레이테스트.md)

## 1. 이 파트에서 AI 티가 나는 이유
AI가 만든 레벨은 대칭적이고 균일하다. 경로는 S자, 방은 격자, 적은 고르게 뿌려진다.
AI는 맵을 걸어보지 못한다. 시야, 동선, 긴장과 휴식의 리듬을 숫자 없이는 판단하지 못한다.
결과는 "그릴 수는 있는데 플레이해보면 밋밋한" 맵이다.

## 2. AI 티 패턴
| 패턴 | 왜 티가 나나 | 대신 이렇게 | 출처 |
|---|---|---|---|
| 좌우 대칭, 반복 격자 구조 | 생성 기본값 | 레벨마다 의도한 비대칭 지점 하나를 정한다 | `[영상]` 비대칭 원칙 응용 |
| 적·자원이 맵에 고르게 분포 | 균등 분배가 기본값 | 밀도 그래프를 먼저 그리고 고점과 쉼표를 정한다 | `[실무]` |
| 난이도가 직선으로 상승 | 선형 증가가 기본값 | 상승 → 짧은 휴식 → 더 큰 상승의 톱니 곡선 | `[실무]` |
| 스테이지마다 색만 바꾼 같은 구조 | 테마 = 색상 교체로 처리 | 테마마다 새 규칙이나 지형 요소 하나를 넣는다 | `[실무]` |
| 의도 설명 없이 맵 그림만 있음 | 결과물만 생성 | 맵마다 "플레이어에게 가르치는 것" 한 줄 | `[실무]` |
| 테마가 바뀌면 화풍이 깨짐 | 레퍼런스가 한 테마 기준 | 테마 사이 중간 레퍼런스를 만든다 | `[영상]` |

## 3. 작업 전에 정할 것 (프로젝트 설정값)
값은 [프로젝트 설정](../00_공통/03_프로젝트설정_템플릿.md)에 적는다.
- 맵 크기 단위 (타일 수, 화면 수)
- 플레이어 이동 속도와 시야 범위
- 스테이지 길이 목표 (분)
- 난이도 곡선 형태와 쉼표 간격
- 스테이지별 새 요소 도입 순서

## 4. 작업 규칙
1. **목적부터 쓴다.** 맵마다 "이 맵이 가르치는 것" 또는 "이 맵이 시험하는 것" 한 줄. `[실무]`
2. **흐름을 그래프로 그린다.** 시간(또는 거리)에 따른 위협 밀도를 그린다. 고점, 쉼표, 보상 지점을 표시한다. `[실무]`
3. **화이트박스로 먼저 확인한다.** 아트 없이 회색 블록으로 동선과 시야를 본다. 아트는 구조가 확정된 뒤에 올린다. `[실무]`
4. **AI에게는 수치 조건을 준다.** "경로 길이 40~50타일, 직선 구간 최대 8타일, 교차 지점 2곳"처럼 쓴다. 검증할 수 있는 조건이어야 AI가 스스로 다시 고친다. `[영상]`
5. **봇으로 측정한다.** 봇이 걸린 시간, 이동한 칸 수, 피해량을 지표로 만든다. AI는 이 지표로 판단한다. `[영상]`
6. **후보를 비교한다.** 같은 목적의 맵을 2~3안 만들어 비교 이미지나 플레이 영상으로 나란히 본다. `[영상]`
7. **테마 전환은 중간 레퍼런스로.** 바다 → 불처럼 테마가 크게 바뀌면 사이 테마의 레퍼런스를 하나 더 만든다. `[영상]`

## 5. 금지
| 금지 | 이유 | 예외 |
|---|---|---|
| 목적 한 줄 없는 맵 | 존재 이유 없음 | 없음 |
| 화이트박스 확인 전 아트 작업 | 구조 수정 시 아트 낭비 | 아트가 곧 규칙인 퍼즐 |
| 이유 없는 완전 대칭 | 기본값 티 | 대칭이 규칙인 대전 맵 |
| 색만 바꾼 스테이지 재사용 | 플레이어가 반복으로 느낌 | 의도된 하드 모드 재방문 |

## 6. 요청서 예시
```
[목표] 타워디펜스 3스테이지 경로 후보 3안
[맥락] 이 스테이지가 가르치는 것: 경로 교차점에 범위 타워를 두는 법
[조건] 15x9 타일. 경로 길이 40~50. 직선 최대 8. 교차 1곳. 입구 1, 코어 1.
[금지] 좌우 대칭, 직선 경로
[산출물] 안마다 ASCII 격자 + 경로 길이/직선 최대/교차 수 자동 계산 결과
[검증] 조건을 벗어나면 스스로 다시 만든다
```
```
[목표] 플랫포머 1-3 난이도 흐름 검토
[입력] 구간별 봇 사망 위치 로그
[요청] 사망이 몰리는 구간과 쉼표 없이 고점이 이어지는 구간을 표로. 수정안은 2개까지.
```

## 7. 검증 체크리스트
- [ ] 맵마다 목적 한 줄이 있다
- [ ] 위협 밀도 그래프에 고점과 쉼표가 있다
- [ ] 수치 조건(길이, 직선, 교차 등)을 자동 계산으로 확인했다
- [ ] 화이트박스 상태로 사람이 플레이했다
- [ ] 봇 지표(시간, 이동 칸, 피해)를 기록했다
- [ ] 테마가 바뀌는 스테이지에서 화풍이 이어진다 (스크린샷 나란히)
