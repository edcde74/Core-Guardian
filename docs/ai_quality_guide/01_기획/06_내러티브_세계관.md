# 기획 / 내러티브·세계관

> 범위: 세계관 설정, 캐릭터 설정, 이야기 구조, 진행에 따른 서사 배치. 문장 자체의 품질은 [../05_텍스트/02_스토리텍스트](../05_텍스트/02_스토리텍스트.md)에서 다룬다.
> 함께 볼 파일: [02_컨텐츠](02_컨텐츠.md), [../05_텍스트/03_용어집](../05_텍스트/03_용어집.md), [../02_아트/01_아트디렉션_스타일가이드](../02_아트/01_아트디렉션_스타일가이드.md)

## 1. 이 파트에서 AI 티가 나는 이유
AI에게 세계관을 부탁하면 고대 문명의 멸망, 선택받은 자, 봉인된 힘, 어둠의 세력이 나온다.
설정은 길고 고유명사는 많은데, 그 설정이 게임 플레이와 연결되지 않는다.
플레이어는 몇 줄 읽고 "AI가 쓴 판타지"라고 넘긴다.

## 2. AI 티 패턴
| 패턴 | 왜 티가 나나 | 대신 이렇게 | 출처 |
|---|---|---|---|
| 고대 문명 멸망 / 선택받은 자 / 봉인 | 판타지 기본값 | 게임의 핵심 동사가 왜 필요한지에서 설정을 시작한다 | `[실무]` |
| 설정 문서는 긴데 플레이에 안 나옴 | 분량으로 깊이를 흉내냄 | 설정마다 "플레이어가 어디서 보거나 겪나"를 적는다 | `[실무]` |
| 고유명사 남발 | AI가 이름 생성을 좋아함 | 고유명사 수를 정하고 용어집으로 관리한다 | `[실무]` |
| 캐릭터 말투가 다 비슷함 | 같은 기본 톤 | 캐릭터마다 말버릇, 금지 단어, 문장 길이를 정한다 | `[실무]` |
| "조용히 ~했다", "A가 아닌 B" 같은 문형 | AI가 즐겨 쓰는 표현 | [../05_텍스트/02_스토리텍스트](../05_텍스트/02_스토리텍스트.md)의 금지 문형을 적용 | `[영상]` |
| 번역투 설정 문장 | AI가 지적인 톤을 흉내냄 | 소리 내 읽어 자연스러운 문장으로 다시 쓴다 | `[영상]` |

## 3. 작업 전에 정할 것 (프로젝트 설정값)
값은 [프로젝트 설정](../00_공통/03_프로젝트설정_템플릿.md)에 적는다.
- 서사 비중 (없음 / 배경 / 중심)
- 이야기를 전달하는 수단 (컷신, 대사, 아이템 설명, 환경, 없음)
- 플레이어 캐릭터의 동기 한 줄
- 톤 3단어와 금지 톤
- 고유명사 최대 수
- 캐릭터별 말투 카드

## 4. 작업 규칙
1. **플레이에서 시작한다.** "플레이어는 왜 이 행동(배치, 탐험, 전투)을 반복하나"에 답하는 설정을 먼저 쓴다. `[실무]`
2. **설정에 노출 위치를 붙인다.** 설정 한 줄마다 플레이어가 그것을 보는 곳(대사, 툴팁, 배경 소품)을 적는다. 노출 위치가 없는 설정은 따로 둔다. `[실무]`
3. **게임 맥락을 다 준다.** AI에게 장르, 톤, 핵심 동사, 금지 클리셰를 같이 넘긴다. 맥락 없이 요청하면 기본값이 나온다. `[영상]`
4. **말투 카드를 만든다.** 캐릭터마다 1인칭, 어미, 말버릇, 쓰지 않는 단어, 평균 문장 길이. `[실무]`
5. **고유명사는 용어집에 먼저 등록한다.** 표기, 뜻, 첫 등장 위치. 번역할 때도 이 표를 쓴다. `[영상]` 용어집 원칙
6. **사람이 소리 내 읽는다.** 번역투와 AI 문형은 소리 내 읽으면 잘 걸린다. `[실무]`

## 5. 금지
| 금지 | 이유 | 예외 |
|---|---|---|
| 기본 클리셰(선택받은 자, 봉인, 고대 멸망)를 그대로 사용 | AI 티 | 의도적으로 비트는 경우, 비트는 방식을 명시 |
| 노출 위치 없는 설정을 본문에 포함 | 문서만 길어짐 | 부록으로 분리 |
| 용어집에 없는 고유명사 | 표기 흔들림 | 없음 |
| 모든 캐릭터 같은 말투 | 개성 없음 | 없음 |

## 6. 요청서 예시
```
[목표] 2D 액션 로그라이크 세계관 후보 3안, 안마다 5줄
[맥락] 핵심 동사: 같은 탑을 반복해서 오른다. 톤: 건조함, 블랙유머, 따뜻한 끝. 서사 비중: 배경.
[전달 수단] 아이템 설명 1~2줄, 층 사이 짧은 대사
[금지] 선택받은 자, 봉인된 힘, 고대 문명 멸망, 어둠의 세력. "조용히", "A가 아닌 B" 문형
[형식] 안마다 "왜 탑을 반복해 오르나" 한 줄 + 설정 4줄(각각 노출 위치 표기)
```

## 7. 검증 체크리스트
- [ ] 반복 행동의 이유가 설정 안에 있다
- [ ] 설정마다 노출 위치가 적혀 있다
- [ ] 고유명사가 정한 수 이하이고 모두 용어집에 있다
- [ ] 캐릭터별 말투 카드가 있고 대사가 그것을 따른다
- [ ] 금지 클리셰와 금지 문형이 없다
- [ ] 사람이 소리 내 읽어 번역투를 걸렀다
