# 기획 / 컨텐츠

> 범위: 시스템 위에 올라가는 개별 요소(유닛, 적, 아이템, 스킬, 스테이지 테마, 이벤트)의 목록과 설계. 시스템 구조는 [01_시스템](01_시스템.md), 맵 구성은 [04_레벨디자인](04_레벨디자인.md)에서 다룬다.
> 함께 볼 파일: [03_전투](03_전투.md), [08_데이터테이블](08_데이터테이블.md), [../05_텍스트/03_용어집](../05_텍스트/03_용어집.md)

## 1. 이 파트에서 AI 티가 나는 이유
AI에게 "아이템 30개 만들어줘"라고 하면 개수는 채우지만 서로 비슷하다.
불·얼음·번개 3속성, 공격력/공속/치명타 수치만 다른 변형, "고대의", "그림자의" 같은 접두어가 반복된다.
컨텐츠 하나하나가 플레이를 바꾸지 않고 숫자만 바꾼다. 플레이어는 금방 눈치챈다.

## 2. AI 티 패턴
| 패턴 | 왜 티가 나나 | 대신 이렇게 | 출처 |
|---|---|---|---|
| 불/얼음/번개/독 4속성 기본 세트 | 판타지 기본값 | 세계관과 핵심 동사에서 속성을 끌어낸다. 속성이 꼭 필요한지부터 묻는다 | `[실무]` |
| 수치만 다른 변형(+10%, +15%, +20%) | 개수 채우기 | 컨텐츠마다 "플레이어 행동을 어떻게 바꾸나" 한 줄을 쓴다 | `[실무]` |
| "고대의", "심연의", "그림자의" 접두어 반복 | AI가 선호하는 판타지 어휘 | 이름 규칙과 금지 어휘를 정한다 | `[실무]` |
| 효과 설명 단어가 매번 바뀜(화상 → 불에 덴다 → 뜨거운 것에 닿는다) | 같은 개념을 다른 말로 씀 | 용어집을 만들고 효과 문구는 용어집 단어만 쓴다 | `[영상]` |
| 모든 적이 "체력 많음/빠름/원거리" 3분류 | 기본 원형 | 적마다 플레이어에게 요구하는 대응 하나를 정한다 | `[실무]` |
| 컨텐츠 수가 많을수록 좋다는 전제 | 분량으로 완성도를 흉내냄 | 시스템별 필요한 최소 수를 정하고, 그 안에서 겹치지 않게 | `[실무]` |

## 3. 작업 전에 정할 것 (프로젝트 설정값)
값은 [프로젝트 설정](../00_공통/03_프로젝트설정_템플릿.md)에 적는다.
- 컨텐츠 종류별 목표 개수 (출시 시 / 업데이트당)
- 컨텐츠를 구분하는 축 2개 (예: 사거리 × 대상 수, 이동 방식 × 위협 방식)
- 이름 규칙 (길이, 어휘 톤, 금지 어휘)
- 효과 태그 목록 (용어집과 같은 단어)
- 컨텐츠가 해금되는 순서

## 4. 작업 규칙
1. **축을 먼저 그린다.** 구분 축 2개로 표(매트릭스)를 만들고 빈칸을 채우는 방식으로 컨텐츠를 만든다. 같은 칸에 두 개가 들어가면 하나는 뺀다. `[실무]`
2. **역할 한 줄을 쓴다.** "이 적은 플레이어가 배치를 앞쪽으로 당기게 만든다"처럼 행동 변화로 쓴다. 수치 설명은 역할이 아니다. `[실무]`
3. **효과는 태그로 쓴다.** 효과 문구는 용어집의 태그 단어만 쓴다. 새 효과가 생기면 용어집에 먼저 추가한다. `[영상]`
4. **AI에게 기존 목록을 넘긴다.** 새 컨텐츠를 요청할 때 기존 목록과 매트릭스를 같이 준다. "기존과 역할이 겹치면 제외"를 조건으로 건다. `[실무]`
5. **한 번에 조금씩 만든다.** 30개를 한 번에 받지 말고 3~5개씩 받아 검토한다. 규칙이 틀렸으면 여기서 고친다. `[영상]`
6. **사람이 고른다.** AI 후보는 `제안`으로 두고 사람이 고른 것만 `확정`으로 옮긴다. `[실무]`

## 5. 금지
| 금지 | 이유 | 예외 |
|---|---|---|
| 수치만 다른 변형을 별개 컨텐츠로 계산 | 개수만 늘어남 | 강화 단계처럼 시스템이 변형을 요구할 때 |
| 용어집에 없는 효과 단어 | 플레이어가 같은 효과인지 알 수 없음 | 없음. 용어집에 먼저 추가 |
| 금지 어휘 접두어 반복 | AI 티 | 세계관 고유명사로 정한 경우 |
| 역할 한 줄 없는 컨텐츠 | 존재 이유가 없음 | 없음 |

## 6. 요청서 예시
```
[목표] 로그라이크 유물 후보 5개
[맥락] 핵심 동사: 근접 회피. 축: 발동 조건(회피/피격/처치) × 효과 대상(자신/적/지형)
[입력] 기존 유물 표(첨부), 효과 태그 목록(첨부)
[조건] 기존과 같은 칸 금지. 효과 문구는 태그 단어만. 접두어 "고대의/심연의/그림자의" 금지
[형식] 이름 / 칸 / 역할 한 줄(플레이어 행동 변화) / 효과 문구
[검증] 역할이 수치 변화만이면 제외하고 다시 만든다
```

## 7. 검증 체크리스트
- [ ] 매트릭스의 같은 칸에 두 개 이상 없다
- [ ] 모든 컨텐츠에 행동 변화로 쓴 역할 한 줄이 있다
- [ ] 효과 문구가 용어집 단어만 쓴다
- [ ] 이름이 이름 규칙과 금지 어휘를 지킨다
- [ ] 이름만 보고 두 컨텐츠를 헷갈리지 않는다
- [ ] 사람이 실제 플레이에서 새 컨텐츠가 선택을 바꾸는지 확인했다
