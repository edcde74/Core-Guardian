# AI 게임 개발 품질 가이드

AI로 만들지만 AI처럼 보이지 않게 하기 위한 파트별 작업 기준이다. 특정 게임에 묶이지 않도록 썼고, 어느 프로젝트에서든 이 폴더를 통째로 복사해 쓴다.

## 쓰는 법

1. 작업을 시작하기 전에 [00_공통/01_공통원칙.md](00_공통/01_공통원칙.md)를 한 번 읽는다.
2. 이번 작업에 해당하는 세부 파트 파일만 연다. 여러 파트에 걸치면 해당 파일을 모두 적용한다.
3. 파일의 "프로젝트 설정값" 칸은 프로젝트마다 다르다. 새 프로젝트에 복사하면 [00_공통/03_프로젝트설정_템플릿.md](00_공통/03_프로젝트설정_템플릿.md)를 먼저 채운다.
4. 결과물은 파일 끝의 "검증 체크리스트"를 통과해야 완료로 본다.
5. 새로 알게 된 AI 티 패턴은 해당 파일의 "AI 티 패턴" 표에 추가한다. 출처(영상, 직접 경험, 피드백)를 함께 적는다.

- `[실무]` 일반적인 게임 개발 실무 기준. 영상에 없는 내용을 보충한 것이다.
- `[프로젝트]` 실제 프로젝트에서 확인한 내용. 직접 추가한다.

## 이 가이드가 프로젝트 규칙과 부딪힐 때

프로젝트 자체의 작업 규칙(AGENTS.md, CLAUDE.md, 보호 규칙 등)이 항상 우선한다. 이 가이드는 결과물의 품질 기준이고, 승인 절차나 작업 범위를 바꾸지 않는다.
