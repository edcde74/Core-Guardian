## 1. 이 파트에서 AI 티가 나는 이유
마케팅 이미지를 AI로 따로 그리면 실제 게임 화면과 화풍이 달라진다. 플레이어는 스크린샷과 실제 플레이가 다르면 바로 알아채고, 이것을 AI 과장 광고로 받아들인다. 트레일러도 AI 기본값(에픽 음악, 슬로모션, 빛 번짐)으로 만들면 어디서 본 듯한 영상이 된다. `[실무]`

## 2. AI 티 패턴
| 패턴 | 왜 티가 나나 | 대신 이렇게 | 출처 |
|---|---|---|---|
| 게임에 없는 장면을 AI로 그린 스크린샷 | 실제와 달라 신뢰 하락 | 실제 게임 화면만 쓴다 | `[실무]` |
| 캡슐 아트 화풍이 게임과 다름 | 다른 게임처럼 보임 | 게임 레퍼런스로 그리고, 게임 에셋을 재사용 | `[실무]` |
| 캡슐에 글로우·렌즈플레어·보라 그라데이션 | AI 기본값 | 게임 팔레트만 | `[영상]` |
| 트레일러 첫 5초가 로고·분위기 컷 | 이탈 | 첫 3초 안에 실제 플레이 | `[실무]` |
| 에픽 합창 음악 | AI 트레일러 기본값 | 게임 실제 BGM 또는 같은 편성 | `[실무]` |
| UI를 숨긴 채 연출 컷만 | 게임 방식이 안 보임 | 핵심 UI가 보이는 컷 포함 | `[실무]` |
| 스크린샷 비율·해상도 제각각 | 스토어에서 잘림 | 규격을 정해 일괄 촬영 | `[영상]` |

## 3. 작업 전에 정할 것 (프로젝트 설정값)
- 스토어별 규격 (스크린샷 해상도·비율, 캡슐 크기별 규격). 스토어 공식 문서에서 최신 값 확인
- 쇼츠·SNS용 세로 비율(9:16) 여부
- 대표 장면 목록 (핵심 판매 포인트와 1:1)
- 트레일러 길이 (예: 30초 / 60초)
- 사용 BGM
- 촬영용 빌드 설정 (디버그 UI 끄기, 고정 시드, 카메라 위치)

## 4. 작업 규칙
1. 판매 포인트마다 증명하는 장면을 정한다. 장면 없는 판매 포인트는 빼거나 장면을 만든다.
2. 촬영용 설정을 만든다. 디버그 표시를 끄고, 같은 상황을 재현할 수 있게 시드와 카메라를 고정한다.
3. 스크린샷은 정해진 규격으로 자동 촬영하게 한다. 비율별 크롭도 자동화한다. `[영상]`
4. 후보를 여러 장 찍어 나란히 비교해 고른다. `[영상]`
5. 캡슐 아트는 게임 레퍼런스와 실제 에셋을 기반으로 만든다. AI로 만들었다면 게임 화면 옆에 놓고 화풍을 비교한다.
6. 캡슐 위 글자(게임 제목)는 이미지에 구워 생성하지 않고 폰트·로고 파일로 얹는다. `[영상]`
7. 트레일러는 첫 3초에 실제 플레이, 이후 판매 포인트 순서로 편집한다. 효과음과 BGM은 실제 게임 사운드를 쓴다.
8. 쇼츠용은 세로로 다시 구성한다. 가로 영상을 그냥 자르면 핵심이 잘린다.

### 트레일러 구성 예 (60초) `[실무]`
| 구간 | 길이 | 내용 |
|---|---|---|
| 1 | 0~3초 | 가장 화려한 실제 플레이 컷 |
| 2 | 3~15초 | 기본 규칙이 보이는 플레이 |
| 3 | 15~40초 | 판매 포인트 3개, 각 6~8초 |
| 4 | 40~55초 | 물량·보스 등 절정 장면 |
| 5 | 55~60초 | 제목, 출시 정보, 위시리스트 안내 |

### 스크린샷 순서 `[실무]`
- 첫 2장은 썸네일로 노출되므로 핵심 플레이 장면으로 한다.
- 메뉴·설정 화면은 넣지 않는다.
- 같은 맵·같은 시점만 반복되지 않게 장면을 섞는다.

### 자주 하는 실수
- 개발 중 빌드로 찍은 스크린샷이 출시 빌드와 달라진다. 출시 직전에 다시 찍는다.

## 5. 금지
| 금지 | 이유 | 예외 |
|---|---|---|
| 게임에 없는 장면 | 허위 광고 인상 | "컨셉 아트"라고 명시 |
| 캡슐에 AI가 생성한 글자 | 글자 깨짐, 수정 불가 | 없음 |
| 디버그 UI·개발용 표시가 보이는 컷 | 미완성 인상 | 개발 로그 영상 |
| 규격 미확인 업로드 | 잘림, 반려 | 없음 |
| 저작권 불명확한 음악 | 영상 차단 | 라이선스 확인 |

## 6. 요청서 예시
```
[목표] 스팀 스크린샷 6장 자동 촬영 스크립트
[장면] 판매 포인트 3개 x 2장. 장면별 시드, 카메라 위치, 웨이브 번호 표 첨부
[규격] 1920x1080 PNG, 디버그 UI 끄기, 같은 장면을 16:9와 9:16 크롭으로 각각 저장
[검증] 6장을 한 장에 모은 비교 이미지와 파일 목록 제출
```

## 7. 검증 체크리스트
- [ ] 모든 이미지·영상이 실제 게임 화면이다 (컨셉 아트는 표시)
- [ ] 규격이 스토어 최신 기준과 같다
- [ ] 디버그 표시가 보이지 않는다
- [ ] 캡슐 화풍이 게임 화면과 같다 (나란히 비교)
- [ ] 트레일러 첫 3초 안에 플레이가 나온다
- [ ] 음악·효과음 라이선스를 확인했다
- [ ] 썸네일 크기로 줄여도 무슨 게임인지 보인다 (사람 판단)
