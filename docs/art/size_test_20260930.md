# 첫 인게임 아트 크기 비교 — 2026-09-30

현재 노션의 큰 픽셀·단순한 형태 방향으로 생성한 시험 스프라이트를 Unity Game 화면에 실제 배치했다. 외형·색상·픽셀 해상도·크기와 배치는 최종 승인된 사항이 아니다.

## 실제 비교
같은 D 경로, 같은 정사영 카메라(orthographicSize 8.5), 같은 1920×1080 캡처 조건에서 스프라이트 크기만 변경했다.

| 후보 | 스프라이트 배율 | 기술병 높이 | 타일 대비 기술병 높이 |
|---|---:|---:|---:|
| A 작은 크기 | 2/3 | 약 64 px | 1칸 |
| B 중간 크기 | 1 | 약 95 px | 1.5칸 |
| C 큰 크기 | 4/3 | 약 127 px | 2칸 |

유닛·포탑·코어는 같은 배율로 변경한다. 바닥과 카메라는 유지한다. 적 3종 및 적 6명 군집을 표시한다. 군집은 정적인 외형 비교용이며 실제 라운드 편성·이동·공격·충돌 범위를 의미하지 않는다.

기존 SampleScene과 기존 임시 아트는 교체하지 않았다. 비교 씬은 SampleScene의 복사본에 새 아트를 넣었고, 기존 플레이어 이동 컴포넌트는 비교 씬에서도 사용한다. 비교 씬의 기술병은 WASD 입력으로 움직일 수 있다. 새 적·포탑·코어는 SpriteRenderer 기반 외형 표시만 한다.

## 픽셀 처리
생성 원본을 알파 경계로 자르고 Unity에서 최근접 샘플링해 시험 해상도를 만들었다. 알파 128 미만은 투명하게 처리했다. Point 필터, 밉맵 없음, 무압축, 시험 PPU 32를 적용했다. URP의 Sprite-Unlit 재질로 표시한다.

기술병 36×48, 공격형 높이 64, 수비형 높이 48, 군기형 높이 96, 단일 포탑 높이 64, 범위 포탑 높이 56, 지원 포탑 높이 64, 코어 높이 96, 바닥·경로 32×32가 첫 시험값이다. 생성 이미지의 세부 스타일과 픽셀 밀도 차이를 최종 생산 규격으로 취급하지 않는다. 카메라의 최종 Pixel Perfect 설정과 기준 해상도는 아직 확정하지 않았다.

## 현재 관찰
- 세 포탑의 단일 포신·세 발사구·열린 고리 형상은 구별된다.
- 적은 창·넓은 방패·높은 군기로 구별되지만 군기형의 높이와 적 갑옷의 잔무늬는 추가 조정 대상이다.
- 큰 크기는 군집에서 겹침이 늘어난다.
- 중간 크기를 Unity에서 먼저 보도록 열어 두었다. 이는 크기 승인이나 최종 선택이 아니다.

다음 사용자 검토에서 크기 후보 또는 개체별 조정값을 선택한 뒤 반복한다. 승인 전에는 노션에 최종 규격을 기록하지 않는다.
