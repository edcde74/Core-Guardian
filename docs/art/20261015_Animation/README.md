# 방향별 2D 애니메이션

2026-10-15. imagegen 기본 내장 도구로 생성하고 Unity C# 도구로 저해상도 정규화·팔레트 제한·아틀라스 조립을 수행했다. 기존 병사/기술병/포탑/보스 원본 PNG와 프리팹을 보존했다. 사용자가 요청한 제작·연결이며 **새 프레임의 화풍·자연스러움 최종 사람 승인을 의미하지 않는다.**

## 생성 입력과 최종 프롬프트 사양

각 `_raw.png`는 생성 원본이다. 고해상도 생성 이미지 자체를 게임 픽셀 규격으로 승인하지 않았다. 현재 병사의 사선 3/4 시점·작은 투구·길고 가는 다리·각진 철갑/붉은 천·큰 명암 면을 기준으로 삼았다.

공통 요청은 투명 배경, 셀마다 동일 크기/발 기준, 장비 잘림 방지, 낮은 픽셀 밀도·원래 팔레트·어두운 외곽선, 배경/그림자/문자/격자/그라데이션/안티앨리어싱 제외였다. Player_raw는 먼저 만든 4방향 이력이며 현재 게임은 Player8_raw 파생 8방향을 사용한다.

## 기술 정규화

`PrepareAnimationAssets.cs`는 셀을 분리하고 고립 잡픽셀 제거, Nearest 샘플링, 기준 원본 팔레트에 최근접 색 매핑, 96×112 공통 셀의 피벗(48,8)을 사용한다. 참조 불투명 높이는 공격형64/수비형48/버프형80/보스66/기술병48px다. 포탑은 받침대와 상부를 별도 셀로 나눈다. Point·무압축·mipmap 없음·PPU32 런타임 Sprite를 사용하며 카메라/전 게임 기준 해상도는 변경하지 않았다.

현재 결과는 같은 팔레트·픽셀 격자·상대 크기로 기술 비교했다. 방향별 장비 윤곽과 체형에는 새로 그린 차이가 있으므로 기존 아트 승인과 이번 프레임의 최종 사람 검토를 구분한다.
