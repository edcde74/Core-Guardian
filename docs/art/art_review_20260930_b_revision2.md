# B 크기 아트 화면 검토 — 수정 2

사용자 선택: 세 크기 중 B(2번)를 다음 비교의 기준으로 사용한다. 기술병과 포탑 외형은 유지한다.

- 병사 3종: 잔인한 분위기를 줄이고 짧은 비율, 회색 갑옷과 붉은 천으로 정리. 창·방패·군기로 구별한다.
- 석재 바닥: 64×64 픽셀의 넓은 면을 4개의 32×32 타일로 나눠 기존 격자에 배치.
- 경로: 직선 32×48, 모서리 48×48 픽셀, PPU 32. 화면상 폭 1.5칸으로 비교한다.
- ㄱ자 모서리: 북쪽·동쪽 출구 기본형을 90도씩 회전. 실제 경로의 7곳에 적용. 직선 52개.
- 스프라이트 Point, 무압축, mipmap 없음. 수치는 검토용이며 최종 제작 규격이 아니다.

저장 후 씬을 다시 열어 바닥 4종·직선 1종·모서리 1종의 참조가 유지되는 것을 확인하고 Play 모드 캡처에서 표시를 확인했다. 병사·포탑은 크기 비교용 정적 배치이며, 기존 플레이어 이동은 유지한다. 경로의 시각적 폭과 기존 통행 판정 폭은 다르므로 실제 플레이용 폭은 별도 검토가 필요하다.

다음 판독: 병사의 분위기가 기술병과 맞는지, 바닥 반복 무늬가 강한지, 모서리 내부 이음선이 자연스러운지 사용자가 실제 화면에서 비교한다. 최종 아트 승인과 실제 레벨 배치 확정은 아직 하지 않았다.
