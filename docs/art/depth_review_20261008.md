8종 아트 프리팹: Player, enemy_attack, enemy_defense, enemy_buff, tower_single, tower_multi, tower_support, core. 위치: `Assets/Art/ScreenTests/20261008_Depth/Prefabs/`. 씬에는 14개 인스턴스가 배치되어 있다.

```
GameObject (발/받침대 중앙)
├─ 2D Sprite
├─ 그림자
│  ├─ 바깥 그림자
│  ├─ 접촉 그림자
│  └─ 바닥 밀착선
└─ 바닥 수정빛 (코어만)
```

`그림자`를 끄면 그림자 전체를 비교할 수 있다. 사용자 피드백 후 바깥 그림자의 옆 방향 오프셋을 제거했다. 무기·군기를 포함한 전체 스프라이트 폭 대신 하단 불투명 영역의 실제 발/받침대 폭을 측정해 타입별 그림자를 맞췄다. 접촉부는 진하게, 외곽은 옅게 둔다. `바닥 밀착선`은 원본 하단 접촉 영역을 별도 Sprite로 참조해 검게 눌러 그린 것으로, 바닥과 닿는 실제 형태를 따른다. 신규 비교용 타원 스프라이트는 Point 필터, 압축 없음, mipmap 없음으로 저장했다. 현재 프로젝트는 URP다.

추가 기법: `ArtDepthSorting`이 발/받침대의 화면 Y 위치에 따라 본체 앞뒤 겹침을 조정한다. 모든 바닥 그림자는 본체 아래에 표시한다. 코어의 청록빛은 바닥용 반투명 스프라이트이며 실시간 광원이나 노멀맵 효과는 아니다.

플레이어는 기존 이동 루트 아래 `PlayerArt` 프리팹을 붙여 이동과 아트 구조를 분리했다. 기존 이동 코드와 씬의 Tilemap 참조를 유지한다.

검증: 컴파일 오류/경고 0. 14개 인스턴스의 프리팹 연결과 Sprite/그림자 구조, 발/받침대 중앙 정렬 확인. 실제 플레이에서 한 칸 이동 후 아트와 그림자가 같은 위치를 따라가며 Y 정렬이 갱신되는 것 확인. 저장·씬 재열기 후 검증 통과.
