# 전투 효과 아트·색감·타이포그래피 기준

노션: https://www.notion.so/3f4389dbfc688118965ecb7a1ffaaf3c

# 역할
채택한 전투 효과의 형태·색감·타이포그래피와 실제 화면 판독 기준을 관리합니다. 세계관과 유닛 외형은 [담당 기획서](https://www.notion.so/3ea389dbfc6881dca4d6fe9ca0b35058), 제작 순서는 [담당 기획서](https://www.notion.so/3f3389dbfc6881d2a70be916ded8ddb7)에서 관리합니다.
# 채택 방향
- 사용자 선택: B 보강 금속 스파크, 기술병 E2 금속 부품 탄, 피해 숫자 Pixelify Sans Bold.
- 낡은 회색 석재 위에 새로 덧댄 금속과 수정 장치가 작동하는 인상입니다. 황동·짙은 금속·청록 수정과 짧은 사각 스파크를 사용합니다.
- 큰 픽셀과 단순한 외곽 형태를 우선합니다. 길게 번지는 안개·과한 광량·큰 폭발이 전장 판독을 덮지 않게 합니다.
- 기존 기술병·적·포탑·코어의 외형과 승인된 60% 비교 크기를 유지합니다. 신규 효과가 캐릭터를 다른 무기나 설비로 바꾸지 않습니다.

# 타이포그래피
- 선택 폰트는 Pixelify Sans Bold입니다. 현재 숫자·부호용 정적 Bold 700 원본을 TMP로 변환해 적용했습니다.
- 피해는 크림색, 골드는 금색, 코어 피해는 붉은색으로 구분하고 공통 어두운 외곽선을 사용합니다.

<tr><td>현재 표시</td><td>실행 색상</td><td>용도</td></tr>
<tr><td>피해 숫자</td><td>#FFF0AD</td><td>적의 피해 결과</td></tr>
<tr><td>획득 숫자</td><td>#FFC238</td><td>골드 획득</td></tr>
<tr><td>코어 감소 숫자</td><td>#FF5C52</td><td>코어 피해</td></tr>
<tr><td>공통 외곽선</td><td>#0E1216</td><td>밝은 바닥·어두운 갑옷 양쪽에서 대비 확보</td></tr>
</table>
- 위 HEX는 현재 실행 색을 8비트로 정리한 값입니다. 숫자는 현재 1920×1080 기준 Canvas에서 32 크기로 사용합니다. 전 게임의 최종 기준 해상도나 글자 크기를 확정하는 규칙이 아닙니다.
- Pixelify Sans는 한국어를 지원하지 않아 한글 HUD는 기존 글꼴을 유지합니다. 최종 한글 HUD 글꼴은 별도 선택 항목입니다.
- 원본 TTF와 SIL OFL 1.1 전문을 프로젝트에 동봉합니다. [공식 폰트 배포](https://github.com/google/fonts/tree/main/ofl/pixelifysans).
- 표시 값·발생 시점·입력 동작은 [담당 기획서](https://www.notion.so/3df389dbfc68811f9a87e5a5ff05a571)에서 관리합니다.
# 정렬·판독 체크
- 기술병·적은 발밑, 포탑·코어는 받침대 접촉 중심을 유지합니다. 창·군기·포신을 포함한 이미지 전체 중심으로 재정렬하지 않습니다.
- 버프 표식은 개체 윗부분에 작게 표시하며 체력 막대·숫자·긴 군기와의 겹침을 점검합니다.
- 다수 명중 시 숫자끼리, 골드와 피해 숫자끼리 겹쳐 읽기 어려운지 실제 전투에서 확인합니다.
- 이동하는 탄은 진행 방향을 따릅니다. 작은 게임 화면에서 황동 부품과 두 청록 탄을 구별할 수 있어야 합니다.
- 그림자·밀착선 상세 기준: [담당 기획서](https://www.notion.so/3f3389dbfc6881089b13e5daf7b766a2).

# 제작 상태와 미확정 범위
- 정지 전투 스프라이트 9종, TMP 피해·골드·코어 숫자를 최신 Unity 전투 씬에 적용했습니다.
- 피격·처치의 짧은 표시·사라짐은 연결됐지만 보행·발사·사망의 프레임 애니메이션은 미제작입니다.
- 애니메이션 방향 수·프레임 수·발사 프레임, 최종 픽셀 규격·제한 팔레트·카메라·기준 해상도, 최종 석재 바닥과 한글 HUD 글꼴은 별도 확정합니다.
- 적용·테스트 기록은 [담당 기획서](https://www.notion.so/3df389dbfc6881fc9f1bd004adfc5999)에서 관리합니다.
