담당 편성표: https://www.notion.so/3e6389dbfc6881c5aa2bed3c32047474

- 각 라운드 첫 생성은 전투 시작 0초입니다.

- n번째 시각은 (n-1)×간격입니다. 상세 순서·시점은 `wave_order_confirmed_20261010.json`에 있습니다.
- 기존 유형별 수량·간격을 유지했고, 2~9라운드 141개 일정을 `Assets/Resources/CoreGuardian/waves.csv`에 반영했습니다. 각 일정은 count=1 행으로 기록했습니다.
- 1라운드 기존 행은 유지했습니다. 10·11라운드는 이번 확정 범위에 포함하지 않습니다.
- 원래 `wave_order_proposal_20261010.json`은 승인 전 기록이며 현재 확정본은 `wave_order_confirmed_20261010.json`입니다.
