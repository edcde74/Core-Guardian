다음 최우선 작업은 HUD 사용성 개선이야.
현재 HUD의 픽셀 아트·색감·금속/황동 스타일은 마음에 들어. 하지만 실제 플레이를 가리거나 방해하는 UI가 많아서 표시 구조와 조작 흐름을 상당히 정리하고 싶어.

원하는 방향:
1. 라운드 시작/전투 진입 시 닫거나 간소화할 UI를 정리해.
2. 빈 땅바닥을 클릭하면 닫히는 UI도 필요해. 어떤 패널이 닫히고 어떤 정보는 유지되는지 먼저 제안해.

4. 타워 스펙과 플레이어 스펙을 편하게 확인하는 UI도 필요해. 현재값 확인과 강화 구매를 구분해서 생각하고, 전투를 덜 가리면서 접근하기 쉬운 방식을 제안해.

아직 어떤 패널을 언제 닫을지나 스펙 UI 배치를 확정한 건 아니므로, 시안을 검토받은 뒤 구현해. 기존에 확정한 아트나 피해 HUD 선택은 다시 묻지 마.
