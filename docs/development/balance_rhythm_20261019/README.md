# 초반 성장 공백·시간 예산 조사 · 2026-10-19

## 현재 상태와 근거

**초반에는 재화 때문에 성장 구매가 막히는 구간이 있고, 기존 전투 길이도 새 40분 목표보다 길다.** 다만 구매 불가가 곧 무행동이나 지루함을 증명하지는 않는다. 이동·전투 대응의 재미는 사람 1배속 확인이 필요하다. 시작 HEAD `6c9d43e`.

`core-guardian-balance`와 `headless-game-balance`를 적용했다. 이번은 정적 수급 계산과 기존 8회/88R 기록 재분석이며 새로운 시뮬레이터·정상 전투 실측·사람 플레이가 아니다. Unity 읽기 조회에서 ready/Play stopped/컴파일false·전투씬1/dirtyfalse를 확인했다. 공유 테스트 상태는 completed이며 표시된 사운드19/19는 과거 결과 조회다. 새 테스트 통과로 세지 않는다.

기존 Preflight를 [읽기 전용 조회](ReadCurrent.cs)로 재사용하고 새 출력에 보관했다. 현재 씬 CSV 참조→CombatData.Load를 다시 확인했고 5CSV 해시가 기존8회 원본과 모두 같았다. Session의 초기재화·능력치별 가격 단계·구매 허용 단계·처치 골드·완료 수정을 코드와 대조했다. 실행 중 Session을 새로 진행하지 않았으며 세션 행동은 기존 정상 계측 자료를 사용한다.

정본: [현재 씬/로더 조회](scene_loader.json), [수급·시점 계산](analysis.json), [라운드 CSV](rounds.csv), [계산 코드](analyze.py), [검증](verification.json), [기존 계측](../balance_measurement_20261019/README.md). 최신 Notion [루프](https://www.notion.so/3e6389dbfc68819fbfe5ca17f14460d3)·[재화](https://www.notion.so/3e3389dbfc688160a9b7efcc83505cb3)를 재조회해 약40분/잦은 성장 방향과 기존 가안을 구분했다. 이번에는 Notion을 수정하지 않았다.

첫 포탑 설치 후 1~2R에는 전원 처치해도 골드93/수정40이라 정상 성장 구매가 없다. 8회에서 두 전투의 합계는 게임시간75.08~81.21초였고 준비 체류는 별도다. 골드100 도달의 정확한 초 단위 시각은 원본에 없으므로 추정으로 채우지 않았다.

보스 처치에 성공한 단일 후반 배치+플레이어 이동 조건에서는 첫 플레이어 구매가 게임시간127.19초(4R준비), 추가 설치214.90초(6R준비), 첫 증강 진입541.10초였다. 구매 가능 시점과 준비에서만 구매한 관측 정책을 구분한다. 이 한 회차로 모든 플레이어가9분을 기다린다고 단정하지 않는다.

40분/100R은 준비·증강 포함 평균24초다. 현재 일반 라운드는 마지막 생성만22~26초에 걸쳐 있고 실제 전투는 대체로37~46초였다. 성장 구매만 늘려도 생성 일정 하한은 남는다. 100R 전체를 현재 길이로 외삽한 예측이나 난이도 확정은 하지 않는다. 초반 코어 무손실 또한 이동 없이 모든 배치가 쉽다는 증거가 아니다.

## 원인 가설

1. **관측:** 첫 두 라운드는 정상 구매가 불가능하고 포탑 성장에는4~5전투가 필요하다. **가설:** 독립된 두 재화가 서로 번갈아 성장 결정을 주지 못해 공백이 생긴다. 전투 중 구매와 분산 투자를 해도 선택 공백이 남는지 반증한다.
2. **관측:** 기존 구매 정책은 플레이어 구매도 준비까지 미룬다. **가설:** 실제 가능한 전투 중 성장을 정책이 덜 보여준다. 동일 배치에서 도달 즉시 구매와 준비 구매를 대조한다.
3. **관측:** 생성 일정과 전투 꼬리가 길고 9R 일부 조건은 누수로 길어진다. **가설:** 단순 적 HP 증가나 동일 수량의 간격 압축은 기다림 또는 동시 압박만 키울 수 있다. 마지막 생성 후 정리 시간·누수·피해 기여를 나눠 확인한다.

## 변경 후보 3가지 — 미적용

| 후보 | 기대 효과 | 장점 | 단점·변경 범위 |
|---|---|---|---|
| A. 초반 구매 진입 비용/단계 재설계 | 첫2R/3R준비부터 성장 갈림길 | 초반 공백에 직접 대응, 시작 포탑 설치100은 별도로 유지 가능 | 성장 가속으로 더 쉬워질 수 있음; 플레이어/포탑 첫 단계와 이후 비용 곡선 검토 |
| B. 처치·완료 수입 시점/규모 조정 | 기존 가격으로 이른 구매 가능 | 표시 가격을 유지하며 선택 여력 제공 | 모든 구매·후반 저축·재화 증강에 파급, 과잉 설치 가능; 재화/적 보상 검토 |
| C. 라운드 편성·시간 재설계 | 짧고 밀도 있는 전투와 잦은 결정 | 40분 목표와 장기 성장 리듬에 직접 대응 | 적 수/생성 간격/보상/보스 시간 연결 필요; 단순 간격 축소만으로 해결 불가 |

**추천은 A의 첫 성장 시점을 먼저 비교하고 C를 별도 대조하는 순서다.** A+B를 함께 적용하면 원인과 비용을 분리하기 어렵다. 증강 주기 변경도 별도 축으로 둔다. 조기 증강을 넣는 것만으로 1~2R 구매 공백과 긴 생성 일정을 모두 해결했다고 보지 않는다.

임의 수치를 채택하는 대신 현재 수급이 요구하는 경계를 제시한다. 2R까지 첫 플레이어 강화를 원하면 비용은93골드 이하여야 하고, 3R준비에 첫 포탑 강화를 원하면 비용은40수정 이하여야 한다. 반대로80수정 가격을 유지하면 첫 두 완료 보상의 합이80 이상이어야 한다(추가 설치100이면100 이상). 이는 수학적 조건이며 해당 가격/보상 적용 권고가 아니다. 목표 첫 성장 시점을 먼저 정해 최소 변경 후보를 만든다.
