# 승인 사진 그림자 실제 적용 — 2026-10-18

사용자가 빨간 원4곳 수정 시안을 긍정 평가하고 ‘이대로 그림자 다 적용’을 지시했다. **플레이어·몬스터3종·코어·포탑3종 및 보스의 실제 생성 경로에 연결 완료**했다. 원본 본체/방향별 아트·전투 수치·맵·HUD·선택/강화·발광/반동·사운드는 이 작업에서 수정하지 않았다.

## 적용 구조

- `CoreGuardianPhotoShadow`가 승인된 사진 추출 마스크를 별도 `PhotoCastShadow`로 표시한다. 원본PNG/프리팹/씬 수정 없이 `CoreGuardianUnitAnimation.Attach`에서 모든 신규 유닛/포탑에 연결하며, 코어는 `CoreGuardianCombatAnimation.Configure`에서 연결한다. 설치 커서에는 연결하지 않는다.
- 별도 `Resources/CoreGuardian/PhotoShadows`8종/등록JSON을 사용한다. Point/무압축/mipmap없음/PPU63.52941. [준비 코드](prepare.py)는 승인 합성의 실제 카메라 좌표→월드 등록값을 추출했다. 본체 리소스를 재생성하거나 변경하지 않았다. 보스는 기존 방패병 마스크를 실제 본체 폭에 비례해 사용하며, 보스 외형의 새 아트 승인을 뜻하지 않는다.
- 사진의 오른쪽 덩어리는 지면 루트에 고정된 세계 방향이며 방향전환 때 뒤집거나 회전하지 않는다. 플레이어/병사/보스의 접촉부는 **매 프레임 현재 보이는 본체 분할 프레임 합집합의 하단**을 `PhotoShadowContact` 셰이더로 처리한다. 고정된 발 복제 PNG를 붙이지 않는다. 별도 비활성 `CoreGuardianSelectionOutline` 인스턴스의 합집합만 재사용하며 실제 초록색 선택선 인스턴스와 독립적이다.
- 그림자는 본체 자식 `2D Sprite` 밖에 있다. 바닥order42/동적접촉43으로 본체/선택/강화/별도발광과 분리한다. 기존 포탑 하단5px명암·발광·반동은 유지한다. 기존 접지 클래스/셰이더를 롤백하지 않았다.
- 승인4종 방패병·코어·멀티·지원(+보스)은 교체 대상의 기존 바깥/접촉/짧은투사 그림자를 숨겨 중첩을 막는다. 코어의 별도 `바닥 수정빛`도 승인 수정 시안대로 런타임만 숨긴다. 코어 본체/코어 입자는 보존한다. 다른 승인 개체의 기존 중앙/주변 그림자는 유지한다. 고정발 복제 `바닥 밀착선`은 계속 숨긴다.
