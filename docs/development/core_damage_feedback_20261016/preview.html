코어 피해가 발생한 순간을 또렷하게

현재 코어 원본 + 기존 CoreHit / 감소 숫자 재현. 본체와 상단 코어 표시의 추가 반응을 비교하는 독립 시안입니다.

A · 붉은색 중심

붉은색 혼합 48% → 240ms 복귀.
상단 아이콘·수치도 함께 붉게 반응.

B · 흰색 짧게 → 붉은색

첫 45ms 흰색 혼합 55% → 붉은색 잔상 → 240ms 복귀.
상단 표시도 같은 순서로 반응.

시안 후보값: 본체 240ms / 상단 300ms / 재점등 제한 300ms. 제한 중 추가 피해는 실제 체력·숫자에 모두 반영하며 새 플래시는 시작하지 않습니다.
예시 체력 100, 피해 2는 시연용 가상 입력입니다. 상단 HUD는 코어 항목만 발췌·재배치했습니다. Unity 실전 캡처나 밸런스 검증이 아닙니다.
기존 효과만 보기로 추가 반응을 끄고 비교할 수 있습니다. 사운드·화면 흔들림·저체력 반복 경고·새 파편은 포함하지 않았습니다.
