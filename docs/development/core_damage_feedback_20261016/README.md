## 검증과 재생성

`make_preview.cjs`가 원본 이미지를 HTML에 내장한다. `verify_preview.cjs`를 번들 Node+Playwright/설치 Chrome으로 실행하여 브라우저 오류0,단발/복귀 시점/연속 입력 수와 추가 반응 수,기존 효과 모드 전환을 확인했다. [결과](checks.json). 실제 PNG를 열어 두 안과 HUD/본체 겹침 없는 표시를 확인했다. 입력60프레임×40ms,인코딩 후 동일 프레임 병합으로 단발24/연속40프레임이며 **각 총2400ms**임을 검사했다. 초기에 브라우저 번들 부재 및 GIF 시간 검사가 실패해 설치 Chrome 경로와 delay 배열로 수정 후 완료했다.

시작 Unity 연결ready/전투 씬active·loaded/dirty=false/Play중지/compiling=false 확인 후 읽기 전용 참조 조회만 수행했다. Unity 테스트·Play·빌드·실행파일 실행 없음. 게임 적용/강도 선택/실전 가독성·연속 피해 성능 검증은 남아 있다.
