# 다중 포탑 기본 피해 하향 · 2026-10-20

사용자가 직접 플레이 후 ‘보스전 이외 초반에 너무 강하다, 데미지를 너프해야 할 듯’이라고 지시해 다중 포탑 피해 입력값 **12.5→11**을 적용했다. 복구 기준 `fdee137`, 시작 미커밋은 기존 PackageManagerSettings 변경뿐이다. 변경 대상은 towers.csv의 Multi damage 한 항목이다.

## 현재 효과와 선택 근거

- 무방어 적 실제 명중 피해13→11, 약15.38% 감소. 공격속도0.6회/초·최대3대상·사거리3·투사체속도6·설치비100·공격력 강화+1.5·첫 강화40수정은 유지한다. 단일/지원·플레이어·적HP40·보상·편성·시간·증강 주기는 변경하지 않았다.
- 명중이 계속되는 정적 DPS는1대상7.8→6.6,2대상15.6→13.2,3대상23.4→19.8이다. 단일 기본 DPS15.6보다 다수전 이점은 유지하며 전 대상 합산 피해를 줄였다. 실제 피해는 노출·비행·타깃·과잉 피해에 따라 다르다.
- 보스 전용 예외는 추가하지 않았다. 보스 한 명에게 주는 피해도13→11로 감소한다. 보스전 약점이 더 커질 수 있어 추가 확인이 필요하다.
- 공격형HP40의 단일 공격원 발수는 기본4발 유지, 첫공격력강화는 기존14피해/3발에서 새12.5입력→13피해/4발이다. 두 번째 강화14피해부터3발이 된다. 첫 강화의 DPS는11→13으로 증가하지만 처치 발수는 두 번째부터 줄어든다. 강한 성장 빌드 자체를 결함으로 보아 강화 증가량까지 일괄 하향하지 않았다.

후보 A는 현재 적용한 기본 피해11로 단순하고 파급 범위를 추적하기 쉽다. B 기본9는 초반 발수를 늘리지만 아래 조건에서2R부터 과도한 손실/전투 장기화가 나왔다. C 추가 대상 피해만 감쇠하는 방식은 보스 단일 화력을 보존할 수 있으나 새 타깃별 규칙과 표시가 필요해 이번에는 적용하지 않았다.
