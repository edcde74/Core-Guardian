# 중복 설치·강화 접기 제거 · 2026-10-13

사용자가 기존 진입 버튼이 열기·닫기를 담당하므로 설치 접기/강화 접기와 중복 기능 버튼을 제거하도록 요청했다.

- CoreGuardianHud에서 InstallFold·PlayerFold 생성과 앵커 연결을 제거했다.
- 설치 초기 분류 화면의 내부 `접기`도 같은 닫기 기능이므로 제거했다.
- 기존 하단 `타워 설치` / `플레이어 강화` 버튼으로 해당 패널을 열고 닫는다. 버튼 선택 반응도 기존 상태에 연결되어 있다.
- `설치 취소 · Esc`는 배치 선택 취소, `분류로 돌아가기`는 분류 이동이므로 유지한다. 상단 상태/피해/타워/증강 접기는 동일한 진입 토글 버튼이 없는 별도 기능이라 유지한다.
- 폰트 시안은 선택 대기 상태 그대로이며 이번에 적용하지 않았다. 밸런스CSV/전투규칙/씬/아트/폰트/원본프리팹 변경 없음.

## 확인

복구 기준2a89bba, 시작 시 해당 소스/인수인계 미커밋 변경 없음. Unity ready/stopped/컴파일false·전투씬dirty=false 확인 후 수정했다.

최초 Play는 디스크 수정이 아직 에디터에 재수입되지 않아 기존 버튼이 남아 검사에 실패했다. TimeScale복원·Play종료 후 AssetDatabase.Refresh로 재수입했고, 준비 씬을 다시 실행하여 최종 검사에 통과했다. 소스의 컴파일 오류가 아니며 기존 사용자 로그를 지우지 않았다.

실제 Button.onClick 실행 검사: 중복 버튼0, 설치 열기→닫기→재열기, 플레이어 강화 열기→닫기→재열기, 닫힘 시 선택 강조 해제, 설치 포탑 선택 유지, 재열기 시 분류 화면 복귀, 분류로 돌아가기, 별도 설치 취소 모두 통과. 선택은 정상 준비 단계의 단일 포탑 버튼으로 했고 밸런스 데이터 주입 없음. [검사 JSON](verification.json), [재현 코드](../CheckHudToggleCleanup.cs).
