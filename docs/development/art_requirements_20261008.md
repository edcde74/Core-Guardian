# 코어 가디언 추가 아트 요구사항 — 2026-10-08

Notion 담당 문서: [전투 프로토타입 추가 아트 제작 목록 — 우선순위 1~3](https://www.notion.so/3f3389dbfc6881d2a70be916ded8ddb7). `06. 아트`에 연결했고 작성 후 재조회했다.

대상은 실제 최소 전투, 기술병 자동 공격·포탑 설치·재화, 일반 적 3종·포탑 3종의 역할 검증이다. 아래 우선순위는 개발 중 필요한 아트 제작 순서이며, 해당 효과를 이미 구현하거나 최종 승인했다는 뜻이 아니다.

기존 기술병·병사·포탑·코어 외형, 60% 크기, 발/받침대 중심, 그림자·밀착선은 승인된 비교 자료를 재사용한다. 길은 A안을 사용한다. 기존 HUD 시안 5장을 바탕으로 필요한 기능을 연결하며 추가 시안 제작을 포함하지 않는다. 최종 픽셀 규격·팔레트·카메라는 별도로 확정해야 한다.

## 우선순위 1 — 전투 결과와 역할 판독

| 필요한 자료 | 목적 | 최초 제작 단위 | 확인할 기준 |
| --- | --- | --- | --- |
| 기술병·단일/범위 포탑 투사체 | 누가 누구를 공격하는지 판독 | 작은 투사체 스프라이트와 발사 위치 표기. 유형별 차이는 짧은 형태·색 차이로 제한 | 60% 아트와 A 길 위에서 보이며 적이나 그림자를 가리지 않음 |
| 적 피격·사망 표현 | 실제 명중과 처치 확인 | 짧은 피격 플래시와 공통 소멸 효과부터 검토 | 잔인한 연출 없이 기존 짧고 단순한 병사 형태와 어울림 |
| 버프형 적의 이동속도 효과 / 지원 포탑의 공격력 효과 표시 | 두 버프 역할과 실제 영향 대상을 구별 | 영향을 받는 대상의 작은 표식, 선택 시 범위 표시 | 두 효과를 구별할 수 있고 바닥 타일·접촉 그림자를 가리지 않음 |
| 코어 피해·골드 획득 표시 | 놓친 적과 처치 보상 확인 | 코어 짧은 피격 표시, +골드 문자 피드백 | 실제 피해/지급 사건에 한 번씩 표시. 획득 표시를 골드 줍기로 오인하지 않음 |

처음에는 작은 임시 투사체, 색상 플래시, 문자와 범위 선으로 기능을 확인할 수 있다. 이것은 최종 스프라이트·VFX 승인을 대신하지 않는다. 범위 포탑은 서로 다른 최대 3명에게 개별 투사체를 발사하므로 폭발·스플래시 아트는 요구하지 않는다. 대상이 먼저 죽은 투사체는 피해 없이 사라진다.

## 우선순위 2 — 움직임과 발사 감각

| 필요한 자료 | 목적 | 제작 전 확인할 사항 |
| --- | --- | --- |
| 기술병 이동 애니메이션 | 한 칸 이동의 움직임을 읽기 쉽게 표현 | 방향 수와 프레임 수, 한 칸 0.12초 보간과의 연결 방식 |
| 일반 적 3종 보행 애니메이션 | 경로 이동·종류·속도 차이 판독 | 경로 방향 전환, 갑옷/긴 창/넓은 방패/높은 군기의 실루엣 유지 |
| 기술병 공격·공격 포탑 발사 애니메이션 | 공격 간격과 발사 순간 판독 | 공격 중 이동, 포신·무기 방향 표현, 투사체 발사 프레임 |
| 지원 포탑·군기병의 버프 작동 표현 | 효과의 활성 상태와 범위 이탈 판독 | 반복 재생 강도, 1순위 대상 표식과 시각적 중복 최소화 |

모든 프레임은 발/받침대 접촉 중심과 화면상 크기를 유지해야 한다. 그림자와 밀착선은 본체와 함께 이동하며 애니메이션 프레임의 무기 폭으로 그림자 크기를 바꾸지 않는다. 방향 수·프레임 수는 현재 기획서에 확정값이 없으므로 제작 전에 사용자와 정한다.

## 우선순위 3 — 분위기와 마무리

| 필요한 자료 | 목적 | 범위 |
| --- | --- | --- |
| 코어 수정의 약한 반복 빛 | 발견한 수정 동력 장치의 분위기 보강 | 승인된 바닥 수정빛과 조화, 타일/그림자 대비 유지 |
| 포탑 설치·강화·파괴의 짧은 효과 | 준비 단계 조작의 결과를 명확히 표현 | 선택한 장치에 한정된 효과, 바닥 밀착 위치 유지 |
| 최종 석재 바닥·A 길 아트 정리 | 수리한 요새 전장의 일관성 | 보이는 바닥 한 장=한 칸과 실제 5칸 폭 유지, 그림자가 묻히지 않는 명도 |
| 기능 HUD의 아이콘·버튼·피드백 정리 | 설치/강화 조작을 읽기 쉽게 표현 | 기존 HUD 시안 활용, 새 시안 추가 제작은 별도 요청 시 진행 |

보스 외형·애니메이션, 10·11라운드 특수 연출, 대규모 에셋 생산은 현재 최소 전투 개발의 추가 아트 범위에 포함하지 않는다.

## 현재 로컬 에셋 확인

- `Assets/Art/ScreenTests/20261008_Depth/Prefabs/`에 승인된 비교용 8종 프리팹이 있다.
- `rg --files Assets` 검색에서 `.anim`·`.controller` 파일은 발견하지 못했다.
- 투사체 관련 자료에는 기존 `BeanProjectile.cs`와 테스트가 있으나, 이것만으로 최종 투사체/피격/사망 스프라이트가 준비되었다고 볼 수 없다.
- 에셋명 검색 결과는 현재 로컬 파일 기준이다. 원본 PNG 안에 포함된 미슬라이스 프레임의 존재까지 보장하거나 부정하지 않는다.
