# 타워 설치 메뉴 재열기 수정

사용자 보고: 분류→개별 포탑 목록으로 이동한 뒤 UI를 닫고 다시 열면 마지막 하위 메뉴가 남는다.

실제 씬에서 수정 전 재현: 공격 포탑 분류 진입→설치 버튼으로 닫기→다시 열기 시 단일 고속·범위 공격·분류로 돌아가기 목록이 표시됐으며 startsAtCategories=false.

수정: 설치 버튼과 삼각형 탭의 열기·닫기를 공통 처리한다. 새로 열 때마다 공격 포탑·지원 포탑의 첫 분류 화면으로 돌아간다. 메뉴 교체 시 기존 버튼을 즉시 비활성화하고 프레임 종료 시 제거해 같은 프레임의 버튼 중복을 막는다. 기존 새로고침 콜백도 정리한다.

패널 접기는 이미 선택한 포탑 설치 모드를 유지한다. 취소 버튼·Esc는 기존처럼 설치를 취소한다. 재열기 화면 초기화와 설치 취소를 구분한다.

실제 UI 검증 통과: 설치 버튼 재열기, 설치할 포탑 선택 후 삼각형 탭 재열기, 지원 하위 메뉴 취소 후 재열기, 분류 화면의 접기 버튼 후 재열기. 모든 경우 첫 분류 표시, 버튼3개, 중복 없음. 접기 중 설치 모드 유지 확인.

검증 스크립트: VerifyInstallMenu.cs. 결과: install_menu_verification_20261010.json. 검증용 timeScale0은1로 복구했고 Play를 종료했다. 최신 씬 저장 검증과 컴파일 준비 상태 확인.

HUD 노션의 타워 설치 화면 절에 재열기 규칙을 반영하고 재조회했다. 기존 HUD 시안5장을 보존했다.
