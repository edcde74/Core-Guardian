# 플레이어 발 그림자와 몬스터 체력바 높이

2026-10-16. 사용자 스크린샷 피드백으로 플레이어 그림자 정리와 병종별 머리 위 체력바 배치를 적용했다. 복구 기준 `d8f8426`.

## 수정

- 플레이어도 원본 정지 발을 납작하게 복제한 `바닥 밀착선`이 켜져 있었다. PlayerMotion 연결 시 해당 렌더러만 끄고, 중앙 바깥/접촉 타원 두 레이어의 표시·위치·크기·색을 유지했다. 원본 아트와 보행은 변경하지 않았다.
- 기존 체력바는 일반 병사 모두 로컬Y0.8, 보스1.4로 고정돼 큰 스프라이트 본체와 겹쳤다. 이제 OriginalWalk가 병종의 원본/상하 프레임 최대 높이와 발 중심으로 안정된 체력바 기준점을 제공하고, 실제 SynchronizeViews에서 위치를 갱신한다. 프레임별 흔들림은 없다.
- 머리뿐 아니라 위로 솟는 창/깃발에도 겹치지 않도록 해당 높이를 포함한다. 스프라이트 상단에서 원본 픽셀4개 여백이다. 현재 로컬Y: 공격형1.29375, 수비형0.9375, 버프형1.65, 보스1.415625. 체력바 기존 초록색·폭0.35·두께0.035·HP비율과 렌더 순서는 유지했다. HP/전투 수치 변경 없음.
- PNG/프리팹/씬, 원본8방향/상행 하체, 몬스터X/Y/발 그림자 정리, 포탑/VFX/밸런스/Notion 보존. 현재 몬스터 기준 아트/기존 비교 자료는 이전 작업과 같은 기준을 유지했다. 새 아트 생성 없음.

- CD 연결·Unity6000.6.2f1, 전투 씬active/dirty=false·Play중지/컴파일false 확인 후 수정. 재컴파일 completed/실패false/오류없음.
- 새 실제 생성 경로 검사에서 병사3종+보스의 체력바 하단이 원본 경계보다 위인지, 기준점 연결·기존 폭 유지·플레이어 고정 발 표시 꺼짐/중앙 그림자 유지 확인. 최초 검사에서 보스의 원본 투명 여백 포함 경계가 예상보다 높아 실패했고, 원본 캔버스 상단까지 포함해 수정했다.
