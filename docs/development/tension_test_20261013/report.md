# 6라운드 A안 실제 Play 비교

2026-10-13. 사용자 요청으로 테스트했다. 수정 전 복구 기준747f649. 게임 데이터·코드·씬·노션은 변경하지 않고 기존 Assets 밖 계측기 MeasureNaturalRounds.cs에 비교 옵션/압박 지표만 확장했다.

## 조건과 방법

- 실제 전투 씬에서 새 Play를 시작해 정상1~6R 진행. 기존안/A안 번갈아 각각3회, 양쪽5배속. 실제 Session.Tick/자동 공격/투사체/정상 구매/한칸 이동 API 사용. 준비는 기존 시작 버튼 명령으로 넘김. 체력·재화·피해 주입/강제 처치/라운드 건너뛰기 없음.
- coverage_save 정책: 기술병을 정상 이동으로(15,16)에 고정, 첫단일(14,16), 수정이 충분하면 범위(17,16) 추가. 준비에서 구매 가능한 기술병 공격력 강화. 양쪽6R 시작에서 범위100수정 설치/기술병2단계140골드 강화가 동일.6R 기술병 피해14, 첫단일 기본, 범위 기본.6R 완료에서 관찰 종료.
- A안은 새 세션의 순수 CombatData 객체에만6R7~11번 Start를9/9.75/10.5/11.25/12초로 수정. 원본TextAsset/CSV/씬 저장하지 않음. 다음 새 Play/종료 시 폐기. 유형 순서/18마리/총HP555/61골드/마지막25.5초 보존 검사6회 모두true.
- peakAlive는 에디터 관찰 때 동시 생존 수의 최대다. peakAliveFrom8To18은 라운드8~18게임초 관찰 구간의 최대다. minimumRemaining은 살아 있는 적의 관측 최소 코어 잔여거리다. 샘플 사이의 정확한 순간 최대/최소는 놓칠 수 있다.
- 반복3회는 프레임 시점 변동을 살피는 탐색이며 다양한 빌드·사람 입력·통계적 승률 검증이 아니다. 계측 시간은게임초, 5배속 관찰/부동소수점오차 포함.1배속 체감 검사로 해석하지 않는다.

## 판단과 남은 검증

확인한 효과: A안은8~18초 관측 생존 수를1 늘리고, 적의최심부 진입을약2.65~3.07타일 늘렸으며, 이 배치의 범위포탑이6R에서24~36 실제피해를 주게 했다. 범위 피해는총555의약4.3~6.5%. 다중타깃 발사 횟수를 계측하지 않았으므로 이것만으로 다중공격 가치가 검증됐다고 결론내리지 않는다.

전체생존최대13·코어손실0·클리어시간은 거의 같았다. 기술병은 설치 후 정지했고피해도 증가하지 않았다. 따라서 이배치에서는 국소압박·추가포탑기여 변화는확인했으나, 이동대응 필요나 사람긴박함이 증가했다는 근거는 없다. A안을정식 적용/승인으로 처리하지 않는다.

다음은1배속 사람 입력으로 같은6R을 비교해 집중구간을 발견하고 이동으로 보완할 수 있는지 확인한다. 다른/불리한 배치에서도 대응 가능한지 검증해야한다. 현재결과만 보고 더많은 적·체력 증가·추가압축을 동시에 적용하지 않는다.
