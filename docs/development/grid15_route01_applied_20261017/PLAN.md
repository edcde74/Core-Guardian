# 적용 범위와 실행 기록

복구 기준005ba5f. 사용자 승인: 화면 유지39×22/실제 칸0.69/경로 재배치, 첨부 원본의 회색 판석·낮은 경계석 길. 카메라/메인 배경/유닛 원본 크기/전투 CSV/기존 HUD·시각 설정 유지.

1. 현재 clean stopped 전투 씬 상태와 보호 설정을 기록한다. 새39×22/0.69/80경로 칸 계약이 현재 보드에서 실패하는지 확인한다.
2. 런타임 보드·코어·경로를 씬 설정에 연결하고 설치 격자 크기를 실제 칸에 비례시킨다. 코어 피해 효과도 새 코어 위치를 참조한다.
3. 에디터 API로 논리 타일·시작점·코어·웨이포인트를 승인 배치로 변경한다. 길 원본 PNG를 Sprite atlas로 참조하고 판석·경계석을 새 경로에 구성한다. 씬 YAML 수동 변경 없음.
4. 논리/런타임 경로 일치, 한 칸 이동0.69/차단, 설치 허용·경로/코어/바깥/점유 차단, 정상 구매와 Overlay 화면을 확인한다. 자체 Play만 종료하고 보호 설정/시간 복원·씬 저장·관련 파일 로컬 커밋.

판정: 길 재질은 사용자 첨부 원본을 재사용하며 그 이미지 전체를 배경으로 덮지 않는다. 원본 안의 코어/플레이어를 새 게임 아트로 중복 추가하지 않는다. 길 폭은 실제 차단 칸과 맞추고 낮은 경계석은 안쪽에 배치한다. 최초 생성 시안의 약1.4배 폭은 프롬프트 의도였으며 정확한 구현 수치가 아니다. 이번 칸 확대는15%로 확정한다.

검증은 맵 기능 QA이며 밸런스 측정/사람 플레이/몬스터 아트 수정으로 확대하지 않는다.

완료 기록: 보드 계약RED→GREEN, 실제 자체Play 집중검사 성공. 읽기 리뷰에서 이동 원점의 PlayerTile 역변환 문제를 발견해 좌표 회귀3건 RED(1통과/2실패)→GREEN(3/3), 실제 씬 좌표 오차도 보정했다. 이동 중 좌표 확인을 추가해 자체Play 집중검사를 재실행하고 보호 검사도 통과했다. 재검토 추가 중요 지적 없음. Unity가 저장한 씬/메타의 빈 값 뒤 공백은 직접 수정하지 않는다. 작성 코드·문서 diff 검사는 별도로 수행한다.
