# 3단계 성능 비교 — 공유 마스크 윤곽

2026-10-24, 사용자 "성능 비교함 해봐" 승인. 원본과 공유를 번갈아 각 3회 측정했다(orig_1 → shared_1 → … → shared_3). 실행은 각각 warm15+sample90이고 6회 모두 error null, 표본 90, 프레임 누락 0이었다. 각 실행 후 Play 종료·복원과 토글 OFF를 확인했다.

## 조건
- Unity 6000.6.2f1 Editor, Ryzen 5 5600X / RTX 3070, 1920×1080, ortho 8.5, VSync 1, 고정 dt 1/60
- 적128(Attack112/Buff16)·타워15. [기준 재측정](../../baseline_remeasure_20261024/README.md)과 같은 드라이버([Template.cs](Template.cs))를 쓰고, 토글만 Setup 직전에 켰다.
- Profiler 녹화·Deep·FrameDebugger OFF, native batch OFF

- Draw·SetPass 증가는 마스크 패스의 부품별 DrawRenderer 때문이다. 그런데도 이 PC에서는 렌더 스레드와 GPU 시간이 오히려 줄었다. **목표기기(GTX750Ti·구형 CPU)에서 SetPass 840이 어떤 영향을 줄지는 미확인**이다.
- GC 증가의 출처는 미확인이다(정렬 비교자, DrawRenderer 기록 등 후보). 후속으로 줄일 여지가 있다.

## 판정 (설계안 5절 기준)
- 게임 메인 스레드 2.5ms 이상 절감, 3회 범위 겹치지 않음: **충족** (3.44ms)
- 렌더 스레드 증가 1ms 이하: **충족** (오히려 2.20ms 감소)
- 픽셀: 고립 개체 차이 0. 겹친 개체 차이는 사용자 시각 판단 대상(2단계 README)
- Editor 측정이다. 실행 파일·목표기기 결과가 아니며, 이 PC 기준 게임 메인 스레드 목표 약 7~8ms에는 아직 못 미친다(10.1ms).
