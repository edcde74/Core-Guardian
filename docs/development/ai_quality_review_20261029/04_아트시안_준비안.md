# 코어가디언 아트 시안 준비안 (제안)

작성 2026-10-29. 기준: ai_quality_guide/02_아트, 00_공통/03_프로젝트설정_템플릿. 읽기만 했다. 모든 값과 항목은 **제안**이며 사용자가 고른 것만 확정이다.

## 0. 먼저 알릴 것: 18개는 이미 시안이 끝났다

인수인계 '기획 상태(10-26)'에는 "실제 시안은 아직 없음, 다음 순서 1 = 아트 개별 시안"이라고 남아 있다. 하지만 Notion [전투 프로토타입 추가 아트 제작 목록](https://app.notion.com/p/3f3389dbfc6881d2a70be916ded8ddb7)과 PC `docs/art/confirmed_art_20261027/README.md` 기준으로는 다음 상태다.
- 신규 1순위 18개 포함 30개 시안 전부 확정(10-26). 시안 방식은 "도트 비교판 + 지시서 둘 다"로 이미 정해짐.
- 투명 PNG 240장 Unity에 추가(10-27). 코드·씬 연결은 안 함.
- 10-28에 B7 격노·D6·D7 얼어붙음·B4 회복 십자는 게임 반영됨.
- HUD 개편 H1~H7도 10-28 확정.

그래서 이 문서의 2부는 "제작 지시서"가 아니라 **개발 재개 때 쓰는 게임 연결 검수 지시서**로 바꿨다. 새로 그릴 것은 없다. 인수인계의 해당 절은 옛 기록이므로 갱신이 필요하다(별도 승인 사항).

### 확인 필요 항목 (7개)
1. 제한 팔레트를 정할지, 정한다면 몇 색인지. 지금은 비슷한 색이 수백 개라 가이드의 "팔레트 고정 + 양자화" 검증을 할 수 없다. 단, 승인된 원본은 바꾸지 않는다(보호 규칙). 신규 제작에만 적용할지 결정 필요.
2. HUD 아이콘의 반투명 가장자리(TowerFrost.png 등)를 허용할지. 캐릭터는 반투명 0인데 HUD 일부만 부드러운 가장자리라 화풍이 다르게 보일 수 있다. 게임 화면에서 확인 후 판단 권장.
3. 최종 카메라·기준 해상도.
4. 지원 화면 비율.
5. 안전 영역.
6. 한글 HUD 글꼴.
7. 비행체 그림자를 땅에 둘지(아트 목록 '남은 확인').

## 2부. 신규 1순위 18개, 게임 연결 검수 지시서 (제안)

목적: 개발 재개 때 확정 아트를 연결하면서 "확정 시안 그대로 게임에서 읽히는가"를 확인한다. 새 디자인이나 재제작이 아니다. 기능 통과를 아트 승인으로 보지 않는다(ART.md).

### 모든 항목 공통 체크
- [ ] 임포트 설정이 PPU 32, Point, 무압축, mipmap 없음이다.
- [ ] 피벗이 발·받침대 접촉 중심(효과는 가운데)이다. 이미지 전체 중심으로 재정렬하지 않았다.
- [ ] 60% 크기, 회색 판석 길 위, 실제 게임 카메라에서 스크린샷을 찍었다.
- [ ] 기준 3종(또는 기존 포탑)과 같은 정수 배율 비교판을 함께 만들었다.
- [ ] 확정 시안판(https://claude.ai/artifact/K1fDVrSS32V8b9Rk4Z8w6y)의 확정안과 나란히 비교했다.
- [ ] 효과 수·수명을 최적화 이유로 줄이지 않았다.
- [ ] 스크린샷을 사용자에게 보내 최종 판단을 받았다.
