# 누적 피해 게이지 · 3안 제안

2026-10-17. 사용자가 첨부한 피해 패널 화면을 기준으로, 게이지를 감싸는 고정 빈 트랙과 그 안을 채우는 피해 표시를 요청했다. 게임 적용 없이 시안 3개만 비교하는 범위다. 시작 HEAD `f8f0f16`.

## 현재 확인

- 첨부 화면과 `Assets/Scripts/CoreGuardianHud.cs`의 Refresh를 읽었다. 현재 각 행은288×60이며 이름/숫자 아래 Bar가 존재한다. 폭은 `280 * 해당 피해 / 최대 피해`, 높이는16이다. 별도 고정 폭의 빈 트랙은 생성하지 않는다. 1위의 채움은 항상 최대 폭이 된다.
- 이번에는 Unity 연결/실제 실행 화면을 새로 조회하지 않았다. 사용자 첨부 화면과 저장 소스가 근거이며 다른 해상도·현재 Play·직접 조작 체감 검증은 하지 않았다. 사용자 Play/씬/시간 설정을 조작하지 않는다.
- 전체 행 배경을 색으로 채우지 않고, 고정 폭 테두리→어두운 빈 트랙→안쪽 채움의 구조를 제안한다. 최대치도 테두리와 안쪽 여백을 남긴다. 표시 계산 기준을 임의 변경하지 않으며 기존 최대 피해 대비 비교를 유지하는 최소안을 우선한다. 전체 합계 대비 기여율로 바꾸는 것은 별도 판단이다.

## 1안 선택 후 심볼 수정

사용자는 범위 공격 왼쪽 심볼을 더 직관적으로 바꾸라고 요청했다. 복잡한 작은 포탑 대신 **중앙 타격·넓은 충격 범위·표적3개**를 묶은 픽셀 심볼로 [수정 시안](basic_symbol_refined.png)을 제작했다. 기존 게이지/이름/수치를 유지했다. 원본 캐릭터나 포탑 아트를 재디자인하는 작업이 아니다. 단일 패널로 확대된 생성 시안이며 아이콘의 상대적 크기가 약간 커졌으므로 실제24px/다른 해상도 가독성은 적용 전 별도 확인이 필요하다. 이번 단계는 수정 시안이며 실제 게임 적용은 하지 않았다. 내장 imagegen 편집 사용, 기존3안 비교 이미지 보존.

## 시각 제작과 다음 확인

**최신 접기 피드백:** 사용자는 이전의 큰 직사각형 글자 탭을 정정하고, 첨부한 빨간 윤곽처럼 왼쪽 테두리에 자연스럽게 일체화하라고 요청했다. [테두리 일체형 손잡이](integrated_edge_handle.png)를 내장 imagegen으로 제작했다. 왼쪽 전체 테두리가 이어지고 중앙에 작은 삼각 돌출/화살표만 있으며 하단 독립 버튼과 손잡이 글자는 제거했다. 위치 확인용으로 원본 첨부처럼 빈 패널을 사용했으며 선택한 게이지/심볼 방향을 취소한 것이 아니다. 이전 직사각형 탭은 미채택 이력이다. 이번에도 게임 적용은 없고 사용자 검토 전이다. 접기/펼치기 시 화살표 방향과 실제 작은 크기 조작성은 구현 단계에서 검토한다.

사용자는 최신 게이지/역할 심볼 방향을 선택하고, 기존 하단의 독립 `피해 접기` 버튼을 첨부 표시처럼 피해 패널 왼쪽에 붙이는 시안을 먼저 검토하겠다고 요청했다. [펼침/접힘 비교판](left_tab_states.png)을 내장 imagegen으로 제작해 부착 위치·이름·방향·기존 하단 버튼 제거를 육안 확인했다. 펼침 상태는 패널 왼쪽 중앙의 부착 탭 `피해 접기`, 접힘 상태는 패널 본체를 오른쪽 밖으로 숨기고 화면 오른쪽 가장자리에 `피해 펼치기` 탭만 남기는 안이다. 방향 표시는 접기=오른쪽, 펼치기=왼쪽으로 제안한다. 접힘 전후 전투/집계 유지 여부 등 실제 동작은 구현 전이며 이번에는 시안만 제작했다. 시안의 확대 비율/공간은 배치 설명용이며 실제 화면 크기 검증은 아니다. 사용자 검토 대기.

최신 범위 심볼 피드백: 사용자가 폭발/충격파 심볼을 마음에 들어 하지 않아 [3개 표적으로 퍼지는 화살표](range_multitarget.png)로 다시 단순화했다. 작은 세부 장식을 없애고 다중 대상 타격을 표현했다. 단일 조준점/기술병 고글 헬멧과 기본 트랙형은 유지한 내장 imagegen 수정 시안이다. 사용자 선택/게임 적용 전이며 실제 작은 크기 검증은 별도다. 이전 시안도 보존한다.

후속 사용자 피드백: 단일 공격#2와 기술병에 같은 강화 심볼이 남아 구분되지 않는 문제를 지적했다. 역할별로 범위 공격=여러 표적에 퍼지는 타격, 단일 공격=한 표적 조준점, 기술병=고글 달린 헬멧으로 각각 분리한 [최신 수정 시안](roles_refined.png)을 내장 imagegen 편집으로 제작하고 세 실루엣의 구분을 육안 확인했다. 이전 수정판의 중복 아이콘을 최종 채택 상태로 취급하지 않는다. 실제 게임 적용은 하지 않았다.

[3안 비교판](comparison.png)은 첨부 화면을 스타일 참고로 내장 imagegen으로 생성했다. 짙은 패널·금속 모서리·흰 픽셀 글자·청록 채움과 고정 트랙/패딩/어두운 미충전부를 육안 확인했다. 425/210/70 및 채움은 외형 설명용이다. 생성 이미지의 아이콘은 원본 게임 리소스로 대체할 최종 산출물이 아니다. 원본 아트나 게임 파일을 수정하지 않았다.

선택 후 적용할 때 0피해·최대 피해·매우 작은 피해·동률·큰 숫자·다수 항목 스크롤을 확인한다. 최대 채움에서도 테두리/패딩이 유지되고 숫자와 겹치지 않아야 한다. 피해 누적은 명중 실제 체력 감소 집계라는 기존 의미를 유지한다. 구현·성능·사람 체감 검증이나 사용자 선택 완료로 표현하지 않는다.
