## 검증·제한

두 Notion 수정 작업의 async status=succeeded를 확인한 뒤 다시 fetch했다. 핵심 문구, 기존 이미지·page/database 태그 동일, 테스트 문서 ‘기록 템플릿’ 이하 과거 이력 동일을 확인했다. [검증 요약](notion_sync_verification.json).

이전에는 자동 승인 검토로 로컬 이미지 업로드가 보류됐으나, 사용자가 ‘적용화면 노션에 첨부해’라고 명시 승인한 뒤 `expanded.png`를 전송했다. 새 업로드 예약을 사용했고 Node 전송은 FormData 미제공/연결 단계에서 실패해 HTTP 전송 가능한 승인된 curl 경로로 업로드했다. [업로드 결과](notion_image_upload_response.json)의 status=uploaded/422297bytes를 확인했다.

기존 HUD 페이지의 ‘실제 피해 HUD 적용 화면 — 2026-10-17’ 절에 네이티브 이미지 블록으로 첨부한 뒤 다시 fetch해 `notion-file-block`과 파일명을 확인했다. 이미지 출처·1920×1080·Overlay 포함·표시 주입 QA라는 설명을 함께 넣고, 기존 참고 시안과 링크는 유지했다. 이미지 첨부 완료이며 추가 승인 대기는 없다. 새 Unity 캡처나 게임 변경은 하지 않았다.
