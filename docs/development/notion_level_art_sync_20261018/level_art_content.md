# 장소와 전체 인상
오래 방치된 석조 요새 안뜰을 기본으로 합니다. 낡은 자연석 바닥과 무너진 외곽 성벽·희소한 이끼가 장소를 만들고, 기존 황동·청록 계열의 코어와 설비가 그 위에서 구분돼야 합니다.
- 메인 그라운드는 실제 이동·설치가 이루어지는 바닥입니다. 내부는 넓고 평평하게 읽히도록 유지합니다.
- 백그라운드는 화면 끝까지 채우는 바깥 폐허입니다. 재질·팔레트·픽셀 밀도·시점을 메인 바닥과 맞춰 검은 여백이나 서로 다른 장소처럼 보이는 경계를 줄입니다.
- 높은 장식은 보드 밖에 두고, 새 바위·상자·기둥을 내부에 배치해 통행/설치 장애물처럼 보이게 하지 않습니다. 추가 장식 종류·위치는 별도 사용자 선택 전까지 미확정입니다.
# 메인 바닥과 백그라운드
사용자가 선택한 자연석1안의 **크고 불규칙한 돌판**을 유지합니다. 돌판을 논리 한 칸마다 똑같이 반복하거나 줄눈을 설치 격자처럼 균등하게 만들 필요는 없습니다.
- 메인/외곽은 `NaturalCourtyard_01_ClearBorder.png` 한 장2D 배경으로 연결합니다.
- 원본 바닥 Tilemap은 이동·설치 판단을 위해 유지하고 반복 바닥 렌더러만 숨깁니다. 그림을 바꾼 것을 논리 칸이 없어진 것으로 해석하지 않습니다.
- 한 칸을 실제로15% 키우고 카메라 범위를 유지하는 배치①를 적용했습니다. 실제 보드·좌표는 레벨 담당 문서를 따릅니다. 화면을 확대해 보이게 하려고 카메라를 추가 변경하지 않습니다.
- 초기32px 반복 바닥은 사용자가 거부한 이전 표현입니다. 현재 자연석 바닥을 그 상태로 되돌리지 않습니다.
# 몬스터 길목
선택한 길목1안은 회색 판석과 낮은 석재 경계석으로 표현합니다. 기존 연속 황동 테두리 길 대신 주변 자연석 배경에 어울리는 석재 재질로 구분합니다.
- 길의 방향과 ㄱ자 모서리에서 판석·경계석이 끊기거나 통로를 막는 선처럼 보이지 않게 합니다.
- 길 위 적의 몸·발밑 그림자와 피해 숫자를 먼저 읽을 수 있도록 과한 장식·발광·질감 대비를 피합니다.
- 현재 길 장식은 논리 차단 길 한 칸 안쪽입니다. 인접 설치 가능 칸을 길 장식으로 덮거나 아트 때문에 별도 설치 금지 칸/충돌을 추가하지 않습니다.
- 길목1안, 바닥1안, 배치①는 서로 다른 선택 항목입니다. 최초 길목 생성 프롬프트의 약1.4배 폭을 실제 적용 배율로 기록하지 않습니다.
