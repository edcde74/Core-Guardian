# 방패병·군기병·보스 Y− 양발 교대 보행

2026-10-17 사용자 요청: 창병 외 몬스터가 Y−로 이동할 때 절뚝거리는 동작을 수정한다. 이 요청으로 이번 채팅의 기존 HUD 담당 범위에서 해당 애니메이션 수정까지 작업 범위를 확장했다. 복구 기준 `d61fd46`; 시작 시 Assets/Packages/ProjectSettings 추적 변경이 없어 빈 checkpoint를 만들지 않았다.

## 원인과 적용

이전 [양발 교대 수정](../vertical_gait_fix_20261016/README.md)은 창병만 대상으로 했다. 나머지는 굽힌 다리가 오래 남는 Down4장 전체 이미지를 순환했고, 한쪽 다리의 짧은 교대만으로 절뚝거리는 인상을 남겼다. 확장 검사에서 창병2건 통과/나머지3종 실패를 먼저 재현했다([red.json](red.json)).

- `CoreGuardianOriginalWalk.VerticalLegPair`에 방패병/군기병/보스별 앞방향 다리 분리 영역을 추가했다. 각자의 기존 Down0 정강이·부츠 도트를 재사용해 좌우 두 다리를 표시하고, 같은3.5원본px 리프트를 반 주기 차이로 적용한다. 정지 시 양발 리프트0. 발이 들리는 시간을 양쪽 동일하게 유지한다.
- 원래 Down4장의 머리/상체/장비 표현은 유지한다. 다리 주변은 병종별 영역을 잘라 고정된 굽힌 다리와 중복하지 않게 하고, 허리 아래 천 영역은 Down0의 기존 도트를 사용한다. 일부 프레임에서 올라온 고정 무릎이 세 번째 무릎처럼 남는 것을 방지한다. 보스는 왼쪽 절단 영역을 넓혀 얇은 잔류 무릎 조각도 제외했다.
- 새 세 종류는 **Y−에만** 분리 보행을 적용한다. Y+로 전환하면 원래 Up 프레임을 표시하고 분리 다리/몸통 조각은 숨긴다. 창병의 기존 상하 교대, 모든 X축 보행, 경로/이동속도/전투 수치/발 중심/그림자/체력바는 유지한다.
- 런타임 Sprite는 기존 텍스처의 사각영역을 참조하며 캐시한다. 원본 PNG/VerticalWalk PNG/프리팹/씬을 덮어쓰지 않았고 새 디자인·팔레트는 만들지 않았다. 공통 아트 문서와 실제 기준 병사3종/비교판을 먼저 직접 열어 확인했다.

## 검증

- 집중 보행 EditMode18/18 통과 후 보스 잔류 무릎/천 영역을 보강했다. 최종 전체 [EditMode121/121](editmode.json)·[PlayMode29/29](playmode.json) completed, 실패/스킵0.
- 기존 EditMode 양발 검사를 나머지3종으로 확장해 양쪽2px 초과 이동/동일 진폭/반 주기 교대를 검사한다. 원본/지면 기준과 X±/Y± 전환 회귀도 포함한다.
- 새 실제 전투 씬 PlayMode 검사는 **실제 Session 경로의 첫 하행 구간**을 찾아3종을 진단 생성한다. 기존 adapter를 통해 이동시키며 Down4프레임/고정 다리 비표시/활성 양발3px 초과 이동/정지 양발0/Y+ 원래 프레임 복귀를 확인했다. 진단 생성·수동Tick·플레이어 원거리 좌표를 사용한 기능 QA이며 정상 라운드 편성·사람 플레이·밸런스 실측이 아니다.
