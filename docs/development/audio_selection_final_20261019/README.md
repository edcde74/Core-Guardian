## 잠정 조건과 실제 연결 전 주의

- 철거3차②는 일단 채택하되 실제 철거/해제 연출에 따라 재검토한다. Esc 설치 취소2차③과 별도 사건이다.
- 라운드 시작2차③은 기존 잠정 선호를 유지한다. 준비 시간이 끝나거나 수동 라운드 시작으로 전투 단계에 진입하는 순간의 알림이다. 기존14개 연결의 시작음과 구분한다.
- 멀티는 B72②의 음색을 바탕으로 실제 발사 수1·2·3개에 맞춰 구분하는 정책을 승인했다. 같은 포탑의 한 공격을 묶어 하나의 파일을 한 번 재생해야 한다. 타깃별 이벤트마다 전체3연타를 반복하지 않는다. 기존0/85/170ms 리듬을 보존한다. 2차 재구성 비교본은 manifest의 count_previews에 있으며 게임 미연결이다.
- 증강 공개·선택 시 전용 BGM2차③으로 전환하는 방향을 선택했다. 실제 상태 전환/복귀·페이드/덕킹/믹스는 구현되지 않았으며 증강 규칙/타이머를 변경하는 승인이 아니다. 전투BGM은B72①이고 기존 BGM 초안/원본은 보존한다.
- 최종 승리는 마지막 라운드 클리어로 게임 전체가 승리 종료되는 순간이다. 일반 완료와 별도다. 선택한 결과음이 서로 다른 번호라고 사용자 선택을 같은 번호로 임의 재조합하지 않는다.
- 기존14개 실제 연결/정책과 마지막 사운드 기능QA Edit3/3·Play12/12는 [기존 승리 연결 기록](../victory_audio_applied_20261019/README.md)을 따른다. 강제피해·진단Session/수동Tick 기능QA이며 정상 다수전투 믹스/성능·전체회귀·밸런스 검증이 아니다.
