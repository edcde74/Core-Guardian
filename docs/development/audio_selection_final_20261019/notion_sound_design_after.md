# 역할
전투·설치/강화·라운드 결과 사운드의 음원 선택, 실제 재생 사건, 정보 우선순위와 소리 중첩을 담당합니다. 증강 선택 규칙·게임 승패/보상 규칙·시각 효과의 상세 설계는 해당 담당 문서를 따르며, 여기서는 소리 연결 범위만 기록합니다.

## 현재 연결된 재생 정책
- 공통 4음성 풀·gain0.55·고정 피치1·비루프·사용자 저장 효과음 음량을 사용합니다. 실제 저장값을 보존하며 기본65%나 과거 약13%로 초기화하지 않습니다. 마지막 이전 Unity 조회는 약6.8%이며 이번 문서 동기화에서 새로 조회하지 않았습니다.
- 멀티 파일은 0/85/170ms 세 포신 리듬을 포함합니다. 같은 포탑의 35ms 이내 타깃별 발사 이벤트는 한 번으로 묶고, 서로 다른 멀티 포탑은 각자 재생합니다. 단일/플레이어 발사는 각각35ms 제한을 사용합니다.
- 피격·처치는 계열별0.1초 간격이며 치명 타격은 처치음만 냅니다. 코어 도착으로 퇴장한 적은 처치음 대상이 아닙니다. 살아남은 보스의 가속 전환은 해당 타격의 일반 피격음을 대체합니다.
- 코어 피해 알림은0.3초, 강화 실패는0.2초 묶음입니다. 풀 포화 시 일반음은 생략할 수 있고, 코어 알림은 우선 재생합니다. 다른 중요 알림이 현재 코어음을 덮지 않도록 보호합니다.
- 최종 승리음은 일반 완료음과 중복하지 않으며 패배·진단 종료에는 재생하지 않습니다. 음소거 해제/재연결로 지난 사건을 뒤늦게 재생하지 않습니다. 기존 승패/최종 보상 규칙은 변경하지 않았습니다.

- 최종 승리는 **마지막 라운드 클리어로 게임 전체가 승리 종료되는 순간**이며 일반 라운드 완료와 별도입니다. 선택 결과를 기존 승패/보상 규칙 변경으로 확대하지 않습니다.

- 마지막 사운드 연결 당시 집중 Edit3/3·Play12/12가 통과했습니다. 진단 Session/메모리 편성/강제 피해·수동 Tick 기능QA이며 정상 최종 라운드 실전 진행·사람 직접 청취·다수전투 믹스·성능·전체 회귀·밸런스 검증이 아닙니다.
- 청취 페이지는66개 경로/해시/HTTP 부분 응답, WAV/OGG 연속 재생, 필터·메모 저장·결과 복사를 확인했습니다. 에이전트 음색 평가나 사용자 전체 후보 승인을 뜻하지 않습니다.
- 이번 노션/인수인계 동기화에서는 게임·Unity·저장 음량을 변경하거나 새 Unity 검사를 하지 않았습니다. 새5차는6개/41미디어URL·기존392파일해시·실버 비교PCM·브라우저 재생을 확인했고, 사용자 골드/플래티넘5차① 선택을 받았습니다. 에이전트 직접 청취와 정상 다수전투 믹스·성능/전체 회귀 통과는 아닙니다.
# 해결할 문제
- 같은 소리가 짧은 간격으로 겹쳐 하나의 큰 잡음처럼 들릴 수 있습니다.
- 모든 포탑의 발사와 모든 적의 피격에 소리를 개별 재생하면 중요한 사건을 구별하기 어려울 수 있습니다.
- 소리를 제한하더라도 공격이 적중했다는 정보와 보스·코어 위험처럼 중요한 변화가 읽혀야 합니다.

# 현재 확정하지 않은 사항
- 새 선택음의 실제 게임 연결/교체 지시 및 연결 전 현재 Unity 연결·씬·Play·컴파일·저장 상태 재조회. 공유 에디터/다른 채팅 검사를 중단하거나 겹치지 않습니다.
- 철거3차②는 해제 연출에 따라 재검토, 라운드 시작2차③은 잠정 선호입니다. 멀티 실제 발사 수 묶음과 증강 선택 BGM 전환은 게임 미구현입니다.
- 정상 다수전투에서 현재4음성/간격/우선권이 충분한지와 반복 피로·중요 사건 구별·클리핑/출력 품질·성능/전체 회귀.
- 오디오 믹서 분류·플랫폼별 출력과 최종 믹스. 골드/플래티넘5차①의 사용자 음색 선택을 이러한 검증의 통과로 확대하지 않습니다.
# 검토 방법
- 한 발 명중, 소수 포탑, 다수 포탑, 한 적 집중 공격, 여러 적 동시 명중 상황을 구분해 비교합니다.
- ‘큰 소리라 잘 들리는가’와 ‘중요한 사건을 구별하는가’를 나눠 확인합니다.
- 시각 효과만 있을 때와 소리를 더했을 때의 전달 차이, 반복 청취 피로를 함께 확인합니다.
- 기존 증강 카드 공개음·BGM 등 다른 작업의 적용 여부를 이 문서 작성만으로 변경하지 않습니다.
