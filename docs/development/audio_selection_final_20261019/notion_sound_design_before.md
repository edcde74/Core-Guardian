## 현재 연결된 재생 정책
- 공통 4음성 풀·gain0.55·고정 피치1·비루프·사용자 저장 효과음 음량을 사용합니다. 실제 저장값을 보존하며 기본65%나 과거 약13%로 초기화하지 않습니다. 마지막 이전 Unity 조회는 약6.8%이며 이번 문서 동기화에서 새로 조회하지 않았습니다.
- 멀티 파일은 0/85/170ms 세 포신 리듬을 포함합니다. 같은 포탑의 35ms 이내 타깃별 발사 이벤트는 한 번으로 묶고, 서로 다른 멀티 포탑은 각자 재생합니다. 단일/플레이어 발사는 각각35ms 제한을 사용합니다.
- 피격·처치는 계열별0.1초 간격이며 치명 타격은 처치음만 냅니다. 코어 도착으로 퇴장한 적은 처치음 대상이 아닙니다. 살아남은 보스의 가속 전환은 해당 타격의 일반 피격음을 대체합니다.
- 코어 피해 알림은0.3초, 강화 실패는0.2초 묶음입니다. 풀 포화 시 일반음은 생략할 수 있고, 코어 알림은 우선 재생합니다. 다른 중요 알림이 현재 코어음을 덮지 않도록 보호합니다.
- 최종 승리음은 일반 완료음과 중복하지 않으며 패배·진단 종료에는 재생하지 않습니다. 음소거 해제/재연결로 지난 사건을 뒤늦게 재생하지 않습니다. 기존 승패/최종 보상 규칙은 변경하지 않았습니다.
## 전체 청취와 선택 방식
- 사용자는 개별 항목을 하나씩 제시하는 방식 대신 **전체 사운드를 한 페이지에서 비교**하도록 요청했습니다. 현재 적용 항목은 **현재음+비교 후보2개=총3개**, 미적용 항목은 후보3개입니다.
- 로컬 페이지는22항목/66청취본이며 현재 적용14개는 모두 페이지 내 **① 현재 적용**으로 표시합니다. 과거 개별 제시 번호와 구분합니다. 기존 확정음을 미선택으로 되돌리지 않습니다.
- 공격음 비교②③은 승인 원본의 길이/고역 파생본이며 게임에 미적용입니다. 설치 실패·철거/취소·패배·UI 클릭/열기/닫기6항목은 후보만 있고 실제 연결은 하지 않았습니다.
- 증강3개는 기존 등급별 코드 공식 재현 참고음으로 택일 후보가 아닙니다. BGM3개는 기존 제작 초안의 읽기 참조이며 원본과 제작 문서를 수정하지 않았습니다.
- 개별/3개 연속/현재음14개 이어 듣기·검색/필터·선택메모 저장·결과 복사/JSON 저장을 제공합니다. 선택은 브라우저 메모이며 Unity 자동 적용이나 최종 적용 승인이 아닙니다. 결과를 받은 뒤 사용자 지시에 따라 연결합니다.
- 페이지 청취 음량은 독립적이며 게임 저장 음량을 변경하지 않습니다. 로컬 경로: `AudioProduction/CoreGuardian_AudioReview_20261019/index.html`. 같은 폴더 `Open_Audio_Review.cmd`로도 엽니다. 로컬 서버 사용 시 [이 PC의 청취 페이지](http://127.0.0.1:8879/AudioProduction/CoreGuardian_AudioReview_20261019/index.html)로 열며 다른 PC/모바일의 공개 사이트가 아닙니다.

# 현재 확정하지 않은 사항
- 전체 청취 페이지의 새 비교 후보 선택 및 교체 여부. 현재 승인14개는 선택 전까지 유지합니다.
- 미연결6항목의 채택 여부와 구체 연결 범위, BGM 최종 선택/실제 적용 여부.
- 정상 다수전투에서 현재4음성/간격/우선권이 충분한지와 반복 피로·중요 사건 구별·클리핑/출력 품질.
- 오디오 믹서 분류·플랫폼별 출력과 최종 믹스. 기존 등급별 증강음의 재구성 여부는 별도 사용자 선택입니다.
# 검토 방법
- 한 발 명중, 소수 포탑, 다수 포탑, 한 적 집중 공격, 여러 적 동시 명중 상황을 구분해 비교합니다.
- ‘큰 소리라 잘 들리는가’와 ‘중요한 사건을 구별하는가’를 나눠 확인합니다.
- 시각 효과만 있을 때와 소리를 더했을 때의 전달 차이, 반복 청취 피로를 함께 확인합니다.
- 기존 증강 카드 공개음·BGM 등 다른 작업의 적용 여부를 이 문서 작성만으로 변경하지 않습니다.
