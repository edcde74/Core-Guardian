## 셰이더와의 접점

C#은 원본 부품 렌더러·마스크·윤곽/발광 출력과 재질/정렬을 준비하고 제출한다. 셰이더는 제출된 정점/픽셀을 처리한다. **C# 준비 중복 축소는 CPU/GC 후보**, **윤곽·발광 샘플 축소는 GPU 후보**, **출력 결합은 정렬·재질·텍스처·추가 렌더러 구조까지 다루는 CPU/Draw 후보**다. 셋의 성과를 서로 대체하거나 합산하지 않는다. [셰이더 보고](SHADER_REPORT.md).
