## 제안 — 미승인·미적용
첫 구현 범위는 피해 HUD 행 재사용으로 좁힌다. 피해원 키로 행과 텍스트/막대/심볼 참조를 보관하고, 값·최대 피해 대비 비율·기존 정렬 순서만 갱신한다. 새 항목만 행을 확보하고 불필요한 행은 재사용 대기로 전환한다. 세션 재시작/종료 시 참조·표시 상태를 정리한다. 접힘 중 집계와 다시 펼침, 역할 심볼·손잡이·WASD 입력 분리는 기존 담당 규칙을 유지한다.

이 단계에서 전투 표시 객체 풀링·개체 강조 렌더 구조·Session 로직은 바꾸지 않는 제안이다. 다음 후보는 전투 표시 객체 재사용/뷰 캐시이며, 지속 프레임 비용을 위한 강조 렌더 통합은 별도 방법 검토가 필요하다. 첫 단계만으로 대량 전투 성능이 해결된다고 판단하지 않는다.

승인 후 검증은 같은16항목의 값 변경·정렬 변경·접기/펼치기·신규 항목·재시작에서 행 재생성/누적/비율/외형을 비교하고, 동일 조건에서 갱신 시간과 유효 할당 지표를 비교한다. 동기 호출 비용과 실제 프레임 통계는 구분한다. 공유 Unity가 사용 중이면 검사를 시작하지 않는다. 목표PC/해상도/배속/FPS 예산은 여전히 미확정이다.

다음 결정은 위 첫 구현 범위에 대한 사용자 선택이다. 현30R 성장·물량/밸런스·아트·효과 표시량/수명·사운드 보존 조건은 유지한다.
