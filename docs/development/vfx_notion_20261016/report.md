# VFX·피드백 논의 Notion 기획서 분류 완료

2026-10-16. 사용자 승인 분류와 코어 가디언 Notion 양식에 맞춰 기존 효과 기준에서4개 담당 문서를 연결하고 사운드를 별도 분류로 정리했다. 이전 사용량 제한으로 중단됐던 연결 수정을 재개해 완료했다.

## 문서와 위치

- [기존 효과 아트·색감·타이포그래피 기준](https://www.notion.so/3f4389dbfc688118965ecb7a1ffaaf3c): 공통 기준과 아래4개 문서의 탐색 시작점. 기존 승인 원본/이미지/표를 보존했다.
  - [타격 VFX·피격 피드백](https://www.notion.so/3fb389dbfc6881b68c6dd8b2e3a23188): 몸 피격 반응의 채택/적용, 현재 구현값과 판독 기준.
  - [상태 효과·위험 알림](https://www.notion.so/3fb389dbfc68816d96b0ed1ad4e98d8c): 상태 표시·보스/코어 강조 방향, 둔화 시안 보류.
  - [셰이더·화면 후처리 기준](https://www.notion.so/3fb389dbfc68813ab657f4600eeae76f): 현재 피격 셰이더와 후처리·발광 등 후보의 구분.
  - [VFX 시안·선택·검증 기록](https://www.notion.so/3fb389dbfc6881f78273d798f989b1cf): 시안·사용자 피드백·선택·검증 근거.
- [07. 사운드](https://www.notion.so/3fb389dbfc68812e99cef57df6b65793): 프로젝트 루트의 별도 분류.
  - [전투 사운드 설계 방향](https://www.notion.so/3fb389dbfc68815f8923cb93f5b90743): 이번 VFX에서 소리를 제외한 결정, 다수 타워의 음 중첩/피로 문제와 미확정 검토 항목.

모든 상세5개는 기존 ‘기획서 관리’ 데이터베이스 항목이다. 물리적으로 DB 밖 하위 페이지로 옮기지 않고, 기존 코어 가디언의 분류 페이지→문서 mention 탐색 양식을 유지했다. 담당자·기획서 유형·대분류·진행 중 상태를 설정했고 기존 분류6개를 보존한 채 사운드 선택지를 추가했다. 시안/검증 기록은 테스트 기록·제작·검증으로 분류했다. 신규 분류1개/상세5개는 중단 전 생성됐으며 이번 재개에서 중복 생성하지 않았다.

## 내용 구분

- 기존 B 효과·E2 탄·승인 숫자를 유지한다. 현재 사용자 선택으로 추가 적용한 것은 몬스터 몸의 짧은 밝기 반응뿐이다.
- 65ms·22%·100ms는 현재 몸 피격 표시 구현값이며 최종 사람 체감 승인과 구분한다. 새 스파크 표시 빈도나 숫자 합산 정책으로 확장하지 않았다.
- 공격별 새 파편/스파크/숫자 반응은 보류·미적용. 둔화 장화 시안도 보관·미적용이며 기본 공격 둔화로 오인하지 않게 담당 증강 문서에 연결했다.
- 사운드 중첩·반복 피로는 별도 기획에서 검토한다. 음원과 동시 재생 상한·간격·우선순위를 임의 확정하지 않았다.
- 상태/피해/증강의 상세 전투 규칙은 기존 담당 문서로 연결하고 새 VFX 문서에서 재정의하지 않았다.

## 첨부와 검증

- 타격 문서에 Unity 몸 피격 비교PNG1개 첨부.
- 시안 기록에 기술병/단일/범위 포탑GIF3개와 둔화 장화 비교PNG1개 첨부.
- 루트·아트·공통 기준·사운드 분류·상세5개 총9페이지를 최종 fetch했다. 담당 문서4개와 별도 사운드 연결, 상세5개 DB 소속, 양식의 역할/관련 기획서, 신규 이미지5개를 확인했다.
- 기존 이미지·기존 child page 태그가 보존됐는지 읽기 비교했으며 모든 항목 통과. 읽은 결과에서 잘림/unknown block 표시 없음. [검증 요약](verification.json).
- 공통 기준 페이지의 중복된 세부 피격 설명을 담당 타격 문서로 연결하고, 적용/보류 및 몸 재점등 제한과 새 숫자/스파크 후보를 구분했다. 기존 아트 분류의 설명과 상세 문서 간 상호 링크도 갱신했다.
- 한도 중단 전 Notion 파일 업로드는 완료됐으며 최종 fetch에서 실제 notion-file-block 첨부를 확인했다. 이번 재개에서는 재업로드하지 않았다.
- 게임 코드·씬·CSV 변경, Unity 실행/새 테스트/빌드/실행파일 실행/Push는 하지 않았다. 자동 검사92/16은 피격 적용 당시 기록을 인용했으며 이번 문서 작업의 재실행 결과가 아니다.
