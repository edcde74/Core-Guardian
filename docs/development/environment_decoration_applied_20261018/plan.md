# 승인 혼합 장식 적용 계획

사용자 선택: D_A_interior_B_edges.png 사진의 A내부/B외곽. 실제 적용 승인. 기존 바닥/땅굴/경로/유닛/HUD/후처리 보존.

1. 현재 Unity 상태/정렬/실제 변경 전 화면 조회. HEAD3f04f5a를 복구 기준으로 유지.
2. built-in imagegen으로 승인 화면에서 장식만 투명 분리. 별도 신규 PNG로 보존. 기존 승인 에셋은 덮어쓰지 않음.
3. 원래 카메라 footprint에 맞춰 신규 비충돌 정적 장식만 추가. 외곽-10/낮은프랍-5, 길1/경계석2/입구4/주요본체 기존높이정렬 유지. 외곽/내부5개 사각 영역으로 UV를 나눠 기존 소스는 변형하지 않음.
4. 변경 전 모든 기존 컴포넌트 직렬화·타일 좌표/색/행렬/참조와 원본 에셋을 기록. 변경 후 모두 동일한지 비교. 신규 장식 Collider/Behaviour0 확인.
5. 동일 Edit 카메라 실제 캡처로 배경/프랍·길·땅굴 접합·오브젝트 가림 확인. 새 검증 필요 범위만 실행. 사용자/다른 채팅 Play가 생기면 중단하지 않고 대기.
6. 씬을 에디터 API로 저장, 상태/콘솔 확인. 인수인계 갱신 후 관련 파일만 로컬 커밋. 빌드/실행파일/push/밸런스 측정 없음.

실제 적용은 생성 시안 전체를 배경으로 교체하는 방식이 아니다. 분리 과정은 원본 도트 완전 동일 보장이 없으므로 실제 적용 화면을 별도 제출한다.
