# 증강 뒷면·공개 연출 시안

2026-10-13 (Asia/Seoul). 앞선 HUD 시안3묶음의 외형은 사용자가 승인했다. 게임에 적용하기 전에 증강 카드 뒷면·오버·뒤집기 연출을 추가로 요청했다. **이번 결과는 상호작용 미리보기이며 Unity 적용 완료가 아니다.**

## 사용자가 정한 공개·선택 흐름

- 처음에는 카드3장이 뒷면이다. **최신 사용자 기준: 등급 이름/배지 없이 뒷면 아트만 보고 등급을 짐작하며 기대감으로 공개한다.** 뒷면의 실버/골드/플래티넘 글자와 배지, 클릭 안내판을 제거했다. 공통 수정문양과 은빛/금빛/청백색 테두리·보강장식으로 구별한다. 카드 이름/효과는 뒤집기 전 숨긴다. 등급 비공개 및 뒷면 등급글자 표시의 이전 해석은 모두 폐기한다.
- 첫 클릭: 그 카드만 뒤집어 등급·이름·효과를 공개한다.
- 공개된 카드를 다시 클릭: 해당 증강을 선택한다. 별도의 확인 버튼을 추가로 누르는 흐름으로 바꾸지 않는다.
- 다른 카드를 다 공개하기 전에도 이미 공개한 카드를 선택할 수 있다.
- 등급이 높을수록 연출과 사운드를 풍부하게 한다.

## 구현한 미리보기

- [새 뒷면 PNG](04_augmentation_back.png): imagegen 내장 도구 생성. 철/황동 모서리·청록 수정 문양, 등급 공통. 1024×1536 RGBA이며 투명도가 존재한다. 최종96×144 픽셀 원본이라는 뜻은 아니다.
- [무손실 WebP](04_augmentation_back.lossless.webp): 같은 이미지의 무손실 인코딩, 614,952bytes. 시안에는 이 이미지를 한 번만 인라인 저장하며 카드3장에 재사용한다. 원본 PNG를 보존했다.
- [상호작용 원본](augmentation_flip_fragment.html), [브라우저 미리보기](augmentation_flip_preview.html). 실제 게임/네트워크/재화와 연결하지 않는다.
- 뒷면 오버는 해당 등급색 강조·짧은 들림·누름 반응. Y축 뒤집기에서 카드가 얇아졌다가 앞면을 보여준다.
- 스파크 수정본: 뒤집기 시간 실버440ms/골드660ms/플래티넘920ms 유지. 카드 중앙의 작은 점 대신 네 변에서 흰 핵·등급색 꼬리의 짧은 스파크와 사각 불꽃을 발사한다. 실버14개, 골드30개, 플래티넘52개+170ms 뒤20개(2차 분출). 공개 중간 이후에만 등급 반응. 기존2음/3음/4음 사운드 유지, 반복 발광 없음.
- WebAudio의 임시 합성음이며 최종게임SFX 승인/제작이 아니다. 사용자 클릭 뒤만 재생하고 소리 끄기를 제공한다.
- 공개 연출 중 그 카드의 두번째 클릭은 차단한다. 이미 공개된 다른 카드는 선택할 수 있으며 선택하면 남은 공개 연출의 후속콜백을 무효화한다.
- 다시보기/키보드 클릭/모션 줄이기/작은폭재배치 지원. 소리/공개·선택 상태를 미리보기의 로컬 상태로 복원한다.

앞면은 이번 연출 미리보기에서 단순한 프레임·임시 Lucide 심볼·한글 텍스트로 표시했다. 최종 앞면 스프라이트는 승인된03보드를 따른다. 뒷면 생성 이미지의 최종픽셀격자·실제1배가독성·Unity Canvas 구현은 아직 검증하지 않았다. 등급3종을 비교하려고 시안에 실버/골드/플래티넘 한 장씩 넣었으며 실제등급추첨이 항상 이렇게 구성된다는 뜻은 아니다.

이번 미리보기는30초카운트다운·시간초과 자동선택·게임단계 전환을 실행하지 않는다. 공개/선택 연출만 확인한다. 게임 적용 시 [증강 담당 기획](https://www.notion.so/3e6389dbfc6881bf9600d5f42fb68a44)의 시간/자동선택 규칙과 연결할 때 추가확인한다. 뒷면 공개가 들어갔다고 기존준비시간/추첨/효과 규칙을 임의변경하지 않는다.

## 실제 확인

- Unity 읽기: ready,6000.6.2f1,Play stopped,compiling=false,domainReload=false. 기존전투씬1개 loaded·active·dirty=false. 새Play/회귀/씬변경 없음.
- Chrome headless 브라우저에서 뒷면3개 이미지 로딩·첫클릭 공개·공개뒤 재클릭선택 확인.
- 한장만 공개한 상태에서 선택완료·다른카드입력차단 확인.
- 다른카드가 공개연출중일 때 기존공개카드를 선택하고,1초 뒤에도 선택상태유지 확인.
- 카드3개 개별공개, 플래티넘오실레이터4개 생성·음소거시추가음없음,360px 가로넘침없음,모션줄이기상태공개/선택 확인. 직접청취품질은 사용자확인필요.
- 브라우저검사에서JS오류없음. 저장상태복원으로 이미선택된시안에 hover검사를 시도한1회타임아웃이 있었고,새브라우저·다시보기 후 최종수정경로 재확인했다.
- [오버 캡처](augmentation_flip_hover_preview.png), [뒤집기 중간](augmentation_flip_mid_preview.png). 최종인라인원본1MB미만, 생성원본과 무손실복사보존.

## 남은 작업

카드뒷면·등급별연출·임시음색에 대한 사용자컨펌. 전체HUD를 Unity에 적용하기 전 로컬Git복구기준을 남기고, 승인앞면/최종심볼/텍스트를 연결하여 실제입력과30초자동선택 경합을 검증한다. 기존HUD승인과 새공개연출승인을 구분한다.

## 스파크 후속 검증

사용자 피드백: 뒤집기 연출은 부드럽고 좋지만 스파크가 더 튀길 원함. 네 변의 빠른 분출·긴 꼬리·작은 사각 불꽃·등급별 개수/거리/수명으로 수정했다. 제목·하단 버튼을 덮는 상하 분출은 제한하고, 가장자리에서 화면 너비를 넘는 분출은 시안 영역에서 잘라 가로 스크롤이 생기지 않게 했다.

Chrome 브라우저 확인: 실버14/골드30/플래티넘72개 관측,1.1초 뒤 제거,레이캐스트방해없음(pointer-events:none),한장공개후선택유지,360px 넘침없음,모션줄이기스파크없음,JS오류없음. 수정중 데스크톱 가로넘침 발견후root영역clip으로 수정·재확인. [최종플래티넘스파크캡처](augmentation_sparks_platinum_v2.png). Unity·게임코드·씬·노션 변경/새Play/회귀 없음. 이번 후속에서 Unity상태를 새로조회하지 않았다.

## 뒷면 등급 표시 정정

이전 수정의 등급 심볼+글자 방식은 사용자 후속 정정으로 폐기했다. 최종은 글자 없는 뒷면 아트이며 은빛 얇은 테두리/금빛 보강테두리/청백색 이중테두리·잔광으로 구별한다. 카드 내부의 클릭 안내판도 제거했다. 첫 클릭 공개/재클릭 선택/전체공개전선택/스파크는 유지했다. Chrome에서 뒷면3개의 가시텍스트가 모두 빈 문자열이고 배지0개,테두리3종이 서로다름,골드공개→선택,JS오류없음을 확인했다. [최신 글자 없는 뒷면](augmentation_back_unlabelled_v4.png). 공통 원본 이미지 위의 장식은 미리보기의 UI 레이어이며 최종 독립스프라이트3종 제작완료로 기록하지 않는다. 게임 미적용.


## 적용 승인과 실행 시점 (2026-10-13)

사용자가 현재 밸런스 테스트 종료 후 전체 HUD 적용을 지시했다. 최신 글자 없는 등급별 뒷면, 첫 클릭 공개·재클릭 선택, 전체 공개 전 선택, 강화 스파크와 등급별 사운드를 포함해 적용한다. 적용 허락을 다시 요청하지 않는다. 테스트 채팅 보스 스프라이트 제작(01a13155-b8c7-7733-9b9d-851a4ec01fa9)의 작업 완료와 결과 보존을 확인한 뒤 Unity 변경을 시작한다. 후속 자동 확인 hud를 이 HUD 채팅에 등록했다. 현재 Unity 적용 완료를 의미하지 않는다.
