# HUD 스프라이트 교체 시안

2026-10-13 (Asia/Seoul). 사용자 요청: HUD를 제대로 된 2D 스프라이트로 교체하기 전 각 시안을 먼저 승인받는다. 모든 기능은 심볼+글자로 구성하며 마우스 오버·클릭 반응을 제공한다. **현재는 승인용 시안이며 게임 적용·상호작용 구현 완료가 아니다.**

## 1. 현재 구조와 확인 근거

- 시작 시 인수인계, HUD 소스, 아트 색감 문서, 기존 HUD 분석을 읽었다.
- Unity 실시간 조회: CD / Unity 6000.6.2f1 / ready / compiling=false / domainReload=false / Play stopped. 전투 씬 하나가 active·loaded, isDirty=false. 새 Play를 시작하지 않았다.
- `CoreGuardianHud.cs`는 런타임 uGUI를 생성한다. 단색 Image 배경과 한글 Text 중심이며 숫자용 TMP는 별도다. 버튼에는 기존 Unity Button 기본 전환이 있으므로 반응이 전혀 없다고 단정하지 않는다. 별도의 일관된 스프라이트 상태 세트와 행동 성공 연출은 확인되지 않았다.
- 2026-10-13 `hud_controls_20261013.png`를 직접 확인했다. 이는 설치/배속 진단 당시의 과거 화면이며 이번 실행 화면이 아니다.
- 최신 Notion 직접 조회: [HUD](https://www.notion.so/3df389dbfc68811f9a87e5a5ff05a571), [플레이어 성장](https://www.notion.so/3e6389dbfc68811283ffe9b73d0f0da8), [증강](https://www.notion.so/3e6389dbfc6881bf9600d5f42fb68a44). 가격·증강 규칙의 소유 문서는 그대로 둔다.

## 2. 확인된 차이와 디자인 판단

- 확인 데이터: 현재 상태·강화·설치 버튼 대부분이 글자만 사용한다. 피해 목록도 이름/숫자/막대이며 개체 심볼은 없다. 플레이어 강화에는 구매 전 현재→다음 값이 없다.
- 확인 데이터: 타워 상세와 증강 화면에 독립 접기가 없다. 현재 일반 접기 버튼은 삼각형 글자만이다.
- 주관적 판단: 짙은 금속 바탕과 밝은 한글, 단순한 황동 모서리, 제한된 청록 강조가 현재 요새 설비와 연결된다. 촘촘한 돌무늬나 번지는 발광은 가독성에 불리할 수 있다.
- 미검증: 생성 시안의 픽셀 격자·최종 1배 아이콘 판독·게임 위 명암·사람 조작 체감. 고해상도 픽셀풍 시안만으로 최종 스프라이트 일치를 승인하지 않는다.

## 3. 정보 우선순위와 시안 구성

| 보드 | 구성 | 핵심 표시 |
|---|---|---|
| 01 상태·기본 조작 | 코어/라운드/골드/수정/증강, 준비 시간, 설치/시작/플레이어 강화/취소/접기, 재시작/테스트 배속/역할 검증 | 필수 상태 유지, 모든 기능 심볼+한글 |
| 02 설치·강화 | 공격/지원 분류, 실제 포탑 3종, 플레이어 강화 4종, 선택 타워 강화/파괴·환급 | 대상 이름/ID, 재화 심볼+종류+가격, 부족 사유 |
| 03 전투·증강 | 개체별 피해 목록, 보스 상태, 실버/골드/플래티넘 카드, 완료·패배 피드백 | 피해 숫자는 막대 위, 카드 효과 심볼+이름+설명 |

타워 아이콘은 기능을 식별하는 심볼 시안이다. 현재 유닛·몬스터 아트를 교체하거나 검토하는 작업은 아니다. 지원 타워는 직접 피해 집계에 넣지 않는다. 증강 카드 예시는 실제 기획의 계열/효과를 사용하되 실버·골드·플래티넘이 한 화면에 반드시 나온다는 뜻은 아니다.

## 4. 배치안 3개

- A: 기존 상단/하단 진입 위치와 독립 패널 유지. 스프라이트 외형, 심볼+글자, 상태 반응과 강화 비교를 추가한다.
- B: A의 표현을 쓰되 타워 상세를 왼쪽 아래로 이동한다. 적 진입 시야는 확보할 수 있으나 설치 메뉴와 동시 노출 간격 검증이 필요하다.
- C: A에 작은 플레이어/선택 타워 스펙 요약 두 줄을 추가한다. 패널을 닫아도 읽을 수 있으나 상시 면적과 주의 분산이 늘어난다.

## 5. 상태별 반응 제안

| 상태 | 스프라이트·움직임 제안 | 의미 |
|---|---|---|
| 기본 | 어두운 철판/황동 모서리, 밝은 글자 | 조작 가능 |
| 마우스 오버·키보드 포커스 | 0.08초 내 테두리/심볼 밝기 상승, 크기는 유지 | 현재 조작 대상 |
| 누르는 중 | 표면과 심볼/글자가 논리 1px 내려간 눌림 프레임 | 입력 중이며 아직 성공 확정 아님 |
| 선택 유지 | 청록 테두리와 체크/선택 문구 | 설치 대상·분류·열린 패널의 유지 상태 |
| 사용 불가 | 회색 표면, 잠금 심볼+사유 | 재화 부족/단계/선행 조건을 텍스트로 구별 |
| 행동 성공 | 성공 결과 확인 뒤 0.12~0.2초 확인 강조, 필요한 짧은 변화량 문구 | 구매/설치/선택이 실제로 성공했음 |
| 실패 | 성공 강조 없음. 읽을 수 있는 사유 | 증가량/보상 거짓 표시 방지 |

사용 불가 버튼은 오버 시 사유만 읽을 수 있고 눌림·성공 반응은 발생하지 않는다. 전투 진행 같은 상태 표시는 조작 버튼과 시각적으로 구별한다. 코어 경고는 실제 위험 상태일 때만 적용한다. 타워 파괴에는 차분한 붉은 심볼+글자를 쓴다. 접기/펼치기에도 삼각형+한글을 넣고 접기는 표시만 변경한다.

## 6. 추천과 제작 경계

A를 추천한다. 기존 조작 위치를 유지하면서 이번 요청인 아트 교체와 반응에 집중할 수 있다. 통합 전투력은 제안하지 않는다.

이번 보드는 imagegen 내장 도구로 만든 래스터 디자인 시안이다. 채택 후 글자를 제외한 투명 PNG 심볼·9-slice 프레임·버튼 상태를 분리 제작한다. 제안 규격은 심볼 16/24/32px, 공통 논리 1px 테두리, Point 필터/무압축/mipmap 없음이다. 최종 규격은 실제 게임 1배/정수 확대 비교를 거쳐 확정한다. 한글은 동적 텍스트로 유지하며 숫자용 Pixelify Sans를 한글용으로 확대 적용하지 않는다.

강화 전후 비교, 성공 변화량, 추가 접기와 반응은 이번 제안이며 현재 구현이라고 주장하지 않는다. 결과 시간 표시/계측은 이번 외형 교체 범위에 새로 추가하지 않는다. 현재 명중/처치 골드 표현은 기존 담당 [효과 아트 문서](../../art/combat_art_style_20261010.md)로 연결한다.

## 7. 승인 후 검증

- 1920×1080 및 1280×720에서 심볼/한글/가격/긴 이름이 분리 판독되는지 확인.
- 16:10/울트라와이드에서 패널에 붙은 접기 탭이 화면 밖으로 나가지 않는지 확인.
- 준비/전투/증강 단계, 부족 재화, 지원 선행 조건에서 비활성 사유와 입력 차단 확인.
- 실제 마우스 Enter/Exit/Down/Up, 클릭 드래그 취소, 연속 구매, 포커스, 닫기/재열기 상태 복구 확인.
- 설치 선택을 유지한 접기와 Esc 취소 구별, 전투/WASD 지속, HUD 레이캐스트 영역 확인.
- 증강 등급/효과/30초 표시와 상단 필수 정보, 선택/자동 선택 이후 반응 확인.
- 사람이 읽기 쉬움·눌림 감각을 확인해야 아트/UX 승인으로 기록한다.

게임·씬·프리팹·Notion 변경 및 테스트 재실행 없음. 기존 Git에서 인수인계 수정과 vendor 폴더 접근 제한에 따른 삭제 표시를 관측했으며 사용자 변경으로 취급해 보존한다. 게임 변경 전 복구 기준/완료 커밋은 승인 후 구현 단계에서 수행한다.

## 시안 검사와 수정

- 01: 상태 5종과 준비 시간, 기본 조작/진단 버튼, 기본·오버·누름·선택·불가 표현 및 빈 프레임 확인. 최종 눌림 이동량은 실제 입력 검증 전이다.
- 02 초기안: 단일 포탑 수치가 플레이어 수치로 복제되어 편집 요청. 단일 포탑 표시 공격력13→15, 공속1.2→1.4, 투사체6→9, 사거리3.5→4를 지정했다. 지원 포탑은 사거리1→1.5와 지원효과20→22.5%만 표시한다. 파괴 환급은 수정이며 별도 행동 버튼이 아닌 설명으로 정정 요청했다.
- 생성된 문자/픽셀 배율은 최종 제작에서 다시 정렬한다. 외형 보드의 구획/크기는 전체 게임 화면 배치를 뜻하지 않는다.
- 02 수정본 직접 확인: 단일 타워4행 수치·수정 환급 설명·지원2행 반영. 하단 작은 장식 캡션에는 생성 문자 오류가 남으며 승인 대상은 기능 영역의 외형이다. 최종 텍스트는 게임의 한글로 다시 연결한다.
- 03 직접 확인: 피해1위 대비100/50/25% 길이와 숫자 위치, 카드3개 등급/효과, 보스·완료·패배 표현 확인. 백분율은 피해 점유율이 아니라 1위 대비 막대 비율이다. 지원 포탑은 집계에서 제외. 오버 발광을 최종 픽셀 프레임으로 분리할 때 번짐 없는 격자로 정렬한다.
