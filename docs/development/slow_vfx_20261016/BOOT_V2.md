# 둔화 표식 V2 — 장화와 아래 화살표

2026-10-16. 사용자가 모래시계 의미를 지적하고 제안한 신발/발 모양을 반영했다. 장화 옆에 아래 화살표를 두는 안을 제작하도록 요청했다. V1은 보존했다.

- `preview_boot_v2.html`: 장화의 발목·앞코·밑창과 아래 화살표. 적용 시 화살표가 정수2도트 내려오고 유지 중 멈춘다. 해제 시 fade. 기존 원본 병사3종, 대상 선택, 동일1/4배 비교와 재생 조작 보존.
- `slow_boot_v2.png`: 18×14 투명 캔버스. 실제 장화9×10, 오른쪽 화살표5×6와 어두운 윤곽. Canvas 원본 좌표를 읽은 `render_boot.ps1`로 정적 유지 프레임을 생성했다. 단순 도형/아이콘의 코드 기반 제작이며 이미지 생성 도구는 사용하지 않았다.
- `boot_preview_v2.png`: 아이콘8배 확대. `monster_comparison_boot_v2.png`: 기존 병사3종과 표식을 모두 같은 Nearest4배로 합성한 정적 비교. 두 PNG를 직접 열어 확인했다. 병사 원본 픽셀은 변경하지 않았으며 아직 사용자 아트 승인 전이다.
- 적용/유지/해제/종료, PNG3개 포함, 원본/표식 비교6개, 단계 프레임4개, 버튼/대상 선택/정수 확대/alpha 범위는 기존 verify.cjs에 V2 경로를 주어 새로 확인해 passed. 모의 Canvas 검사이며 브라우저 실제 재생을 확인한 것은 아니다.
- HTML의 로컬 파일 브라우저 접근 제한은 이전과 같아 다시 시도하거나 우회하지 않았다. PNG 정적 검토와 실제 게임에서의 보행/체력바/다른 버프 겹침 검증을 구분한다.
- 게임 미적용. Unity 연결/Play/빌드/실행 없음. 게임 코드·씬·CSV·프리팹·기준 아트 변경 없음. 연출 시간은 시안용이며 전투 규칙이 아니다.
