# 둔화 VFX 첫 시안

2026-10-16. 사용자 선택: 평상시 효과는 작게, 보스 가속/코어 피해만 강조. 첫 묶음에서 둔화 하나의 분리된 프리뷰를 제작했다. 게임 미적용·아트 승인 전이다.

- `preview.html`: 의존성 없는 Canvas 픽셀 애니메이션. 적용0~0.24초의 작은 사각 펄스, 유지 표식, 1.25~1.5초 해제. 시간은 연출 시안이며 둔화 규칙을 변경한 값이 아니다. 자동 반복 없이 버튼으로 재생한다.
- 9×9 픽셀의 작은 기계식 모래시계 문양, 어두운 윤곽/차분한 청록. 얼음/몸 전체 틴트/화면 후처리 없음. 색과 형태는 제안이며 미승인이다.
- 현재 공격형42×64/수비형33×48/버프형35×80 PNG를 변경 없이 base64로 포함했다. 대상 선택으로 원본/표식 적용을 나란히 비교하며 양쪽에 동일한1배/4배 Nearest 확대를 적용한다. 화면 배치는 프리뷰용이며 게임 월드의 최종 위치가 아니다. 보행·체력바·기존 버프 표식이 섞인 전투 가독성은 아직 확인하지 않았다.
- MONSTER_ART_STYLE.md와 실제 병사3종/지정 비교판을 직접 열어 확인한 후 제작했다. 고해상도 생성 이미지를 축소한 에셋이 아니라 정수 좌표의 작은 문양을 Canvas로 그린 동작 시안이다. 이미지 생성 도구를 사용하지 않았다.
- `verify.cjs`는 PNG 포함·단계 전환·버튼·대상 선택·정수 확대·alpha 범위를 모의 Canvas로 확인한다. 실제 브라우저 렌더 검증을 대신하지 않는다.
- 로컬 HTML 열기는 브라우저 URL 보안 정책에서 file 프로토콜을 거부했다. 우회하지 않았다. 실제 시각 검토와 게임 연결은 남아 있다. Unity/Play/빌드/실행파일/게임 코드·원본 이미지·씬·프리팹·CSV 변경 없음.

다음: 사용자가 프리뷰에서 크기·형태를 검토한 뒤 실제 체력바·군기·이동 버프와의 겹침을 확인하고 게임 상태 연결 여부를 정한다.
