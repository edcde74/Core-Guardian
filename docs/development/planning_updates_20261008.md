강화 가격의 이어지는 예시는 1~6단계 100, 140, 190, 250, 320, 400골드이다. 능력치별 가격 단계가 독립이고 단계 상한 없음은 기존 규칙을 유지한다.

## 검증 방법과 범위

1. 수정 전 해당 6개 페이지를 live fetch로 읽고 주변 문맥과 정확한 원문을 확인했다.
2. `update_content`의 작은 고유 문자열로만 수정했다. 전체 페이지 교체나 자식 페이지 이동은 사용하지 않았다.
3. 수정 후 6개 페이지를 다시 fetch하고 각 추가·수정 문장을 비교했다. 모든 기대 문장이 존재했다.
4. 문서의 완료/검증 상태 속성을 변경하지 않았다. 이 기록의 재조회 확인은 문구 반영 확인이며 실제 게임 기능 검증을 뜻하지 않는다.

추가 아트 요구사항의 우선순위 보고서는 `art_requirements_20261008.md`에 기록했다. 애니메이션 방향 수와 프레임 수는 현재 승인값이 없어 에셋 제작 전에 확인해야 한다.
