## 3. 원인 가설과 한계

과거 실험의 전제와 현재 후보 데이터가 달라 거부·잘못된 비교가 발생할 수 있다. 소스를 읽은 확인이며 과거 실험을 실제 실행해 실패시킨 결과가 아니다.

HP25→27은 기본 단일 포탑의12.5피해가CombatRules에서13으로 반올림되는 조건에서2발→3발 경계를 넘는다. 정적 계산이며 배치·지원·강화·사람 조작을 포함한 난이도나 재미의 결론은 아니다. 이전HP27의2R탐색 결과는 [기존12회 비교](../early_pressure_test_20261013/report.md)를 재사용하며 새 실측으로 세지 않는다.

## 4. 다음 검증 방법 3가지

1. **사람1배속 결과 먼저 확인**: 최신 후보의 압박과 조작 필요성을 확인할 수 있다. 미기록 조건은 비교하기 어려워 배치·구매·배속·실패 지점을 함께 받아야 한다. 게임 변경 없음.
2. **기존 계측기를 현재 데이터 무변형 모드로 정비해3~9R계측**: 과거2R반복을 줄이고 공용HP의 후반 영향을 추적할 수 있다. 고정 정책이므로 사람 체감의 대체는 아니다. 변경 범위는Assets밖 계측기/새 결과이며 이번에는 아직 수정·실행하지 않았다.
3. **10R보스와11R증강 기록부터 정비**: 정상 전투의 보스 처치/도착·추첨·선택·효과를 연결할 수 있다. 전반에 패배하는 정책은 도달하지 못하므로 경과 비교가 필요하다. 후보 고정·강제 처치로 대체하지 않는다.
