# Unity 구현 ↔ 노션 문서 동기화

2026-10-13 Asia/Seoul. 사용자 요청으로 현재 런타임 소스·실행 CSV·개발 검증 기록과 담당 문서 20개를 대조했다. 비교 기준 HEAD `ba72484`. Unity 코드를 기획에 맞춰 바꾼 작업이 아니라 구현 현황과 승인된 UX를 문서에 반영한 작업이다.

## 최종 범위

- 본문 13개 갱신, 기존 '시작 전' 8개를 '진행 중'으로 변경. 총 16개 페이지에 본문 또는 상태 변경.
- 1~11 진행·10 보스·증강·프로토타입 종료의 오래된 미구현 표시, 승인 보스 정지 외형·HUD 적용 상태와 남은 제작 작업을 정리.
- 증강 첫 클릭 공개/연출 완료 후 재클릭 선택/전체 공개 전 선택, 기존 30초 자동 선택, 등급 글자 없는 뒷면·오버·스파크·합성 사운드 반영. 규칙은 증강, 외형·연출은 HUD, 키 배치는 PC 조작에서 관리.
- 실제 접기는 즉시 숨김·복원/상단 축소이다. 기존 슬라이드·삼각형 목표는 미구현으로 구분. 증강 접기 중 배경 입력 차단은 유지. 다른 종횡비·사람 조작/청취 검증은 남음.
- 레벨의 정적 비교 배치와 실제 준비 단계 설치를 구분. 한글 맑은 고딕과 숫자용 Pixelify Sans를 구분. 데이터 시트 목표와 현재 CSV 열·코드에 남은 수치 정의의 관리 범위를 구분.
- 과거 테스트 기록은 전부 보존하고 최신 기능 검사 결과를 별도 절로 추가. 저장된 EditMode73/73·PlayMode8/8을 인용했으며 이번에 새 테스트·Play·빌드·난이도 계측을 실행하지 않았다.

## 밸런스 제외와 복구

작업 중 사용자가 '밸런스 부분은 아직 건들지말아'라고 범위를 제한했다. 앞서 이번 작업에서 노션에 넣은 체력·생성 간격·새 실험 요약은 취소했다. 적/보스 문서 본문은 조회 원문과 완전히 같고, 편성표의 모든 수치 표도 원문과 같다. 재화·성장 수치도 변경하지 않았다. Unity CSV·소스·씬·프리팹·프로젝트 설정은 변경하지 않았다. 이 때문에 실행 CSV와 기획 수치 사이의 차이를 이번 동기화가 해결한 것으로 해석하지 않는다.

`initial_proposal.json`은 범위 제한 전의 수정안·원문 이력이며 최종 기획이 아니다. `verified.json`의 before/after와 검증 결과가 최종 상태다.

자동 승인 검사가 웨이브 전체 교체 및 새 밸런스 요약 취소를 거절했다. 웨이브는 기존 블록을 유지하는 국소 수정으로 처리했고, 이력은 삭제 대상 두 문장이 이번 작업의 추가분이며 기존 이력 전체가 보존됨을 먼저 비교 입증한 뒤 취소에 성공했다. 미해결 차단 없음.

## 최종 읽기 확인

- 변경된 16개 페이지를 다시 fetch하여 저장 본문·속성을 확인했다. 이전 문서 링크와 이미지 모두 보존, 수치 표 복구와 새 밸런스 문장 제외 확인.
- 20개 조회는 게임 루프·웨이브·편성·적/보스·HUD·증강·성장·타워·재화·플레이어·피해·레벨·효과 아트·추가 아트·후속 작업·테스트 이력·PC 조작·데이터 명세·게임 개요·프로젝트 루트다. 엑셀 원본 동기화·Android 실행·전체 노션 워크스페이스 감사를 완료한 결과는 아니다.
- 종료 에디터 ready, Play stopped, compiling=false, domainReload=false. 전투 씬 active/loaded/dirty=false. Git의 Assets/Packages/ProjectSettings diff 없음. 다른 작업의 음악·분석 파일과 vendor 파일은 보존.
