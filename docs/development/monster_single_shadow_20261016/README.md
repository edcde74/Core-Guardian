# 몬스터 고정 발 그림자 정리

2026-10-16. 사용자가 중앙 큰 그림자 외 발 아래 두 원이 보행과 어긋난다고 지적했고, 중앙 그림자만 유지하는 수정에 동의했다. 복구 기준 HEAD: `72c771d`.

## 원인과 변경

프리팹의 `바닥 밀착선`은 원본 발 영역을 잘라 납작하게 표시한 별도 SpriteRenderer다. 공격형은 원본 PNG의 (13,0,26,5) 영역을 사용한다. 원본 정지 자세에 고정된 이 표시가 움직이는 양발과 분리돼 보였다.

`CoreGuardianOriginalWalk`가 몬스터 보행을 연결할 때 해당 렌더러만 비활성화한다. 병사3종에 적용되며 보스의 해당 렌더러는 원래 비활성이다. 중앙 그림자는 같은 중심의 바깥/접촉 타원 두 레이어로 이루어진 한 실루엣이며, 둘의 표시 여부·위치·배율·색·스프라이트를 그대로 유지했다. 새 발 그림자를 추가하지 않았다.

원본 PNG·프리팹·씬은 수정하지 않았다. X/Y 보행·발 기준점·플레이어·포탑·VFX·밸런스도 변경하지 않았다. 원본 프리팹을 직접 놓은 아트 비교용 정지 오브젝트는 기존 상태를 유지하고, 실제 전투 생성 경로의 애니메이션 연결 시 적용한다.

## 검증

- 연결 프로젝트 CD, Unity6000.6.2f1, URP. 시작 전 전투 씬 active/dirty=false·Play중지/컴파일false 확인.
- 재컴파일 completed, failed=false, 오류 없음.
- 기존 `CoreGuardianOriginalGaitTests`: EditMode15/15 completed. 양발·상행 폭·지면 기준점·방향 전환 회귀 확인.
- 기존 `CoreGuardianAnimationPlayModeTests`: PlayMode3/3 completed. 정상 웨이포인트 X±/Y± 실제 표시·플레이어 발사·포탑 원본 보존 확인. 이번 전체 회귀 실행은 아니다.
- `CaptureShadows.cs`: 수정 전/후 실제 Unity PreviewRenderUtility로 4역할×4방향×24프레임 캡처. 중앙 타원 렌더러의 상태·위치·배율·색·스프라이트 동일 및 수정 후 고정 발 표시 비활성 검사 통과. 전투 씬 녹화가 아닌 격리된 프리팹 애니메이션 비교다. 전체 격자 마지막 행 보스 발 끝은 캡처 경계에 걸려 있으므로 보스 접지감의 시각 검증 자료로 사용하지 않는다.
- [같은 배율·같은 프레임 공격형 전후 영상](comparison.webp), [정적 비교](comparison.png). 좌 수정 전/우 수정 후, 각각 위 X+/X-, 아래 Y+/Y-. 원본 캡처 자르기만 사용했고 재디자인/리샘플링 없음.
- 최종 전투 씬active/dirty=false, Play=false/paused=false/컴파일false, TimeScale1/captureDelta0. 사용자 Play 중단 없음. 빌드/게임 실행파일 실행/push/Notion 수정 없음.
