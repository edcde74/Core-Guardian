# 보스 하행 상하체 연결 · 방패병 상행 다리 간격

2026-10-17 사용자 피드백: 앞선 보스 Y− 상하체가 부자연스럽고 방패병 Y+ 다리 간격이 좁다. `05d8671`의 기능 통과를 자연스러움 승인으로 취급하지 않는다. 이번 복구 기준도 `05d8671`; 수정 전 게임 추적 파일/staged 변경 없음, Unity stopped/compilingfalse/전투씬1·dirtyfalse 확인.

## 실제 수정

- **보스 Y−:** 이전에는 매 프레임 다른 상체/장비에 Down0 골반 천을 붙여 허리 형태와 장비 위치가 어긋났다. 실제 표시되는 상체·장비·골반 천을 기존 Down0의 한 자세로 통일하고 함께0~0.75원본px 체중 이동을 준다. 기존 정강이/부츠의 양발 교대는 유지하며 발 중심 간격13→10원본px로 골반 아래에 모았다. 원본 이미지를 다시 그리거나 다른 화풍으로 대체하지 않았다. 실제 상체는 이제4개 자세를 교체하는 방식이 아니라 같은 원본 자세의 연속 이동이다. `VerticalWalk.sprite`의 기존4장 선택은 추적/방향 메타데이터로 남으며4종의 실제 상체가 보인다는 근거로 쓰지 않는다.
- **방패병 Y+:** 원래 뒷모습의 다리가 겹치는 구도를 상행 전용 양발 분리로 바꿨다. **Up0 뒷방향** 정강이·뒤꿈치/부츠를 사용하며 앞모습/옆모습 다리를 가져오지 않는다. 발 중심은 원본 피벗 기준(-4,+5), 간격9원본px로 넓혔다. 머리/등/골반 천/방패는 같은 뒷방향 자세로 연결하고 보스와 같은 작은 체중 이동을 사용한다. 두 발3.5px 리프트·반 주기 교대·정지0을 유지한다.
- 방패병 Y−, 보스 Y+, 창병/군기병, X축, 원본PNG·파생PNG/프리팹/씬/경로·이동속도/그림자/체력바/HUD/VFX/전투 수치는 변경하지 않았다. 런타임 분리 영역/표시만 수정했다. 공통 몬스터 아트 문서·기준3종 실제 PNG와 비교판을 먼저 직접 확인했다. URP인 것을 읽기 확인했으며 카메라/필터/패키지는 변경하지 않았다.
