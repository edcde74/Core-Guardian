# 로컬 Git 초기 구성 기록

- CD 루트와 상위 경로에 Git 저장소 없음 확인. Git 2.43.0.windows.1 사용.
- 별도 `HUDDesigner/.git` 발견. 수정·삭제·원격 연결 없이 보존하고 CD 추적에서 제외.
- Unity 전용 `.gitignore` 추가. Assets/.meta, Packages, ProjectSettings, 문서·아트 시안은 추적하고 캐시·빌드·로컬 설정만 제외.
- 기존 작성자 설정 `edcde74` / `edcde74@gmail.com` 사용. 전역 설정은 변경하지 않음.
- 로컬 main 브랜치 초기화, 파일 바이트 보존을 위한 저장소 한정 core.autocrlf=false.
- 작업 지침에 기능 수정 전후 복구 기준 커밋 기록 추가. 자세한 사용법은 [LOCAL_GIT.md](LOCAL_GIT.md).
- Unity 코드·씬·프리팹·메타 변경 없음. Unity 실행·저장·컴파일 상태는 이번 작업에서 검사하지 않음. 인수인계의 이전 Unity 검증 상태는 과거 기록으로 유지.
- 커밋 전 검증: 인수인계 수정 파일을 제외한 기존 Assets·Packages·ProjectSettings·docs 1,325개 파일의 SHA256 일치, 삭제/변경 0. Unity 소스·설정 추적 누락 0. 제외된 해당 경로 파일 341개는 모두 Python 캐시. 추적 파일 총1,015개, gitlink 0, 원격 설정 없음 확인.
- 기존 Unity 메타의 빈 필드 등 공백 경고는 원본 보존을 위해 수정하지 않음. 이번 변경은 게임 동작을 바꾸지 않으므로 게임 테스트를 재실행하지 않음.
- 커밋 후 저장소 무결성·작업 트리·원격 설정 검사를 수행한다. 초기 커밋 ID는 `git log --reverse --oneline`으로 조회한다.
