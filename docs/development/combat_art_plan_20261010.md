# 승인된 전투 아트 적용 계획

사용자 승인: B 금속 스파크, 기술병 E2 금속 부품 탄, 피해 숫자 Pixelify Sans Bold.

1. 투명 정지 원본에서 에디터 API로 9개 스프라이트를 분리한다. Point 필터, 압축·mipmap 없음. 원본 프리팹과 카메라는 보존한다.
2. 정적 Bold 700 TTF와 OFL을 프로젝트에 포함하고 TMP 숫자 폰트·외곽선 재질을 생성한다. 한글 HUD는 교체하지 않는다.
3. 실제 투사체와 버프 대상 표식에 아트를 연결한다. 피해 이벤트에서 피격·처치·즉시 골드 피드백을 표시하고 코어 감소 시 코어 피격을 표시한다.
4. 미확정 보행·발사 프레임 애니메이션을 제작하지 않는다. 승인 정지 스프라이트의 짧은 표시·투명도 전환만 연결한다.
5. 실제 씬에서 TMP 숫자, 투사체 3종, 버프 대상, 처치와 코어 도착의 차이, 효과 정리·재설정과 1라운드 회귀를 검증한다.
