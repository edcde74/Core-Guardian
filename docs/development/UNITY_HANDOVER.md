## 남은 작업·배포 주의

2026-10-16 사용자 최신 VFX 방향은 **현재 기본 공격의 타격/시각 피드백 우선, 사운드 제외·별도 파트 검토**다. 기술병/단일/범위 포탑의 [타격 시안3종](hit_vfx_20261016/README.md)을 분리 제작했다. 단발/집중 공격GIF6개·투명6프레임 시트3개·포스터/단계 비교 제공. 원본 병사와 같은 도트3배로 정적 검토했고 다중프레임 인코딩·효과 종료 복원·숫자 합산 보존을 로컬 렌더러로 확인했다. **게임 미적용·아트 미승인**, 실제 Unity 전투·성능 검증 아님. 표시 제한100ms/숫자 묶음200ms는 미확정 후보. 게임 코드/씬/수치 변경·Play/빌드/실행 없음.
