- 적 본체 풀은 위 최신 승인 후 반영했다. [적 본체 풀 정본](enemy_body_pool_20261021/README.md)의 초기화/회수·보관 상한과 검사 보류 경계를 읽고 중복 구현하지 않는다. 기존 표시/Session 재사용도 반영 상태다. 새 후보는 현재 코드와 비용 근거를 확인한 뒤 기존 품질/밸런스를 유지하는 범위에서 정한다.
- 사용자가 검사 재개를 요청하면 이번 변경의 대상 QA·동일 입력/시드 이벤트 동등성·풀 피크/정리·같은 조건 Profiler 전후부터 확인한다. 사용자 보고로 본체 공유의 깜박임·잘림·방향 이상 없음은 기록했으며, 새 풀링/Session의 실제 동작·정상30R/수십분·GPU VRAM/Memory Profiler는 미검증이다.
- 다른 해상도/줌/회전·사용자 투영으로 공유 범위를 확장하려면 같은 조건 픽셀·비용부터 확인한다. 제한 밖은 기존 합성이다. 알려진 픽셀 차이를 품질 절충으로 임의 허용하지 않는다.
- 보스 전체 합성 미확정9건과 원래 순간 지연은 별도다. 재현 시 기존 세분화 마커를 추적한다. 목표 FPS/기기/배속 예산은 미확정이다.
- 표시/HUD·Session·탄환 표시와 적 본체 풀링의 최신 승인/반영은 각각의 정본을 따른다. 모델 객체 풀링과 전역 설정·품질 절충은 미적용이다. 다음 조작 전 사용자 Play/다른 검사와 현재 diff를 확인하고 중단·중복하지 않는다.
