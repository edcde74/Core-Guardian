## 현재 작업
사용자는 **공통 리소스 참조를 먼저 적용**하도록 지정했다. `b77b0df` 기준 마스크 생성/윤곽/접촉 그림자 재질을 참조 수로 공유하고 개체별 값을 PropertyBlock으로 분리했다. 현재128적/15포탑에서 소유 재질677→3, 해당 엔진 메모리1,829,568→8,032bytes(-99.561%), 최종100프레임×3의 평균FPS28.123→30.083(+6.970%)를 관측했다. **Draw Calls/SetPass 감소는 없으며 전체 성능 통과가 아니다.** 최종 계약17/17·효과 픽셀3,456건 차이0. 첫 구현의 악화/보완·수명 관측 버전 구분·실패·원본은 [공통 재질 결과 정본](shared_mask_materials_20261021/RESULTS.md)을 따른다. 본체 RT 공유는 미구현이다.

사용자는 다음 순서 중 **1번 PhotoShadow 순간 지연 원인 조사**를 승인했다. `77aebb9` 기준 제품2파일에 세분화 마커12개만 추가했다. 전후100프레임×3/추가300×3에서 원래162.609ms는 미재현이며 원인 해결이 아니다. 정상 그림자 약11.3ms 중 접촉 마스크 경로 약8.7~8.8ms를 분리했다. 마커 후 평균 프레임은 관측상 증가했다. 기존 그림자10/10·아웃라인3/3, 설정3파일 해시 보존을 확인했다. 원본·오프라인 분석 실패/보완·잔류 한계와 다음 행동은 [진단 결과 정본](photo_shadow_diagnostic_20261021/RESULTS.md)을 따른다. 동일 본체 마스크 공유 구현은 이번 범위 밖이다.

사용자는 SetPass/Draw Calls 감소를 우선 지정하고 진단 후 같은texture/opacity 메시 묶기 구현을 승인했다. `eba2b8e` 기준 후보 검사는4/4, 효과 픽셀3456건 차이0이었으나 실제128적/15포탑에서는 묶인 소유자0개로 Draw Calls3208/SetPass1608 모두 절감0%였다. 후보 제품3파일을 원복했다. 원복 후 검사 요청은 완료 결과 없이 남아 자체 요청만 취소했으며 재통과로 주장하지 않는다. [실험·실패·원본·복원](mask_batch_20261021/README.md).

이후 **계속 진행해** 승인으로 마스크 전용 배열 아틀라스를 구현했다(`5531f70`, 최종 정리 커밋 별도). 2D 페이지는 픽셀 차이로 폐기하고 원본 UV를 유지하는92원본/9배열을 적용했다. 동일128적/15포탑100프레임×3에서 Draw Calls3208→2178(-32.107%), SetPass1608→578(-64.055%). 새 계약2/2·기존 아웃라인3/3·최종 효과 픽셀3456건 차이0을 확인했다. **p95/일부 최저 FPS는 악화했으며 FPS·반응성/전체 성능 통과가 아니다.** 수명600프레임×3과 native 잔류 한계·실패·원본은 [현재 결과 정본](mask_atlas_20261021/RESULTS.md)을 따른다.

사용자 승인으로 잔여 자동 검증을 진행했다. 보행 PlayMode6/6, 효과 출력 픽셀3,456건 차이0, 실제 씬128적/15포탑600프레임×3회에서 초기화 후RT274→3개/305,992bytes를 확인했다. 테스트의 낡은 준비 조건만 수정했고 제품 소스/셰이더/씬/밸런스 변경은 없다. 보스 본체까지 합친9건 차이는 원본끼리 대조군에서도 재현돼 판정 미확정이다. [실패·보완·원본·한계·복원](mask_validation_20261021/README.md).

문서 경량화와 단독 **인수인계** 단축 지시는 적용 상태를 유지한다. [경량화 기록](context_efficiency_20261021/README.md), [단축 지시 등록/백업](context_efficiency_20261021/handoff_alias.md). 자체 Play/검사만 수행·종료했고 빌드·실행파일·push는 하지 않았다.

## 미완료와 다음 행동
- 배열 아틀라스는 적용, 동일 본체 마스크 공유·표시/HUD 풀링·Session 탐색 감소는 미적용이다. 첫 항목 승인으로 후속을 확대하지 않는다. 목표 FPS/기기/배속 예산도 미확정이다.
- 보행 실행0건은 이번에 재현되지 않았다. 줌/해상도/겹침의 효과 출력은 검사했으나 보스 본체 전체 합성 비교·수십분/정상30R·GPU VRAM/메모리 스냅샷은 남는다. 제한된3회 관측을 장시간/전체 성능 통과로 확대하지 않는다.
- 최신 종료는 전투씬1/dirty=false·Play/pause/compile/update/Profiler/Driver/Deep/FrameDebugger=false, background=false·카메라8.5다. 설정3파일은 이번 시작 해시와 같다. 공유 재질0/lease0, 기존 이름 기준 배치 메시6/native RT35는 픽셀 전후 동일하며 일괄 삭제하지 않았다. 전역 누수 통과가 아니다. [종료·설정·잔류 정본](shared_mask_materials_20261021/RESULTS.md).
- 원래 PhotoShadow 순간 지연은 미확정이다. 세분화 마커를 유지해 재현 시 경로를 확인하고, 정상 반복 비용의 다음 후보인 동일 본체 마스크 공유를 검토한다. 호출 감소를 FPS 성공으로 확대하지 않는다. 보스 전체 합성·실게임 중첩·장기/입력 검증과 HUD/Session은 후속 범위다. [아틀라스 구현/검증](mask_atlas_20261021/RESULTS.md). 실행 직전 사용자 작업과 diff를 재확인한다.
