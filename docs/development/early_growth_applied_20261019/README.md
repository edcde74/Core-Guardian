시작 설치 후 별도 지출 없이 전원 처치하면 첫 플레이어 강화는 **2R전투 중**(2R까지93골드), 포탑 첫 강화는 **3R준비**(2R완료 수정40)부터 가능하다. 시작 설치비100을 내고 남은 수정0에서 계산했다. 첫 두 라운드에서 모두 구매할 수 있다는 뜻은 아니다. 추가 설치만 저축하는 경우 기존 6R준비가 유지되고, 먼저 강화하면 추가 설치는 늦어진다. 같은 플레이어 능력치3회 누적은410골드, 세 능력치 첫 강화는240골드다. 구매 가능 시점의 정적 계산이며 새로운 정상 전투 계측은 아니다.

`stage.csv`에 `playerFirstUpgradeDiscount,20`/`towerFirstUpgradeDiscount,40`을 추가했다. CombatData.Load는 누락 시0으로 읽어 기존 입력과 호환하며 무료/음수 가격을 만드는 할인은 거부한다. 기본 가격 필드는100/80으로 남기고 첫 단계에서만 할인해 후속 가격을 보존했다. 실제 HUD 표시는 기존 Session 가격 API를 사용한다. 새 UI는 추가하지 않았다.
