# 정적 계산과 계측 해석 전제

이 문서는 수치 적용안이 아닌 현재 데이터 해석이다. 최종 관측은 README와 comparison.json을 따른다.

- 실제 경로 중심선은79타일이다. 보드의 경로 점유80칸과 이동 길이79를 혼동하지 않는다. 첫 포탑(12,13)의 경로 피복 길이는 단일R3.5에서9.3501타일, 멀티R3에서4.4721타일이다. 속도·어그로·대기·투사체를 포함한 실제 공격 시간은 별도다.
- 둘째(14,13)의 멀티R3은 경로와 접하는 점만 존재해 연속 경로 피복 길이가0이다. 단일R3.5는4.7624타일이다. 같은 좌표 비교가 병종별 최적 배치 비교를 보장하지 않는다. 실제 피해가 여러 라운드0인 것과 함께 보되 포탑 자체의 피해 부족으로 단정하지 않는다. 유한 스텝에서 접점에 정확히 놓이면 발사가 가능하므로 영구적으로 공격 불가능하다는 뜻은 아니다. 혼합기본11R에서는 실제30피해가 관측됐다.
- 후반 둘째(16,11)는 단일6.7082/멀티5.6569타일을 덮는다. 단일 증설 baseline→late는 둘째 위치만 달라지는 대조다. 멀티/지원 late는 지원 위치도 달라져 피복과 지원 대상이 함께 달라진다.
- 공격형HP27에서 플레이어 입력10→12는3발→3발,14는2발이다. 첫 공격력 강화의 명목DPS+20%를 적 한 마리 처치 발수 감소와 같다고 하지 않는다. 단일13피해는3발, 첫 강화15피해는2발이다. 지원20%도12.5입력→15로2발 경계를 넘는다.
- 단일 기본 실제 무방어 단일 대상DPS15.6, 첫 damage 강화 후18, 다음21.6이다. 각각 강화80/100수정이 필요하며 새 단일100수정의 이상적DPS15.6과 비교할 수 있지만, 배치/노출 시간·대상/투사체 낭비가 실제 기여를 결정한다.
- 전원 처치 가정 골드100/240/430은3/5/8R전투 중 마련된다. 준비 구매 정책의 실제 구매는4/6/9R가 될 수 있다. 게임은 전투 중 플레이어 강화를 허용하므로 이를 게임의 구매 제한으로 해석하지 않는다. 첫 라운드 준비/라운드 간50초를 건너뛴 자동 계측은 실제 기다림·재미를 측정하지 않는다.
- 증강 추첨의 seed는 정상 생성자에서 미지정이다. 각 회차 초기PRNG상태/후보/선택을 남기지만 서로 다른 자연 추첨의11R을 카드 효과의 인과 비교로 사용할 수 없다.11R편성도10R/9R과 달라 단순 전후 시간 감소를 증강 단독 효과로 쓰지 않는다.
- 강한 증강 성립은 보상이며 결함으로 보지 않는다. 이번 자료는1~11R 한 번의 증강 기회여서 여러 증강 중첩 빌드의 성립·상대 가치·반복 재미는 평가하지 않는다.
