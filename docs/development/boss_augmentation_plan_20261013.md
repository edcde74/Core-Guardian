# 보스·증강·11라운드 구현 계획

사용자 요청: 표시 체감 확인 완료, 보스와 증강 선택부터 11라운드까지 구현.
복구 기준: c2d16f0. 기존 미추적 분석/스킬 파일은 보존하고 이번 커밋에서 제외.

## 기준

담당 노션의 적/보스, 증강, 편성표, 재화, 게임 루프를 2026-10-13 재조회.
규칙의 원본은 각 노션이며 이 문서는 적용 작업만 관리한다.

- 증강: https://www.notion.so/3e6389dbfc6881bf9600d5f42fb68a44

## 작업 순서

1. 기존 테스트에 11라운드/보스 데이터 계약을 추가해 실패 확인.
2. CombatData/CSV: Boss 종 추가, 10·11 일정/보상. 1~9 일정 보존.
3. Session과 별도 Augmentations 모델: 보스 반피 가속/처치 조건, 선택 단계/독립 추첨/중복 제외/시간초과, 18종 카드 효과/재선택 누적, 무피해 조건/코어 최대치/둔화/추가 투사체.
4. 기존 HUD에 중앙 차단형 선택 패널 3장과 남은 시간·등급·효과를 추가. 선택 중 이동/설치/강화/파괴 차단. 보스는 기존 아트 임시 확대·색 구분과 체력/가속 표식으로 표시, 최종 아트 승인으로 처리하지 않음.
5. 보스 처치/도착/패배, 자동 선택, 18종 효과, 지속/새 포탑/재설정과 11라운드 승리 테스트. 기존 회귀 검사.
6. 실제 씬에서 보스/선택 UI 진단 검사. 최신 빌드를 별도 폴더 생성 후 바로 실행, ZIP은 생성하지 않음. 인수인계 갱신/검증 커밋.

## 판단

- 보스 방어/버프 반경은 미정이므로 추가 효과 없이 0 사용. 기본 가속은 .6→.78, 일반 버프와 둔화는 기존 속도에 곱 적용.
- 진단 강제 처치는 흐름·효과 검증에만 사용하며 난이도 실측으로 주장하지 않음.
- 이전 빌드/원본 프리팹/씬 YAML/메타를 직접 편집하지 않음. 현재 에디터 전투 씬 저장/중지 확인 후 시작.
