# Unity 미사용 이미지 리소스 정리 · 2026-10-23

## 요청·결과

사용자 요청: 연결된 스프라이트는 유지, 미사용 리소스 제거, 삭제 전에 복구 커밋, 재사용 가능성이 높은 원본 별도 보고. 후속 지시로 **게임 기록/캡처는 보존**한다.

- **미사용 리소스69개 제거, 약49.54MiB.** 이미지 원본과 해당 `.meta`만 제거했다. 스프라이트 시트/임포트 이미지37개·미참조 효과 텍스처32개다.
- **게임 기록 캡처13개는 삭제하지 않고 이동·보존.** Unity의 Assets/docs에서 [문서 기록 폴더](imported_evidence/)로 옮겼으며 SHA25613/13 동일. 기존3문서의 링크6개 갱신, 유효6/6.
- **연결된 이미지170개 보존.** 씬/프리팹/애니메이션/재질/Tile/커스텀 마스크 아틀라스·런타임 문자열 로드를 포함했다. 원본·`.meta`170/170 해시 동일.
- 소리·폰트·코드·설정·프리팹·애니메이션·씬을 삭제하지 않았다. 사용자의 새 `CG_Enemies` 아틀라스·복구 씬도 보존한다. `CG_Enemies`의 packables는 현재 비어 있다.

Unity Assets에서 빠진 이미지는 총82개지만, 이 중13개는 보존된 기록이다. 이를 게임 리소스82개 삭제로 보고하지 않는다. [최종 분류](final_manifest.json)의 finalDisposition을 따른다. [실행 당시 목록](manifest.json)의 delete는 Assets에서 제거한 작업을 뜻하며 기록13개의 폐기를 뜻하지 않는다.

## 복구 기준

- 작업 시작 HEAD `77df619`.
- 사용자에게 현재 전투씬 dirty를 알렸고 **현재 씬 저장 후 복구 커밋** 승인을 받았다. Unity API로 같은 전투씬에 현재 변경을 저장했다. 비교 씬/새 씬 생성 없음. 기존 사용자 `_Recovery`씬2개는 임의 생성/삭제하지 않고 기존 파일을 커밋에 포함했다.
- **삭제 전 커밋: `5ae39a1ae36595ad19bf9489817f535509a7ca40`** (`Checkpoint before unused sprite resource cleanup`). 사용자 씬·새 아틀라스·기존 Assets 상태와 조사 원본을 포함한다. 개인정보/사용자 설정 변경을 포함하지 않았다.
- 실행 전에 제거 대상82개 원본+meta **164개 Git blob 존재**를 검증했다. [확인](checkpoint.json), [blob 목록](checkpoint_blobs.txt).

필요한 리소스만 복원하는 예:

```powershell
git restore --source 5ae39a1 -- Assets/Art/Hud/20261013/CardBackSource.png Assets/Art/Hud/20261013/CardBackSource.png.meta
```

이 명령은 예시이며 실행하지 않았다. 현재 씬/설정을 통째로 과거 상태로 돌리지 않는다.

## 참조 판정·보존 범위

[Audit.cs](Audit.cs)는 현재 열린 씬의 실제 오브젝트 의존성, Assets 내 직렬화 에셋의 직접 이미지 의존성, 이미지 import 정보·원본/meta SHA256을 수집했다. [분류](Classify.ps1)는 현재 코드의 동적 Resources 가족과 직접 문자열 경로를 추가 보호했다.

- 초기 이미지252개(원본75,888,924B), Sprite가 포함된 이미지200개. `FindAssets(t:Sprite)` 검색 결과 수와 이미지 파일 수를 혼동하지 않는다.
- 기존 직접 참조와 live 참조 외에 HUD33개, 보행/방향/포탑 동작·그림자·CombatB 등 런타임 로더의 전체 해당 프레임을 보호했다.
- 리소스를 많이 지우려고 데모 재질/기존 Tile/다른 프리팹에 연결된 이미지를 제거하지 않았다. 예를 들어 효과 팩의 데모 재질 연결10개는 유지했다. 이는 현재 전투에서10개가 모두 사용된다는 판정은 아니다.
- 이름·모양만으로 미사용/승인 여부를 판단하지 않았다. 과거 거절 애니메이션4개 및 미참조 Animation/{Attack,Defense,Buff,Boss}/atlas.png4개는 현재 로더/직렬화 참조가 없어 제거했다. 현재 OriginalWalk/OriginalMotion/PlayerFacing/VerticalWalk는 유지했다.
- 독립 읽기 검토: 삭제 후보의 외부 meta GUID 참조0·직렬화 텍스트 GUID 참조0, 동적 코드 경로 차단 항목 없음. 테스트/Play를 실행한 검토는 아니다.

## 별도 재사용 후보와 다음 행동
