- 발 중심은 원본 좌우 정강이 레이어 각각의 맨 아래2개 불투명 행에서 발바닥 가로 경계 중점을 구해 월드 변환한 뒤 두 발의 중점을 사용했다. 그림자는 바깥 타원 렌더러 중심을 사용했다. 보행48샘플 평균과 우보행 후 정지를 별도로 측정했다. 무기/깃발 포함 전체 이미지 경계 중심으로 판단하지 않았다.
- [실제 비교](rest_left_right.png): 행은 공격/수비/버프/보스, 열은 정지/좌보행/우보행. 모두 원본3배 픽셀. [전체 수치와 계층](measurements.json), [실행 결과](invocation.json), [에디터 상태](editor_state.json).

- 특히 우측 이동에서 공격/수비/버프의 발 중심이 타원 중심에서 크게 벗어나며 멈춰도 남는다. 보스의 가로 오차는 이 기준에서1도트 이하다.
- 원인: 원본 병사 본체는 발 위치를 맞추는 별도 localPosition을 가진다. 공격/수비 X=-0.09375월드(본체 기준 -5도트), 버프 X=+0.0375월드(+2도트)다. 그림자 타원은 루트중심0에 남아 있다.
- `CoreGuardianOriginalWalk.Present`가 rig.localScale.x=-1과 original.flipX를 적용하면서 이미지 피벗을 기준으로 반전한다. 기존 발 위치 보정은 그대로라 본체의 발 중심이 그림자 반대쪽으로 이동한다. 정지 시 원본 SpriteRenderer에도 같은 피벗 반전을 적용해 오차가 유지된다.
- 세로는 원본 양발의 원근/높이 차이와 스윙 높이가 포함된다. 보스 정지의 두 발 중점은 타원보다 약2도트 위, 보행 평균은 약2.82도트 위다. 이 평균만으로 그림자를 발 스윙에 따라 위아래 흔들어야 한다고 결론 내리지 않는다.

## 수정 후보 / 현재 상태
