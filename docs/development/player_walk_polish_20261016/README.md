## 원인과 수정

1. 타깃이 없어도 이동 벡터에 팔을 완전히 조준했다. 평상시 이동은 원본의 내려놓은 팔을5도 이내로 흔들고, `MoveWithoutTurning/Aim`의 실제 타깃 또는 `Fire`에서만 도구를 조준한다. 실제 발사 프레임의 도구 끝 원점 갱신은 유지한다.
2. 몸의900도/초 회전이0.12초 한 칸 이동보다 늦어, 기본 남서향에서 동쪽으로 첫 이동해도 중간 방향을 거쳤다. 플레이어의 타깃 없는 이동만 첫 프레임에 실제 변위 방향으로 전환한다. 몬스터/포탑 분기는 유지한다.
3. 아래쪽 다리 덩어리를 위로3px 올리기만 하고 정지 시 즉시0으로 되돌렸다. 기존 원본 다리 조각을 무릎 위 피벗에서6도 회전하고 작은 앞뒤 보폭/2.2px 들기로 교대한다. 이동 시작·정지에 약0.1초 가중치를 주고 남은 반 걸음을 착지하며 복귀한다. 최대3주기/초로 빠른 타일 이동에서 발 떨림을 제한했다. 실제 이동/키 입력/이동 시간·전투 수치는 변경하지 않았다.
4. 정면 머리 반쪽 복제가 고글/얼굴을 중복했고, 옆방향 가로 압축이 몸/다리를 찌그러뜨렸다. 원본 머리 전체를2px 옮겨 사용하고 가로 압축을 없앴다. 배낭 위치/겹침으로 방향을 구분한다. 원본 PNG·기본 남서향의 보이는 픽셀·기존 팔레트를 보존한다.

새 이미지 생성·채색·캐릭터 재디자인을 하지 않았다. [현재 제작기](BuildSourceFacings.cs), [원본 픽셀/임포트 감사](source_audit.json): 추가색0·기본 방향 보이는 픽셀 차이0·36×48/PPU32/Point/mipmap없음·실제 합성8종 구분. [동일6배 방향 비교](facings6x.png). 원본 아트/씬/프리팹/몬스터 원본 보행·상하 다리 폭 수정/코어 VFX/밸런스·Notion은 변경하지 않았다.
