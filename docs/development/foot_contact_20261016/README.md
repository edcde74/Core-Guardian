# 공격형 오른발 접지 원본 수정

2026-10-16. 사용자 화면의 원으로 표시한 공격형이 우측 이동 중, 화면 오른쪽 발이 그림자보다 떠 보여 접지감이 약하다는 피드백. 원본 도트 수정 요청을 받았다. 시작 복구 기준 `ad99143`, 진행 중 별도 피격90ms 작업 `2990bdd`가 커밋됐으며 해당 변경을 보존했다.

## 원인·적용

- 화면 오른쪽 발은 우측 이동 때 원본이 좌우 반전돼 표시된 **원본 왼쪽 발**이다. 원본42×64px에서 해당 발바닥은 하단보다4px 위, 반대 발은 하단0px에 있었다. 기존 평균 발 중심(4,2) 정렬은 양발 사이를 그림자에 맞춰 한 발의 뜬 인상을 남겼다.
- `MONSTER_ART_STYLE.md`와 실제 기준 병사3종·비교판을 직접 열어 확인했다. 사용자 사진은 [원본 피드백](user_feedback.png)에 보관했다.
- 이미지 생성 편집 결과는 별도 참고로 보존했다. 대상 밖 픽셀 변화가 있어 전체 재도안으로 적용하지 않았다. 원본의 왼쪽 부츠·발목 부분만4px 아래로 이동하고 원본 정강이의 기존 색면으로 연결했다. [편집 프롬프트·적용 방식](image_prompt.md), [정수 픽셀 보정 스크립트](ApplySource.cs).
- 사용자 요청에 따라 실제 `enemy_attack_v2.png`를 수정했다. 이전 원본은 [backup](backup/)에 복사했고 원본 GUID·42×64 캔버스·PPU32·기존 메타는 유지한다. 재디자인·새 장비·팔레트 추가 없음. 해당 사각영역(x12~24, 상단기준y55~63) 밖 픽셀 변화0.
- 공격형 원본 분리 레이어 중 `OriginalWalk/Attack/LeftLower.png`만 새 발 픽셀로 갱신했다. 다른4개 레이어·다른 몬스터·보스·VerticalWalk는 변경하지 않았다.
- 원본 발 위치에 맞춰 공격형 왼발 발목 기준57→61, 지면 기준(4,2)→(3.5,0)만 갱신했다. X축의 보폭14·발 들기1.8·반 주기·이동 거리 기반 위상·방향 반전과 보행 알고리즘은 유지했다. 기존 그림자·루트·씬·원본 프리팹은 수정하지 않았다. Y+Up/Y-Down4프레임 선택·X복귀도 유지했다.

## 확인

- [픽셀 검증](pixel_verification.json): 수정 전 양발 바닥높이4/0px, 수정 후0/0px. 영역 밖 차이0, 새 불투명 색0, 캔버스42×64·PPU32.
- [실제 Unity 렌더러3배 비교](unity_contact_native3x.png): 위 우측 이동/좌우반전, 아래 좌측 이동. 열 수정 전 정지/수정 후 정지/수정 후 보행위상0·.25·.5·.75. 발과 그림자·원본 픽셀을 직접 확인했다. [간단 전후](before_after.png)는 첫행 첫2칸이다. 걷는 동안 드는 발은 유지되며 양발이 항상 바닥에 붙는 동작으로 바꾸지 않았다.
- 최초 전체 EditMode91/92의1실패는 공격형의 예전(4,2) 지면 기준을 기대하는 검사였다([중간 결과](editmode_sync.json)). 새 기준으로 갱신하고 실제 PNG 양발 바닥선 동일 검사를 추가했다. 최종 전체 **EditMode93/93 통과**([원본 응답](editmode_final.json)).
- 최종 전체 **PlayMode16/16 completed**([원본 응답](playmode_final.json)). 실제 정상 생성 적 웨이포인트의 X±/Y± 외형·프레임과 X복귀, 기존 발사·피격·HUD·전투 흐름 포함. 기능 회귀이며 밸런스 실측·사람의 접지감/아트 승인으로 대신하지 않는다.
- 동기 PlayMode 요청은 HTTP 도메인 재로드 제약으로 거부돼0건이었다. 이를 통과로 쓰지 않고 [거부 응답](playmode_sync_not_supported.json)·[등록16건](playmode_inventory.json)을 남긴 뒤 비동기로16건 완료를 확인했다. 중간 공유 상태의1건 응답은 다른 회차와 혼동하지 않으며 최종 결과는 위 파일만 사용한다.
- [최종 에디터 상태](final_editor_state.json): Play=false, compiling=false, 기존 전투 씬active·dirty=false. 사용자 Play를 임의 종료하지 않았다. 실행 전 stopped를 확인했고 자체 회귀검사만 실행했다.

원본 외형 대부분과 승인된 보행 방식은 유지했다. 자연스러운 접지감의 최종 사용자 검토는 별도다. 별도 피격90ms 작업·VFX 문서·음악·분석 자료는 보존했다. 밸런스CSV·노션·씬YAML·프리팹 변경, 빌드·실행파일 실행·GitHub push 없음. 기존 실행파일에는 이번 원본 수정이 포함되지 않는다.
