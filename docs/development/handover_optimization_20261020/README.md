## Notion

3. PC조작: WASD는플레이어이동, UI탐색/Submit/Cancel차단·마우스/별도Esc유지.
4. HUD표시: 골드심볼통일/동일패널·체력바유지·현재총30R/키보드포커스안내정정·성능문서연결.
