# HUD 글자·상자 맞춤 수정

2026-10-13 Asia/Seoul. 사용자 요청으로 문구가 장식 테두리에 걸리거나 패널 밖으로 나가지 않도록 런타임 UI 크기·안쪽 여백을 수정했다. 복구 기준 `8c6344d`: 작업 시작 시 게임 파일 변경 없음 확인, 빈 체크포인트 커밋은 만들지 않았다.

## 원인과 수정

- 기존 강화 버튼의 글자 Rect가 버튼 전체 높이를 사용하고 y 여백이 없었다. 프레임의 원래 9-slice 테두리도 작은 버튼의 본문 공간을 소비해 글자가 장식에 걸렸다. 원래 캡처 `../hud_sprite_review_20261013/HudAppliedPanelsFinal.png`에서 확인했다.
- 공통 프레임의 pixelsPerUnitMultiplier를 2.5로 설정하고 버튼 라벨에 왼쪽 심볼 자리·오른쪽16·위/아래16 여백을 확보했다. 글자는 줄바꿈하며 Rect 밖으로 그리지 않는다. 단순히 글자를 잘라 숨기는 방식으로 완료 처리하지 않고 전체 문구의 필요한 높이를 검사했다.
- 설치 버튼204×96, 3×3 패널660×328; 플레이어 강화 버튼488×80/패널520×412; 타워 강화 버튼428×80/정보 패널460×560. 기존 문구·가격·효과·선택 조건은 그대로다. 지원 포탑 네 줄 정보는112 높이를 확보했다.
- 상단 상태72/접힘52, 하단 행동 버튼56 높이와 여백을 확보했다. 단계와 피드백 문구는 같은 상자 안의 별도 줄로 배치하여 하단 설치/강화 패널 위에 겹쳐 있던 안내를 정리했다.
- 증강 패널1140×650, 카드350×460. 심볼·제목·효과·재클릭 안내를 별도 영역으로 배치하고 프레임 안쪽 여백을 확보했다. 뒷면의 등급 글자 없음, 공개/재클릭 선택·연출 시간·효과음은 유지했다. 스파크 시작점은 커진 카드 경계를 따른다.
- 피해 패널320 폭, 항목 본문250 폭을 확보했다. Viewport에 RectMask2D와 투명한 스크롤 입력 면을 두어 항목이 패널 안에서만 보이고 빈 영역에서도 휠 입력을 받도록 유지했다.

## 확인 결과

- 실제 Unity Play의 1920×1080에서 설치 분류·개별 포탑·선행 조건 안내, 재화 부족 강화, 단일/지원 포탑 정보, 상단 접힘, 눌린 버튼을 검사했다.
- 증강 18종을 3장씩6그룹의 런타임 후보로 주입하고 실제 클릭으로 공개한 후 제목·효과·선택 안내 전체를 검사했다. 후보 주입/강제 처치는 UI 문구 검사이며 실제 추첨·밸런스 결과가 아니다.
- `CheckHudTextLayout.cs`는 폰트가 전체 문구에 요구하는 높이, Text Rect의 부모 상자 포함, 직접 부모의 9-slice 장식 테두리 안쪽 포함을 검사한다. after_install/support_requirement, final_support/compact/pressed_support, final_cards_0~5, final_scroll, final_support_full 결과의 위반0 확인. 원래 before 기록은 테두리 안쪽 조건을 추가하기 전의 단순 검사이며 장식에 걸리는 문제를 검출하지 못했던 자료다.
- 긴 숫자13개 피해 항목 주입: 텍스트 검사 위반0, RectMask2D 클리핑, 입력 면 레이캐스트와 스크롤 후content y=4 확인.
- 최신 기존 PlayMode **8/8 통과**: 카드 공개·중복 클릭 차단·중단 정리, 실제 씬1~11/재시작·이동·전투 회귀. [결과](playmode.json). UI 소스만 변경하여 이번 EditMode73개는 재실행하지 않았다.
- `BuildCombatPrototype.Verify` success=true, saved=true, A 길·원본 적/포탑3종·플레이어(15,10) 유지. 종료ready/Play stopped/compiling=false/domainReload=false·전투 씬dirty=false, 콘솔현재오류0/컴파일실패false.
- 검사 도구 초기 작성에서 존재하지 않는 SelectTower 호출로 임시 컴파일 실패, 진단 모드가 포탑을 미리 만들지 않아 조회 실패가 있었다. 게임 코드 오류가 아니며 정상 Place API로 검사기를 수정한 후 검증했다.
- 다른 해상도·종횡비 및 사람의 실제 사용성은 이번에 검증하지 않았다. 확대된 패널이 전장 판독에 주는 영향은 사람 플레이로 확인할 수 있다.
