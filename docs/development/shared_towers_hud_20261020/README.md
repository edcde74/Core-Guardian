# 종류별 공유 강화·능력치 고정 배치·칸 체력바

2026-10-20. 사용자 요청 및 추가 답변 ‘같은 종류의 모든 포탑 + 이후 설치분’에 따라 적용했다. 복구 기준은 `15fa5ae`(사용자 직접 수정한 보스 HP500 포함)다.

## 현재 동작

- 강화는 단일 고속·범위 공격·지원 각각의 종류/능력치별로 공유한다. 비용은 구매당 한 번 지불하고 현재 같은 종류 전체와 이후 설치분에 적용한다. 종류를 모두 철거해도 공유 단계는 남는다. 새 Session/진단 재시작은 초기화한다.
- 설치비100, 강화 증가량과 단계 가격40→100→120→140은 유지했다. 첫 할인도 종류/능력치별 한 번이다. 철거는 해당 설치비의50%(현재50)만 환급하고 공유 투자금은 환급하지 않는다. 한 구매의 환급을 여러 포탑에서 중복 회수하지 않는다.
- 실제 구매 성공 시 같은 종류의 현재 포탑 전체에 기존 B 청록 스캔(0.8초)을 표시한다. 성공음은 구매당 한 번, 조회 아웃라인은 선택 개체 하나다. 지원 전투 무음은 유지한다.
- 현재 능력치↔강화는 플레이어900×220/포탑900×280, 왼쪽 세로 탭220×56, 오른쪽 단일 안쪽 패널의 칸306×64를 고정한다. 공격형2×2 순서는 공격력/공속/사거리/탄환 속도, 지원은 공격력 증가/범위 두 칸이다. 강화는 같은 칸 안의 현재→다음/증가량/비용과 Hover/Pressed 구매 반응으로 표시한다. 포탑은 공유 적용 범위를 안내한다.
- 적 체력바는 일반8칸/보스12칸, 고정 외곽 프레임 안의 칸을 비운다. `ceil(HP/maxHP*칸수)`이며0HP는0칸이다. 한 칸=고정 HP가 아니다. 3px 칸/1px 구분·외곽, 높이5px, PPU64/Point의 공유 캐시 Sprite를 기존 Health 렌더러 하나에 사용한다. 마지막 체력바 제거/새 Play 시 생성 리소스를 정리한다.
- 병종별 `HealthBarWorld`와 원본/장비 기준 높이는 유지한다. 생명력 비율이 줄어도 프레임 폭이나 기준점은 움직이지 않는다. 높이7px 첫 구현은 보스 장비 여백 검사에 실패해 기준점 대신 높이를5px로 줄였다.

## 남은 판단

사용자의 ‘설치 수를 늘리는 성장’ 방향을 공유 강화로 구현했다. 설치비·수급은 그대로이므로 설치 빈도 자체가 빨라졌다고 주장하지 않는다. 공유 강화의 기체 수에 따른 화력 상승과 설치/강화/지원 선택, 초반 압박·10R보스·11R증강 후 체감은 현재 데이터로 새 정상 전투에서 비교해야 한다. 과거8회/옛 개별 강화 정책을 현행 결과로 사용하지 않으며 임의 가격·보상·HP 추가 조정은 하지 않는다.
