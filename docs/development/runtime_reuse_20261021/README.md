# 표시 재사용·Session 반복 비용 감소

2026-10-21 Asia/Seoul. 복구 기준 `5914347`. 사용자가 실제 플레이 테스트를 나중으로 미루고 후속 최적화 적용을 요청했다. 구체안은 대화에서 HUD 행/뷰 동기화 재사용, 숫자/탄환/효과의 소유자별 풀링, Session 버퍼/타깃 선택 순서 보존을 각각 승인했다. 새 Play·자동 테스트·성능 측정은 보류했다. 코드 반영과 성능/품질 통과를 구분한다.

피해 HUD의 .2초 갱신, 피해 내림차순/동률 소스명 순서, 최대 피해 대비 막대, 외형/접기/스크롤 계층은 유지하는 코드다. 기존 피해 정렬 배열·signature 문자열은 아직 생성한다. 신규 코드 전체가 무할당이라는 주장은 하지 않는다.

활성 객체에는 개수 상한을 넣지 않았다. **비활성 보관 상한**은 숫자 종류별128, 표시 탄환256, 일회성 효과256, 섬광128이다. 초과 회수분은 기존처럼 삭제한다. HUD 행과 컬렉션 용량은 해당 세션의 최대 사용량을 보관하며, 메모리 절충이 있다. Session은 StepWork/ShotWork 각각 최대8개를 보관하고 반환 때 객체 참조를 Clear한다. 소유 컴포넌트 종료 때 활성/대기 표시 객체를 정리한다.

사거리 `Vector2.Distance` 임계값, 초기/재획득 타깃 정책, 발사/적중/라운드 이벤트 순서, 버프 선계산→이동 순서, 포탑/탄환 스냅샷 시점과 발사 수·수명을 보존하도록 구현했다. 전투 CSV·씬·아트/임포트·전역 렌더/오디오/입력 설정은 수정하지 않았다. 실제 동등성은 아래 미검증 범위다.

## 실제 확인

- 5개 제품 소스 diff를 독립 읽기 전용 코드 리뷰로 확인했고, Session 및 마지막 애니메이션 버퍼 변경도 재검토했다. 수정이 필요한 문제 보고 없음. 리뷰는 실행 증거가 아니다.
- 공식 Unity MCP `recompile(focus=false)`: completed, failed=false, errors=[], compilationFailed=false. 테스트 실행/새 Play 없음.
- 컴파일 전 Console ground truth 오류0/경고3, 후 오류0/경고117. 컴파일 전 cursor 이후 수집116건은 UAC0005 36건, CS0618 79건, 계정 API 접근 지연1건. 기존 소스/API 경고를 새 오류로 오인하거나 경고0으로 보고하지 않는다. [수집 원본](compile_warnings.json), [요약](verification.json).
- `git diff --check` 통과. 사용자 TimeManager/PackageManagerSettings/ProjectSettings의 SHA256은 이전 본체 공유 종료 기록과 모두 일치했다.
- 종료 조회: Unity6000.6.2f1, 전투씬1, **dirty=true는 수정 전부터 있던 사용자 상태**, Play stopped/compiling=false/domainReload=false, 실행 중 Unity 테스트 없음. 씬 저장/전환/복원은 하지 않았다. 미추적·폰트 도구 접근오류 표시도 보존했다.

## 성능 판정과 미완료

사용자 지시로 이번 작업의 전후 Profiler·FPS·GC·RT/VRAM·활성/대기 피크·장시간 잔류 계측을 수행하지 않았다. 과거 본체 공유 수치를 이번 변경의 성과로 재사용하지 않는다.

|---|---|---|---|---|
|최소/최대/평균 FPS, 프레임 ms 분포|미측정|미측정|N/A|측정 보류|
|관련 CPU/GC.Alloc/생성·반환·풀 확장 비용|미측정|미측정|N/A|측정 보류|
|활성/대기/최대 메모리·종료 잔류|미측정|미측정|N/A|측정 보류|
|실제 픽셀·입력·효과/음량·전투 결과 동등성|기존 자료만 존재|이번 실행 미검증|N/A|검사 보류|

후속 검증을 재개할 때는 이번 소스를 기준으로 대상 QA만 선택한다. HUD 행 재바인딩/리셋/접기/스크롤, 숫자 종류 전환/알파/계층/수명, 탄환/효과 중첩과 풀 확장/정리, 같은 seed·dt·입력에서 타깃/발사/적중/라운드 이벤트 기록, 이벤트 재진입을 확인한다. 정상30R·장시간 플레이와 기존 보스 전체 합성9건/원래 순간 지연은 미완료다.

적 본체 GameObject 풀은 이번에 적용하지 않았다. 현재 UnitAnimation/OriginalWalk의 보행 위상·이전 위치·방향·피격·강조·마스크 소유권을 새 적으로 재바인딩하는 명시적 초기화 계약이 없어 단순 SetActive 재사용으로 바꾸지 않았다. `EnemyState`/`ProjectileState` 자체 재사용도 외부 이벤트가 보관한 참조를 바꾸므로 이번 표시 풀과 구분한다. 마스크의 알려진 픽셀 차이가 있는 뷰 확장·임의 품질 축소·전역 설정 변경도 하지 않았다.
