# 코어 가디언 전투 프로토타입 — 2026-10-08

## 실행

Unity에서 `Assets/Scenes/CoreGuardian_CombatPrototype_20261008.unity`를 열고 Play를 누른다.

- WASD를 한 번 누를 때 보이는 바닥 한 칸의 중앙에서 다음 중앙으로 이동한다.
- 왼쪽 아래 **타워 설치 → 공격 포탑 → 단일 고속/범위 공격**을 선택하고 바닥을 클릭한다.
- 설치 중 보드 위에서는 일반 마우스 커서를 숨기고 포탑 미리보기를 커서로 사용한다. 포탑 커서는 타일 중앙 사이로 한 칸씩 이동하고, 경로·코어·기존 포탑 칸은 빨간색으로 표시한다. 메뉴·버튼 위와 보드 밖에서는 일반 커서를 사용한다.
- **Esc** 또는 **설치 취소 · Esc** 버튼으로 포탑 선택 메뉴와 설치 모드를 닫는다. 미리보기·설치 가능 타일 표시를 제거하고 일반 커서를 복구한다.
- 기술병이 서 있는 칸에도 설치할 수 있다. 기술병은 자동으로 이동하지 않고 WASD로 빈 인접 칸에 나간다.
- **라운드 시작** 또는 준비 시간 50초 종료로 전투를 시작한다. 포탑이 없어도 시간 종료 시 시작한다.
- 포탑 클릭 후 정보 패널에서 강화하거나 파괴한다. 전투 중 설치·포탑 강화는 차단하고 파괴는 허용한다.
- 오른쪽 아래 플레이어 강화는 전투를 정지하지 않는다.
- 적 명중 위치 위에 실제 감소한 체력만큼의 피해 숫자가 뜬다. 방어 계산·반올림 후 남은 체력을 초과한 피해는 제외하며, 약 0.85초 동안 떠오르고 사라진다. 피해 0·이미 죽은 대상·코어 도착에는 적 피해 숫자가 뜨지 않는다.

## 검증 범위

정식 편성은 **1라운드 공격형 15명, 1.8초 간격**이다. 적 생성·경로 이동·자동 공격·투사체·처치 보상·코어 도착·완료/패배를 확인한다. 2~11라운드 진행, 보스, 증강은 이번 개발 범위에 넣지 않았다.

왼쪽 위 **3종 역할 검증 / 재설정**은 별도 진입점이다. 화면에 역할 검증임을 표시하고 1,000골드·1,000수정으로 초기화한다. 포탑 3종을 설치·강화한 뒤 시작하면 공격형·수비형·버프형이 상단 경로 가까이 등장한다. 이는 정식 라운드의 편성이나 보상이 아니다.

검증 예시: 단일 포탑 (14,15), 범위 포탑 (17,15), 지원 포탑 (14,16). 지원은 인접 단일 포탑에만 영향을 주고 기술병에는 적용하지 않는다. 군기병의 이동 버프 표식은 주황색, 포탑의 공격력 버프 표식은 청록색이다.
