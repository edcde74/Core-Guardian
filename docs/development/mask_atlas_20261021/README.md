## 현재 판정

호출 수 부분 개선을 확인했다: Draw Calls3208→2178(-32.107%), SetPass1608→578(-64.055%). 평균 FPS 개선은 확정하지 않았고 p95·일부 최저 FPS 악화는 남는다. 원본 본체 Sprite·텍스처/importer·보행·소리·밸런스는 유지한다. **수치·실패·품질·잔존·원복·다음 행동 정본은 [RESULTS](RESULTS.md)**다. 게임 성능 전체 통과로 판정하지 않았다.

최초2D 페이지 방식은 UV/샘플 경계에서 픽셀 차이를 일으켜 폐기했다. 텍셀 floor/양자화 등 보정도 통과하지 못해 하드웨어별 보정 코드는 제품에 남기지 않았다. `rejected_2d/`, `pixels_uv_first/`, `pixels_uv_floor/`, `pixels_uv_round/`에 관측 자료를 보존한다. 중간 shader 재임포트 전 결과는 최종 셰이더 결과로 간주하지 않는다.

최종 방식은 **동일 원본 크기별 Texture2DArray**다. 각 파츠를 별도 레이어에 복사하고 원본 UV·크기·Point/Clamp/no mip 샘플링을 유지한다. 페이지+정확한 opacity별 결합 메시와 파츠별 GPU 행렬을 사용한다. 미등록/지원되지 않는 소스는 원본 경로로 그린다. RT 소비자와 효과 수/수명은 그대로다. 현재 Windows/RTX3070/Direct3D12에서 검사하며 다른 그래픽 API·standalone은 미검증이다.

공격형 실제5파츠→1제출 및432조건 픽셀 차이0을 확인했다(`attack_only/`). 최종92개/9배열과 리뷰 수정을 적용한8역할3456조건에서도 차이0/등록 누락0을 재확인했다. 수명600프레임×3, 신규 계약2/2·기존 아웃라인3/3, native 정리 검사의 범위와 한계는 결과 정본을 따른다.

## 회귀·리뷰

- `red_result.json`: manifest 부재로 계약1건 실패 후 구현했다. 테스트 준비물의 본체 SpriteRenderer 누락, Clamp 설정의 재컴파일 지연은 별도 실패 파일에 보존했다.
- `array_red.json`→`array_green.json`: 원본 UV/크기를 유지하는 배열 페이지 계약의 실패/통과다.
- 독립 코드 리뷰에서 원본 재임포트 staleness, manifest 버전 변경 캐시, 페이지 중간 덮어쓰기를 지적했다. `review_red.json`의2건 실패 후 `review_cache_green.json`2/2를 확인했다. 실제 crop/flip/alpha/fallback 픽셀 비교와 서로 다른 크기 페이지 분리도 포함한다.
- `publication_red.json`은 재생성이 기존 페이지 알파를 덮어쓰는 결함을 재현한다. 해시 기반 불변 페이지, 모든 레이어 검증 후 manifest 마지막 저장, 실패 시 자체 신규 자산만 정리하고 이전 manifest 메모리 복원으로 수정했다. `review_final_green.json`2/2. 늦은 페이지/디스크 실패를 강제로 주입한 검사는 없으며 이 실패 복원 경로는 정적 리뷰 범위다.
- 재리뷰에서 기존 주요3건 수정과 현재 Direct3D12 범위의 추가 차단 결함 없음이 보고됐다. combined3→2 축소를 별도 픽셀 계약에 추가하고, 본 실험에서 만든 구버전 페이지 정리는 사용 여부를 확인해 진행한다.
