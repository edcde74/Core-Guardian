# 마력포 시험 적용

- 사용자 임포트 RPG Essentials FREE 48개/Aura Kit FREE 7개를 보존한다. 원본 취득 체크포인트 `1523eb7`.
- 대지/불 폭발/오라 생성 원본에서 짧은 시험용 파생3개를 만든다. 직접 청취 평가는 사용자 몫이며 최종 음원 확정이 아니다.
- 단일 포탑의 실제 ProjectileLaunched에만 연결한다. 발사/피해/주기/그림자/국소발광/밸런스는 변경하지 않는다.
- 기존 개발 도구에 효과음 0~100% 슬라이더, 후보 전환과 미리 듣기를 추가한다. 현재 증강 효과음도 같은 음량을 사용한다. BGM 자료는 수정하지 않는다.
- 음량/후보를 로컬에 저장하고 재시작에 반영한다. 최대4 동시 음성으로 중첩을 제한한다.
- 팩 데모 씬은 Assets 밖으로 원본 보관하고 전투 씬 하나를 유지한다.
- 볼륨/실제 클립 테스트 실패 확인 후 구현, 실제 발사/미리듣기/UI/음소거/재시작 기능 확인. 직접 청취/다수 전투 믹스/밸런스/전체회귀 통과로 표현하지 않는다.
