사용자가 직전 전체 비교판의 방패병·코어·멀티·지원 접지/그림자를 빨간 원으로 지적하고 수정 시안을 요청했다. [4곳 전후 동일4배](four_marked_before_after_4x.png), [전체8종 결과 동일2배](all_result_2x.png). 왼쪽은 직전 접점 미세 보완, 오른쪽은 이번 수정이다. **시안만이며 사용자 미승인/게임 미적용**이다.

- 방패병: 기존 바깥/접촉/밀착선과 추출 그림자를 중복 합성하던 바닥을 분리하고, 사진 추출 마스크와 실제 방패/발 하단 사이의 끊긴 작은 영역을 국소 연결했다.
- 코어: 실제 씬 조회에서 청색 영역이 core.png 본체가 아니라 별도 `바닥 수정빛` SpriteRenderer(ShadowEllipse/RGBA.1,.8,1,.16)임을 확인했다. 앞선 ‘원본에 포함된 바닥 표현’이라는 설명을 이 근거로 정정한다. **임시 비교용 복제 코어에서만** 해당 바닥빛과 기존 그림자들을 숨기고 추출 그림자·밑면 접촉부를 합성해 중첩된 판 형태를 줄였다. 실제 씬 코어의 발광/바닥빛/원본은 유지한다.
- 멀티: 추출 그림자의 폭1.10/높이0.80로 재등록하고(-3,+5)px 이동해 받침보다 높이 튀어나온 부분을 낮췄다. 지원: 폭1.10/높이0.85·(-5,+2)px로 받침 뒤쪽으로 당겼다. 이동량은 직전 등록에 대한1920×1080 이미지 좌표이며 아래방향이+다. 새 다각형/타원/무기·본체 실루엣 투사를 사용하지 않았다.
- 네 종류의 실제 하단 윤곽을 따라1~2px 접촉 농도를 보완하고 기존 그림자와의 작은 틈은 제한된 마스크 closing으로 연결했다. 사진의 노출 그림자 추출을 주 형태로 유지하며, 새 접촉부는 정지 시안용 재구성이다. 원본 알파/가려진 영역을 정확히 복원한 것은 아니다. 보행 중 고정 발 복제로 연결하지 않았다.
