## 현재 확인

- 승인 공격음 3종과 지원 무음은 [적용 담당 기록](combat_audio_final_20261018/README.md)이 현재 기준이다. `CoreGuardianCombatAudio.cs`의 고정 리소스 경로·4음성·gain0.55·멀티 포탑별35ms 묶음을 확인했다.
- 증강 카드 공개음은 `CoreGuardianAugmentationView.cs`에 등급별 기존 합성음이 있으며 공통 효과음 음량을 사용한다. 이번 작업의 새 승인/변경 대상이 아니다.
- `CoreGuardianSoundSettings.cs`는 기존 PlayerPrefs 값을 읽고, 저장값이 없을 때만0.65를 기본값으로 쓴다. 이번에는 Unity/PlayerPrefs 현재값을 조회하거나 쓰지 않았다. 약13%는 이전 확인 이력이며 현재 실측값으로 표현하지 않는다.
- Notion [전투 사운드 설계 방향](https://www.notion.so/3fb389dbfc68815f8923cb93f5b90743)과 [07. 사운드](https://www.notion.so/3fb389dbfc68812e99cef57df6b65793)는10월16일 내용으로, 공격음 미정 표기는 최신 사용자 지시/실제 적용보다 과거다. 이번에는 Notion을 수정하지 않았다.
