## 기록할 항목

회차/데이터 해시/빌드 또는 에디터/배속·게임초와 실제 시간/난수·증강/배치·구매 순서를 기록한다. 라운드별 완료·패배 지점,코어 손실,클리어 시간,최대 생존 적·최소 코어 잔여거리(관측 샘플),기술병·각 포탑 실제 피해,골드·수정 획득/지출/잔액,첫 강화 시점을 비교한다. 골드와 수정은 분리한다. 사람이 느낀 지루함·긴장감·선택 보상은 별도 의견으로 남긴다. 자동3회 탐색 결과를 통계적 승률이나 최종 재미 승인으로 쓰지 않는다.

## 기존 계측기 주의

`MeasureNaturalRounds.cs`를 새로 복제하기 전에 재사용 가능성을 점검한다.

- StartEarlyComparison은 HP25를 전제하며 빠른 변형은 간격/start를0.9배한다. 현재HP27/단축된CSV에서 그대로 호출하면 거부되거나 비교 조건이 잘못된다. 과거 수치로 현재CSV를 임의 복구하거나 단축을 중복 적용하지 않는다.
- 6R scheduleInvariant에는 과거 총HP555가 하드코딩되어 있다. 현재공용HP27의 합계로 재검토한다. 불변 항목(편성·수급·유형순서 등)과 의도적으로 바뀐HP를 구분한다.
- Start 기본 출력은 과거 natural_rounds_20261010_<policy>.json이다. 기존 결과를 덮어쓰지 않도록 새 출력 경로·회차 처리를 먼저 정리한다.
- 10R 증강의 직접 선택/자동 선택 조건·18종 효과 기록과11R 종료까지의 계측 범위를 확인한다. 일반 실행이 돌아간다는 것만으로 최신 증강 비교가 기록된다고 가정하지 않는다.
- 강제 처치/재화 주입/라운드 건너뛰기를 사용하는 VerifyBossAugmentation·HUD 검사기는 기능/화면 확인용이다. 밸런스 실측에 사용하지 않는다.
