# 승인된 적용 순서

사용자 승인: 기존 외형·보행·B 제한/fallback 유지, 추가 몬스터·타워를 고려한 아틀라스 적용. 복구 기준 `bf76436`(소스 변경 없음), 테스트2개 RED 확인 후 구현한다. 기존 사용자 설정2개는 제외한다.

1. 현재 정지/clean/컴파일 완료/다른 테스트 없음 확인. 새 짧은128적·15타워 기준 구간 수집. 원시 FrameProbe는 안전한 per-frame 값만 저장하며 ProfilerRecorder 배열 복사를 사용하지 않는다.
2. 부위 자르기는 textureRect 기준으로 하고, 생성 Sprite에 원본Texture/UV 변환 정보를 계승한다. 에디터 제작 source manifest를 런타임에 읽어 B 원본 배열과 연결한다. 회전/비직사각 패킹은 명시 거부한다. 원본 fallback 유지.
3. 전투 효과·일반 적·타워별 V2 폴더 기반 제작과 빌드 전 동기화. 현재 빈 사용자 CG_Enemies는 보존한다. 환경 길/플레이어/코어/UI/폰트는 이번 패킹에서 제외한다. 기존9효과는 이미1텍스처이므로 단독 Draw 개선을 주장하지 않는다.
4. 좌표·B 매핑 테스트와 대상 보행/타워/마스크 테스트, 실제 패킹된 Sprite와 마스크 원본 대조. 새 유닛 폴더 포함·중복·페이지 확인.
5. 같은 짧은128적·15타워 전후FPS/Draw/메모리와 원본 기록. 악화/불확실성을 포함해 보고하고, 사용자 파일 hash·씬/설정/자체 상태 복구 확인 후 로컬 완료 커밋. 빌드/실행파일/push 없음.
