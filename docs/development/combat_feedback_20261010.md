# 전투 피드백과 설치 입력 — 2026-10-10

사용자 플레이 피드백으로 적 피해 숫자, Esc 설치 취소, 타일 단위 설치 커서를 추가했다.

## 동작

- 피해 숫자는 모델의 실제 체력 감소 이벤트에서 생성한다. 치명타격에도 남은 체력만 표시하며, 사라진 대상을 따라갈 필요 없이 명중 당시 위치에 남는다. 노란 숫자·어두운 외곽선, 약 0.85초 상승·페이드, 동시 숫자 위치 분산을 사용하는 임시 표현이다. 기존 Canvas를 재사용하고 입력 레이캐스트를 차단하지 않는다.
- Esc와 설치 취소 버튼은 포탑 선택 메뉴·설치 모드·미리보기·타일 강조를 해제하고 일반 커서를 복구한다. 설치 취소만 처리하며 전투를 멈추지 않는다.
- 설치 중 보드 위의 화면 커서는 타일 중앙에 맞춘 포탑 미리보기다. 자유롭게 움직이는 OS 커서를 숨기며, 메뉴·버튼 위와 보드 밖에서는 일반 커서를 사용한다. OS 포인터 좌표를 강제로 워프하거나 잠그는 방식은 아니다.

## 검증

- 신규 피해 이벤트 테스트 2개: 구현 전 이벤트 부재로 실패 확인, 구현 후 통과.
- EditMode 22개, PlayMode 5개 통과. 기존 정식 1라운드 전투·재화·플레이어 이동 검증 포함.
- 실제 씬 입력 검증: (14,15) → (15,15) 타일 중앙 이동, 보드의 일반 커서 숨김, Esc로 설치 취소·타일 강조·미리보기 제거·일반 커서 복구.
- 버튼 위에서는 일반 커서를 복구하고 포탑 미리보기를 숨긴다. 포탑을 고르기 전 선택 메뉴만 열린 상태에서도 실제 Esc 입력으로 메뉴 닫힘을 확인했다.
- 실제 피해 표시 검증: 13·12·12, 치명 피해 숫자 유지, 숫자 클릭 비차단, 기존 Canvas 1개 유지, 시간 경과 후 숫자 제거.
- 실제 투사체 명중도 별도 확인했다. 지원 효과를 받은 단일 포탑 명중 피해 15와 누적 피해 15가 일치했다. `actual_hit_verification_20261010.json`, `combat_damage_20261010.png`는 별도 역할 검증 모드 자료다.
- 실행 가능한 추가 검증 스크립트: `VerifyCombatFeedback.cs`. Play Mode에서만 실행하며 씬·프리팹을 저장하지 않는다. 검증 캡처를 위한 Time.timeScale=0은 종료 전에 1로 복구한다.
- 테스트 결과: `editmode_results_20261010.json`, `playmode_results_20261010.json`.

사용법: `combat_prototype_20261008.md`. 최신 씬은 `Assets/Scenes/CoreGuardian_CombatPrototype_20261008.unity`다. 기존 Windows 실행 파일은 이번에도 재빌드하지 않았다. 개발 완료 후 사용자 요청으로 노션 담당 문서 본문에 반영하고 재조회했다. 문서 상태 속성은 변경하지 않았다. 반영 기록: `planning_updates_20261010.md`.
