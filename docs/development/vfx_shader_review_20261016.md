# 코어 가디언 VFX·후처리·셰이더 검토

2026-10-16. 최신 조회한 담당 Notion과 디스크 코드·설정에 근거한 제안. 게임 적용·아트 승인·성능 검증 결과가 아니다. Unity Play/빌드/실행과 수치 변경 없음。

## 결론

기존 승인 B 금속 스파크/E2 탄을 유지하고, 둔화·보스 가속·코어 위협 판독을 먼저 보강한다. 화면 전체 후처리는 선택 사항이다. 아래 순서는 VFX 내부의 우선순위이며 기존 밸런스 실측 재개 순서를 대체하지 않는다.

VFX는 사건·상태를 보여주는 표현, 셰이더는 개체를 그리는 방식, 후처리는 카메라 화면에 적용하는 효과다. 모든 VFX에 새 셰이더가 필요한 것은 아니다.

## 확인한 구현

- CoreGuardianCombatArt: 기술병/단일/범위 포탑 탄, 적 피격/처치, 적 이동 버프, 포탑 공격력 버프, 코어 피해, 골드 획득의 9종 승인 스프라이트 사용. 피격0.2초·처치0.55초·코어 피해0.35초 표시와 alpha 감소가 있으며 연속 프레임 효과는 아니다.
- CoreGuardianCombatAnimation: 발사 반응과 짧은 발사 플래시가 있다.
- CoreGuardianPrototype: 적 이동 버프와 공격 포탑 버프를 대상 상단 표식으로 표시한다. 지원 포탑/증강의 공격력 버프가 같은 표시 조건에 포함된다.
- CombatData/Session: 보스 절반 체력 이하 가속과 증강 명중 둔화가 있다. 확인한 표시·애니메이션 코드에서 두 상태의 전용 표현은 찾지 못했다.
- CoreGuardianAugmentationView: 카드 뒤집기·등급별 스파크가 UI로 구현돼 있다.
- manifest: URP17.6.0. UniversalRP는 Renderer2D를 참조한다. 저장된 전투 씬 Main Camera의 m_RenderPostProcessing=0, DefaultVolumeProfile의 Bloom intensity=0. 현재 열린 에디터·실행 화면은 이번에 확인하지 않았다.
- Notion 효과 문서에는 한글 폰트·애니메이션의 과거 설명이 일부 남아 있다. 구현 상태는 최근 인수인계와 현재 코드로 구분하고, 채택 효과 형태·색감은 유지했다.

## 전투 VFX 목록

P1=첫 보강, P2=완성도 보강, P3=선택 장식. 신규 표현은 모두 제안이다.

| 우선 | 항목 | 현황과 제안 |
|---|---|---|
| P1 | 둔화 | 규칙 있음·전용 표시 미확인. 작은 둔화 문양과 약한 부분 색 변화로 표시하고 실제 지속 시간에 맞춰 해제한다. 이동 버프 화살표와 형태로 구분한다. 빙결로 오인될 얼음 감옥은 제외한다. |
| P1 | 보스 가속 | 규칙 있음·전용 표시 미확인. 진입 순간 각진 펄스와 유지 표식을 제안한다. 기존 보스 안광 외형과 적 이동 버프의 의미를 보존한다. |
| P1 | 피격 | 승인 금속 스파크 있음. 짧은 부분 밝기 플래시를 추가 비교한다. 연속 피격에도 흰색 실루엣으로 고정되지 않게 한다. |
| P1 | 코어 피해/위험 | 국소 플래시·감소 숫자 있음. HUD와 짧게 연동한다. 낮은 에너지의 약한 경고 펄스는 후보이며 시작 기준은 미확정이다. |
| P2 | 발사/투사체 | 3종 탄·발사 플래시 재사용. 짧은 픽셀 잔상과 타이밍 보강. 추가 탄이 개별 탄으로 읽히게 한다. |
| P2 | 처치 | 정지 파편 페이드 있음. 승인 금속/천 파편의 짧은 움직임 보강. 코어 도착 소멸과 처치/골드 획득은 구분한다. |
| P2 | 버프 | 표식 있음. 부여/해제 펄스만 보강하고 상시 범위 원·연결선의 과밀을 피한다. |
| P2 | 설치/강화/파괴 | 기존 HUD 피드백과 연결해 월드 설비의 짧은 조립 스파크·수정 점등을 검토한다. 성공/실패를 구분한다. |
| P2 | 보스 처치/코어 파괴 | 전용 연출 보강 후보. 보스 금속·수정 파편, 코어 동력 소등과 결과 전환. 판정/증강 진입 시점을 바꾸지 않는다. |
| P3 | 증강 공개/선택 | 기존 뒤집기·스파크 유지. 선택 확정 펄스·짧은 광택만 추가 검토한다. |

범위 포탑은 승인 문서에서 개별 투사체 구별과 스플래시 폭발 미제작을 명시한다. 광역 폭발을 기본 효과로 추가하지 않는다. 현재 확인한 규칙에 없는 독·화상·빙결·치명타·플레이어 피격도 필수 목록에서 제외한다.

## 셰이더 묶음

| 우선 | 묶음 | 용도와 주의점 |
|---|---|---|
| P1 | 스프라이트 상태 반응 | 피격 Flash·둔화 Tint·보스 부분 강조. 관절 보행/공격의 여러 SpriteRenderer에 상태와 해제를 일치시켜야 한다. 원본 색/형태 보존. |
| P1 | 픽셀 VFX 공통 재질 | 스파크·잔상·버프 펄스의 alpha/제한적 가산 발광. 알파/가산은 필요한 렌더 상태별 재질 변형 가능. 투명 사각형·빛 누적 점검. |
| P2 | 외곽선/선택 강조 | 선택 포탑·설치 대상. 텍스처 픽셀 기준 굵기, 아틀라스 패딩/잘림 점검. 관절 조각별 외곽선은 내부 이음매가 생길 수 있어 전체 실루엣 마스크나 별도 선택 표식과 비교. |
| P2 | 수정 부분 발광 | 코어/포탑 수정만 마스크로 점등. 금속·천 전체 발광 제외. Bloom 없이도 먼저 비교. |
| P3 | UI 광택 | 증강 카드. uGUI Mask/RectMask2D 호환 필요. 기존 UI 애니메이션으로 충분하면 생략. |
| P3 | 픽셀 소멸 | 원본 격자에 맞춘 소멸 후보. 파편 애니메이션과 겹치면 한쪽만 채택. |

처음에는 P1 두 공통 묶음으로 시작한다. 유닛별 셰이더를 각각 만들 필요는 없다. 개체별 Material 복제 누적을 피하고 공통 재질/개체 파라미터 전달을 검토하되 배칭·할당 비용은 구현 후 실측한다.

## 후처리

| 항목 | 판단 |
|---|---|
| Bloom | 선택. 코어·수정의 빛을 약하게 확장하는 후보. 기본 Bloom은 밝기 기준이므로 밝은 길·숫자도 번질 수 있다. 수정만 빛나게 하려면 마스크/레이어 분리를 검토하고, 먼저 국소 발광 스프라이트와 비교한다. |
| 색보정 | 선택. 전장/유닛 분리 목적. 승인 팔레트와 밝은 길 대비가 유지되는지 원본과 비교한다. |
| Vignette | 상황 한정 후보. 코어 위험에 약하게 사용 가능하나 가장자리 배치 칸/적 진입/HUD를 가리면 국소 경고로 처리한다. |
| 결과 화면 어둡게 하기/채도 감소 | 선택. UI 오버레이로 충분하면 별도 후처리는 생략한다. |
| Motion Blur·Depth of Field·Chromatic Aberration·Film Grain·렌즈 왜곡 | 기본 사용 제외 제안. 도트 경계·탄·숫자 판독을 해칠 가능성이 크다. |

URP 후처리는 카메라 Post Processing과 Volume 설정을 함께 확인한다. 실제 Canvas 렌더 경로를 확인해 HUD/숫자가 흐려지지 않게 한다. 카메라 설정을 켜는 것만으로 아트/성능 검증이 끝나지는 않는다.

## 제작과 승인 기준

1. 정상 전투 기준 화면 보존 후 둔화·보스 가속·코어 피해를 비교한다.
2. P1 상태/공통 VFX 재질과 작은 표식을 연결한다. 전투 수치·판정은 유지한다.
3. 승인 탄·금속 스파크·파편의 프레임/타이밍을 보강한다.
4. 수정 국소 발광과 Bloom 없음/있음을 비교하고 필요한 경우만 후처리를 추가한다.
5. 정상 구매·이동·공격의 다수 적/추가 탄 전투에서 판독·프레임 시간·오버드로·할당을 계측한다. 이번에는 실행/측정하지 않았다.

피격 중 적 유형, 둔화/가속/버프 형태, 발 그림자·길·체력·숫자가 읽혀야 한다. 연속 명중에 화면이 하얗게 누적되지 않고 해제/재시작 때 효과가 남지 않아야 한다. 최종 Pixel Perfect 규격은 미확정이므로 임의 PPU를 확정하지 않는다. 몬스터 아트 제작/검토 시 MONSTER_ART_STYLE.md와 지정 실제 스프라이트/비교판부터 직접 확인한다. 이번에는 신규 아트·비교판을 제작하지 않았다.
