## 실행 테이블

- `Assets/Resources/CoreGuardian/towers.csv`: 설치비, `upgrades.csv`: 공유 가격/증가량, `stage.csv`: 플레이어 가격·라운드별 수정·준비·증강 주기.
- **`waves.csv`는 기존6열 뒤에 health,defense,speed,gold 4열을 추가했다.** 각 등장 행에 실제 수치를 입력한다. 같은 스프라이트/EnemyKind를 사용하면서 라운드별 능력치를 구분한다. 보스 수치를 직접 바꾸려면 `w10_boss`/`w20_boss`/`w30_boss` 행을 수정한다. 일반 적은 해당 라운드·종류의 등장 행들을 함께 수정한다.
- `enemies.csv`는 바이트 그대로 보존했다. 새 waves의 체력/방어/속도/골드가 해당 기본값보다 우선한다. 코어 피해·버프와 구형6열의 기본값은 계속 enemies가 담당한다. **기본 enemies의HP만 바꾸면 override된 등장 행에는 반영되지 않는다.** 에디터 TextAsset 재임포트도 구분한다.
- 로더는 구형6열을 지원하고 잘못된 체력/속도·방어100% 이상·음수 보상을 거부한다. 실제 생성 시 각 행의 Spec을 연결하며 전역 기본 Spec을 변형하지 않는다.
- 전체1946개체. 일반적 수량15→최대120, 간격1.62/1.53초의1~2R은 유지한 뒤3R.55초→29R.21초로 혼합 밀집한다.10/20/30R은 방패3명0/.25/.5초→보스.75초→나머지1.5초 이후다. [전체30R 요약](table_summary.json).
- 전원 처치 상한은10277골드, 완료 수정2295(시작100/증강 별도)다. 이는 실제 획득 보장값이 아니다. 강화 없이 저축하면1R 완료 후부터 추가 설치 또는 공유 강화가 가능하다.

## 남은 판단과 보존

고정 정책 전투만 평균약30분대이며 준비/카드 대기를 생략했다. **100R·40분 목표는 아직 미달**이다. 이번은30R 성장·물량·보스 실험 범위이며 사람의 이동/공격 기여·구매 선택과 실제 진행 시간을 다음에 확인한다. 혼합 정책의 공유 투자 분산·후반 방패 압박·지원 배치·다수 전투 CPU/GPU 성능도 후속이다. 정적 가격/기능QA/시뮬레이션/정상 초기 스모크를 구분한다.
