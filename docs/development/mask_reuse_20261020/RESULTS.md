메모리는 Profiler.GetRuntimeMemorySizeLong 합계이며 GPU VRAM/Memory Profiler snapshot이 아니다. 100프레임의 실시간 길이와 자세·경로 위치가 달라 마지막 RT 크기도 다르므로 이 값을 메모리 절감률로 쓰지 않는다. 새 방식은 동일한 작은 자세에서도 과거 최대 용량을 보유하므로 더 많은 메모리가 필요할 수 있다.

표의 변화는 참조·배열/정렬·RT 재사용 묶음 효과다. 개별 기법에 절감량을 분배하지 않는다. Session 코드는 바꾸지 않았으나 dt가 짧아져 하위 Tick 횟수와 투사체 위상이 달라진다. 전체 프레임 향상을 해당 CPU 함수 절감량으로 단순 합산하거나 GPU 시간 절감으로 단정하지 않는다.
