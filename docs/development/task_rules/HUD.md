# HUD 작업 보호 규칙

HUD·설치/능력치·피해 표시·입력·포탑 발광을 변경할 때 읽는다. 2026-10-21 기존 승인 규칙을 이동했다. 아래 과거 검증/빌드의 시점과 현재 실행 상태를 구분한다.

- 피해 HUD는 사용자 선택한 기본 빈 트랙·안쪽 여백·역할별 심볼과 얇은 황동 포인트 손잡이를 보존한다. 하단 독립 ‘피해 접기’ 글자 버튼, 큰 직사각형 글자 탭, 큰 삼각 돌출 시안으로 되돌리지 않는다. 막대는 기존 최대 피해 대비 비율이며 전체 피해 합계 대비 비율로 임의 변경하지 않는다. 접어도 집계를 유지하고 오른쪽 가장자리 손잡이로 다시 펼칠 수 있어야 한다. 상세 외형·구현·검증은 `docs/development/damage_hud_applied_20261017/README.md`, 표시 규칙은 기존 Notion ‘HUD 화면 및 표시’가 담당한다.

- 능력치 HUD는 사용자 선택 A안의 안쪽 단일 패널·항목별 심볼을 유지한다. 현재 능력치 조회와 강화 구매를 구분하며 지원 포탑에 직접 공격 수치를 표시하지 않는다. 최신 구현·실제 화면·검증 범위는 `docs/development/hud_ability_A_20261017/README.md`, 표시 규칙은 기존 Notion ‘HUD 화면 및 표시’를 따른다.

- 사용자 지시로 설치 UI를 닫을 때 남던 `포탑 #번호 · 능력치` 작은 요약 바와 해당 재개방 손잡이를 제거했다(`1cfecfa`). 이를 재생성하지 않는다. 실제 큰 능력치창의 접기 손잡이·피해 HUD 손잡이와 구분하며, 포탑 능력치는 월드 포탑 클릭으로 다시 조회한다. 담당 기록은 `docs/development/hud_tower_summary_removed_20261017/README.md`다.

- 접기 손잡이 반응과 설치 포탑 심볼은 사용자 선택 B안을 유지한다. 기존 얇은 황동 손잡이의 Hover 청록 강조·Pressed 반응과 원본 외형에 따른 긴 포신/세 포신/양팔 수정 구분이다. 기존 피해 HUD의 역할 심볼과 혼동해 교체하지 않는다. 담당 기록은 `docs/development/hud_handles_tower_B_20261017/README.md`다.

- 포탑 국소 발광은 사용자 선택한 **단일1/범위(멀티)3/지원1**을 보존한다. 단일 짧은 발사 섬광·멀티 중앙→양옆 순차 점등·지원 수정 호흡과 실제 범위 내 아군 발사 반응이다. 기존 원본·탄환·반동·전투 수치를 유지하고 빠른 연사는 점등도 단축한다. 코어 전용 발광/움직이는 입자와 구분하며, 국소 효과 선택을 카메라 Bloom/HDR/전체 후처리 적용 승인으로 확대하지 않는다. 상세는 `docs/development/tower_glow_applied_20261017/README.md`, 표현 규칙은 기존 Notion ‘셰이더·화면 후처리 기준’이 담당한다.

- **입력·빌드 구분:** WASD UI 탐색 차단9935523/집중Play1/1, 마우스Hover/클릭·플레이어이동 유지. 담당 `hud_navigation_20261020/README.md`. 기존 `Builds/Windows_20261020_30R/CoreGuardian.exe`는aab5b86게임/오류0·경고499빌드로 WASD후속수정 미포함·최적화미적용이다. 이전 빌드/실행 승인을 새 빌드 자동 승인으로 확대하지 않는다.
