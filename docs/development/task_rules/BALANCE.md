# BALANCE 작업 보호 규칙

전투/경제/라운드/증강 분석·변경 시 읽는다. 아래는 기존 승인 범위/자료 한계를 유지한 작업 규칙이며 현재 수치는 최신 담당 Notion·씬 참조→CombatData.Load→Session에서 재확인한다. 파일 경로는 프로젝트 루트 기준이다.

- 밸런싱에는 `core-guardian-balance`와 설치한 `headless-game-balance`를 함께 사용한다. 동일 게임 로직·고정 정책/버전·대응 시드·분포/실패 원인 비교를 적용하며, 기존 8회 비지정 시드 결과를 결정론적 반복 실험이나 통계적 승률로 재분류하지 않는다. Unity 작업에는 설치한 공식 `unity@unity-agent-plugin`의 관련 스킬을 사용하고 현재 연결 명령 스키마를 확인한다. 설치·적용·다음 계측 계약은 `docs/development/balance_skills_20261019/README.md`를 따른다. 스킬 설치는 전투 수치 변경·새 Play/빌드·MCP 중복 연결 승인으로 확대하지 않는다.

- **현재 게임은30R 실험(aab5b86):** 설치 단일60/다중60/지원75, 공유강화60→90→120(+30), 플레이어40→65→85→110…, 준비20초, 증강5/10/15/20/25R완료·보스처치와독립·30R종료. 보스HP500/1600/4500·방어5/12/20. `waves.csv`의health/defense/speed/gold가enemies기본값보다 우선한다. 담당 `aggressive_30r_20261020/README.md`. - **종류별 공유강화/HUD는 유지:** 같은 종류의 현재/이후 설치분·철거 후 단계 유지·새세션초기화·설치비50%환급(공유강화비환급없음), 동일 능력치/강화 패널·세로탭·칸 위치/순서, 일반8/보스12칸 체력바와 병종별 높이. 담당 `shared_towers_hud_20261020/README.md`; 그 문서의 과거40→100→120 가격은 현재30R가격으로 대체됐다.
