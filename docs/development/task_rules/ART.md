# ART 작업 보호 규칙

몬스터·보행·방향·그림자·체력바를 생성/수정/검토할 때 읽는다. 2026-10-21 기존 AGENTS에서 원문 규칙을 이동했다. 세부 증거·리소스는 각 담당 기록이 정본이다.

- 몬스터 아트 생성·수정·검토를 시작하기 전에 `docs/art/MONSTER_ART_STYLE.md`를 반드시 읽고, 문서가 지정한 현재 적용 병사 3종의 실제 스프라이트와 비교판을 직접 확인한다. 현재 적용 몬스터를 공통 화풍 기준으로 삼아 한 사람이 계속 제작한 느낌을 유지한다.

- 새 몬스터·보스 시안은 현재 병사와 동일한 픽셀 확대 배율로 나란히 제시한다. 고해상도 픽셀풍 생성 이미지만 보고 화풍/픽셀 일치를 완료했다고 하지 않는다. 시점·비율·팔레트·픽셀 격자·명암 밀도를 비교하고 어긋나면 먼저 수정한다. 기준 몬스터를 새 시안에 맞춰 임의 변경하지 않는다.

- 애니메이션은 기존 플레이어·포탑·몬스터 원본 외형을 기준으로 한다. 임의 재디자인으로 대체하지 않는다. 방향 전환은 방향 변수나 관절 움직임만으로 완료 처리하지 말고, 실제 웨이포인트 경로에서 표시되는 X±/Y± 외형·프레임까지 확인한다. Y+ 뒷방향/Y- 앞방향 요구와 최신 파생 리소스는 `docs/development/vertical_facing_20261016/README.md`를 따른다. 기능 통과를 파생 아트 승인으로 간주하지 않는다.

- 방향별 외형은 머리·상체·골반·무릎·뒤꿈치/앞코까지 함께 확인한다. 상체만 돌리거나 옆모습 다리를 반전한 것을 뒷모습 완성으로 처리하지 않는다. 원본 픽셀/팔레트 일치나 단순 반전 일치 검사도 자연스러움의 증거가 아니다. 플레이어 최신 상행 하체와 전체 재생성 후처리 순서는 `docs/development/player_rear_lowerbody_20261016/README.md`를 따른다.

- 플레이어 보행 수정은 실제 씬의 정상 키 입력으로 이동→방향 전환→정지를 확인한다. 격리 프리팹 Preview, 고정 자세, 실제 게임 카메라, 사람 직접 플레이를 구분해 기록하고 비교 캡처의 배율·위상·임시 줌/주입 여부를 명시한다. 카메라 렌더에 ScreenSpaceOverlay HUD가 포함됐다고 가정하지 않는다.

- 그림자는 실제 렌더러·참조 리소스부터 확인한다. 정지 발 복제 `바닥 밀착선`은 계속 끄고, 이동 개체는 현재 프레임 하단의 동적 접촉을 사용한다. 과거 ‘모든 몬스터 중앙 타원 유지’를 최신 공통 규칙으로 적용하지 않는다. 승인된 종류별 교체/유지 범위는 `docs/development/photo_shadow_applied_20261018/README.md`가 담당한다. 원본 발 도트·프리팹·발 중심 정렬은 변경하지 않는다.

- **접지감 후속은 원본을 유지하고 그림자만 다듬는다.** 기준 사진은 `docs/development/shadow_reference_extract_20261018/reference_user_selected.png` 하단 ①이다. 본체 뒤쪽 오른편의 넓고 뭉뚝한 노출 그림자와 발/받침 접점을 기준으로 하며 세부 무기·팔다리 투사/임의 타원·다각형/새 받침·앵커/생성형 본체 재제작으로 되돌리지 않는다. RGB 사진의 알파와 가려진 영역은 완벽한 복원이 아니다. 추출 당시 시안은 이후 사용자 승인으로 `8a5c303`에서 실제 적용했다. 현재 담당은 `docs/development/photo_shadow_applied_20261018/README.md`이며 `27b92d8`의 기존 포탑 하단 명암·효과는 보존한다.

- 머리 위 체력바는 모든 병종의 공통 고정 높이로 처리하지 않는다. 현재 원본/방향별 프레임·위로 솟는 장비·투명 여백을 확인하고 본체와 겹치지 않는 안정된 기준점을 사용한다. 보행 프레임마다 들썩이지 않는지와 HP비율 표시를 함께 검증한다. 현재 높이/구현은 `docs/development/health_shadow_20261016/README.md`가 담당한다.
