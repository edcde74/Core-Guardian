# 후속 제작·검증 작업 순서

노션: https://www.notion.so/3f4389dbfc688171b84dc19b138925f4

# 역할
현재 전투 프로토타입 이후의 작업 순서와 완료 확인 항목을 관리합니다. 상세 시스템 규칙과 아트 규격은 연결된 담당 기획서에서 관리합니다. 아래는 제안 작업 순서이며 아직 구현한 결과가 아닙니다.
# 현재 출발점
- 정식 전투 진행은 1~9라운드까지 연결했습니다. 일반 적·포탑 3종의 별도 역할 검증 모드도 유지합니다.
- B 전투 효과·E2 기술병 탄·Pixelify Sans Bold TMP가 적용됐습니다.
- 정식 10~11라운드·보스·증강은 미구현입니다. 기존 Windows 실행 파일도 최신 전투 씬을 반영하지 않습니다.
# 먼저 할 작업
1. 실제 조작으로 현재 전투 피드백 확인: 피해 숫자와 투사체 크기, 버프 표식·체력 막대 겹침, 설치 커서·Esc, 명중·처치 체감 확인. 발생 조건과 화면을 남깁니다. 담당: [담당 기획서](https://www.notion.so/3df389dbfc6881fc9f1bd004adfc5999).
2. 발견한 버그와 판독 문제 수정: 입력·전투·표시 오류를 재현하고 수정 전후 결과를 비교합니다. 현재 승인 크기·그림자·A 길 유지.
3. 2~9라운드 실행 편성 확정: 2026-10-10 사용자 확인 완료. 고정 순서·0초 첫 생성·공통 간격을 확정하고 실행 CSV에 반영했습니다. 라운드 간 진행 연결도 구현했고 실제 난이도 플레이테스트는 남아 있습니다. 담당: [담당 기획서](https://www.notion.so/3e6389dbfc6881c5aa2bed3c32047474) 및 [담당 기획서](https://www.notion.so/3e6389dbfc68815db2e7e95be4598092).
4. 정식 2~9라운드와 라운드 간 흐름 구현 — 완료: 종료→보상→다음 50초 준비→전투를 연결했습니다. 포탑·강화·재화·코어 상태 유지, 패배와 보상 중복 방지, 9라운드 완료 및 재시작을 자동 테스트로 확인했습니다. 담당: [담당 기획서](https://www.notion.so/3e6389dbfc68819fbfe5ca17f14460d3).
# 전체 프로토타입 연결
5. 10라운드 보스 구현: 기존 보스 설계의 전투와 코어 도착을 연결하고 생존·처치 결과를 구분해 검증합니다. 보스 외형은 별도 시안·컨펌 후 제작합니다. 담당: [담당 기획서](https://www.notion.so/3df389dbfc6881ea9f5ec4e0f7b8084c).
6. 증강 선택·추첨·자동 선택·효과 적용 구현: 기존 카드 기획서대로 연결하고 보스 처치 여부·중복 후보·효과 적용을 검증합니다. 담당: [담당 기획서](https://www.notion.so/3e6389dbfc6881bf9600d5f42fb68a44).
7. 11라운드와 프로토타입 종료 연결: 10라운드에서 선택한 증강 효과가 11라운드에서 작동하는지 확인합니다. 100라운드 최종 승리와 구분된 종료 화면을 검토합니다. 담당: 게임 루프·웨이브·증강 문서.
8. 1~11라운드 연속 플레이테스트·밸런스 조정: 라운드별 코어 피해, 처치 시간, 골드·수정, 설치·강화 선택과 실패 지점을 기록합니다. 현재 수치는 가안이므로 결과를 보고 조정합니다. 담당: 플레이테스트 및 데이터·밸런스 문서.
# 아트·사용감 후속 작업
9. 애니메이션 제작 조건 확정: 기술병과 일반 적의 방향 수·프레임 수, 공격 동작·발사 시점을 먼저 정합니다. 발/받침대 앵커·현재 크기 유지. 담당: [담당 기획서](https://www.notion.so/3f3389dbfc6881d2a70be916ded8ddb7).
10. 2순위 움직임·발사 아트 제작·적용: 기술병 이동, 적 3종 보행, 스패너 공격 동작, 공격 포탑 발사, 군기병·지원 포탑의 작동 표현. 조건 확정 후 제작하고 실제 속도와 발사 타이밍을 비교합니다.
11. 기존 HUD 시안으로 표시 정리: 아이콘·버튼 상태·정보 패널·라운드 결과·증강 선택 화면을 실제 구현 범위에 맞게 정리합니다. 한글 글꼴과 다양한 자리 수·화면 크기를 확인합니다. 담당: [담당 기획서](https://www.notion.so/3df389dbfc68811f9a87e5a5ff05a571).
12. 3순위 분위기 마무리: 약한 코어 반복 빛, 설치·강화·파괴 효과, 최종 석재 바닥·A 길 아트 정리. 최종 픽셀 규격·제한 팔레트·카메라·기준 해상도는 별도 검토·확정합니다.
13. 사운드 범위와 에셋 현황 확인 후 추가: 발사·피격·처치·코어 피해·설치·강화·UI 효과음과 음량 균형. 기존 사운드 기획·보유 파일을 먼저 확인하며 이번 목록만으로 새 규칙을 확정하지 않습니다.
# 배포·최종 확인
14. 최신 Windows 실행 파일 제작: 시작 씬과 포함 씬을 확인하고 최신 전투·아트·폰트·라이선스를 포함합니다. 필요하면 현재 1라운드 확인용 빌드를 먼저 만들 수 있습니다.
15. 실행 파일에서 회귀·사용자 플레이테스트: 새 게임·재시작·패배·라운드 전환, 입력·설치·강화·환급, UI 겹침, 폰트·효과·성능과 오류를 확인합니다.
# 다음 작업 추천
현재 화면의 짧은 실제 플레이 확인과 버그 수정을 마친 뒤, 연결된 1~9라운드로 실제 연속 플레이를 진행하고 난이도·코어 피해·재화·강화 선택 결과를 기록합니다. 애니메이션은 제작 조건을 정한 뒤 별도로 진행합니다.
