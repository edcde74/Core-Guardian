# 전체 HUD 스프라이트 적용

2026-10-13 (Asia/Seoul). 사용자의 승인 시안과 최신 카드 지시를 Unity 런타임 HUD에 적용했다. 밸런스 테스트 채팅 완료 확인 후 시작했으며, 그 채팅에서 이후 적용한 HP27/생성 간격 CSV는 보존했다.

## 적용 범위

- 공통 금속·황동 프레임, 오버용 청록 프레임, 비활성 프레임, 기능 심볼을 모든 버튼과 상태·설치·플레이어 강화·타워 정보·피해 목록·보스 상태·라운드 상태·증강 패널에 연결했다. 상태 표시는 항목별 심볼과 한글을 분리했다.
- 버튼은 오버/포커스 밝기, 누르는 동안 글자 3px 이동과 표면 명암, 열린 메뉴/설치 대상의 선택 테두리를 제공한다. 비활성 입력은 기존 단계/재화 조건으로 차단한다. 실제 강화 성공 때만 강조와 증가량 피드백을 표시한다.
- 강화에 현재→다음·증가량·비용/재화 부족을 표시한다. 값은 실행 CSV의 현재 스펙·강화 Delta로 계산하며 공격력 표시에는 0.5 올림을 사용한다. 별도 전투력 지표는 만들지 않았다.
- 설치/플레이어/피해/상단/선택 타워/증강의 독립 접기 조작을 연결했다. 설치 접기와 Esc 취소의 기존 차이를 유지했다. 오른쪽 모서리 조작은 앵커를 고정했다.
- 증강은 글자·배지 없는 뒷면 세 종류의 스프라이트를 사용한다. 은색/금색/청백색의 실제 테두리·수정·장식이 다르다. 처음 클릭 공개, 뒤집기 완료 후 재클릭 선택이다. 다른 카드가 닫힌 상태에서도 선택할 수 있다.
- 뒤집기 .44/.66/.92초, 네 변 스파크 14/30/52+20개, 등급별 원본 합성 효과음을 연결했다. Play 배속과 별개로 UI 연출은 unscaled time을 사용한다. 숨기기/선택/타임아웃에서 연출과 사운드를 정리하고 오래된 클릭은 Session 단계로 거부한다.
- 기존 30초 최고 등급/동률 왼쪽 자동 선택과 선택 후 준비 50초 흐름을 유지했다. 전투 피드백은 HUD보다 아래 계층이다. 게임 수급/전투 판정·원본 프리팹·저장 씬은 변경하지 않았다.

## 스프라이트와 제작

내장 imagegen으로 투명 원본 아틀라스와 등급별 뒷면을 제작했다. [프롬프트](../../Assets/Art/Hud/20261013/prompts.md), [원본/아트](../../Assets/Art/Hud/20261013/), [실행 스프라이트](../../Assets/Resources/CoreGuardian/Hud/). 승인 보드를 통째로 HUD에 사용하지 않았다. `ImportHudSprites.cs`의 에디터 API로 알파 경계 추출/최근접 정규화/메타 생성을 수행했다. 심볼48×48, 프레임128×96·9-slice, 뒷면160×240. Point/무압축/mipmap 없음, 20개 PNG 모두 알파 최솟값0 확인. 인수인계의 공통 Pixel Perfect 규격을 새로 확정한 것은 아니다.

## 검증과 복구

- 시작/종료: CD Unity6000.6.2f1 ready, Play stopped, compiling=false, domainReload=false. 전투 씬 loaded/active/dirty=false. 최종 콘솔 현재 오류0/컴파일실패false, 경고1.
- [EditMode 73/73](hud_editmode_20261013.json), [최종 PlayMode 8/8](hud_playmode_20261013.json). 기존 1~11 흐름·재시작·보상·상단 정보와 새 첫 클릭 공개/연속 클릭 차단/재클릭 선택/중단 정리 검사 통과. 기존 HP25 고정 가정 테스트는 현재 데이터의 체력으로 검증하도록 수정했다. CSV는 이번 작업에서 변경하지 않았다.
- 실제 Play HUD 캡처 직접 확인: [설치/강화](hud_sprite_review_20261013/HudAppliedPanelsFinal.png), [등급별 뒷면](hud_sprite_review_20261013/HudAppliedTiersFinal.png), [공개 앞면](hud_sprite_review_20261013/HudAppliedFrontFinal.png). 캡처 출력1920×1080. 패널 접기 탭과 강화 마지막 행의 겹침을 수정했다. 다른 종횡비의 실제 창 조작 검증은 남음.
- `VerifyHudSprites`의 강제 전투 완료와 고정 실버/골드/플래티넘은 UI 확인용 런타임 주입이며 난이도 실측이나 실제 추첨 결과가 아니다. 실제 버튼으로 첫 공개 뒤 다른 두 장이 닫힌 상태에서 선택, 준비50초 복귀 확인.
- `BuildCombatPrototype.Verify` success=true, A길/적·타워3종/플레이어(15,10)/saved=true 확인. 씬 YAML을 직접 수정하지 않았다.
- 수정 전 복구859b9ec. 이후 다른 채팅의 데이터 적용 d5c45db를 보존했다. 사용자 vendor/음악/분석 미커밋 파일을 임의로 삭제하거나 커밋에 포함하지 않았다.
- HUD 후속 자동 확인 hud는 현재 PAUSED로 확인되었으며 재적용을 반복하지 않는다. Windows 빌드 생성/갱신과 GitHub push는 수행하지 않았다.
