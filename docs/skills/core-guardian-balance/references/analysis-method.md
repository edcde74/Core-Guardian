# 계산과 해석

## 근거

중요한 값에 자료 경로/페이지, 날짜, 기획 상태, 로딩 확인 여부, 계산식/가정, 측정 조건을 붙인다. 기획 수치는 실행 수치로, 시뮬레이션은 실측으로, 자동 Play는 사람의 재미 검증으로 바꾸어 쓰지 않는다. 정적 최대치·계측값·가정 시나리오를 별도 열/선으로 둔다.

## 라운드 위협과 시간

- 수량·총 HP·방어 적용 후 필요한 발수·마지막 생성 시각·생성 간격·동시 위협·코어 실패 비용을 함께 본다. 총 HP/생성 구간은 유입 밀도이며 필요한 방어 DPS가 아니다. 타입 혼합·수비형 체류·버프 동행·보스 가속을 반영한다.
- 노출시간은 실제 경로와 원형 사거리 교차 길이/속도로 구한다. 이동속도 +20%는 지속 노출시간을 약 1/1.2로 줄인다. 버프 범위·속도차·타깃 선정에 따라 실제 지속 여부는 다르다. 두 공격원을 함께 이동한 계측으로 단일 원인의 효과를 확정하지 않는다.
- 마지막 생성과 클리어 시간은 다르다. 누수로 코어까지 가는 적은 전투를 길게 만들 수 있다. 성장 후에도 생성 일정이 클리어 시간의 하한을 만들 수 있다.
- 첫 증강까지 실제 준비 체류+각 전투+전환을 계산한다. 시작 버튼 사용과 준비50초 전부 대기를 분리하고 미구현 라운드는 관측 합계에 더하지 않는다. 선택 시간과 다음 라운드에서 효과를 체감하기까지도 따로 기록한다.

## 화력과 성장

- 피해식·float·반올림 순서를 코드에서 확인한다. 현재 후보식은 `floor(max(0,inputDamage*(1-defense/100))+0.5)`이며 명중마다 반올림한다. 12.5×rate는 실제 반올림 DPS와 다르다.
- 지속 단일 타깃 DPS=명중당 피해×초당 공격횟수. 범위 포탑의 최대 대상 수와 실제 평균 적중 대상 수를 구분한다. 현재 Multi는 대상별 투사체이며 스플래시가 아니다. 지원의 적용 대상도 확인한다.
- 유효 피해는 실제 체력 감소로 집계하고 초과 피해·죽은 대상에게 향한 투사체 손실·사거리 밖 시간·타깃 유지·방어·둔화를 분리한다. 실전 화력을 이상적 DPS 합으로 단정하지 않는다.
- `ceil(HP/명중피해)` 발, `(발수-1)/rate`를 계산한다. 뒤 식은 첫 공격 즉시·정지 타깃·비행시간 제외의 **공격 간격 시간**이며 완전한 처치 시간이 아니다. 첫 명중 지연과 이동은 별도로 붙인다. 피해0이면 미처치로 표시한다.
- 강화 전후 DPS%, 발수 경계, 투사체 도달시간, 사거리 커버 차이를 함께 본다. 피해+20%여도 같은3발이면 체감이 작을 수 있다. 사거리/투사체 속도는 명목 DPS가 같아도 실제 기여를 바꾼다.

## 재화와 선택

- 시작 재화, 처치율, 보스 처치, 완료 보상, 설치·능력치별 비용·환급을 시점별로 추적한다. 전원 처치 수급은 상한이며 구매 정책/실제 구매시점과 다르다.
- 가격 단계가 능력치별인지 전체 공유인지 확인한다. 집중·분산 투자 가능 시점을 비교한다. 종료 잔액과 전투 중 구매 가능 시점을 혼동하지 않는다.
- 타워 강화는 준비 중만 가능할 수 있다. 이전 라운드 종료에 마련된 돈은 다음 준비에 사용한다. 강화2회 목표가 추가 설치2기도 동시에 보장한다는 뜻은 아니다.
- 누수→골드 감소→강화 지연→추가 누수와, 충분한 잔액인데 다음 준비까지 선택을 못 하는 공백을 구분한다.

## 증강

- 카드 풀·등급확률·중복 제외/후보 고갈 복귀·재선택 중첩을 최신 문서에서 확인한다. 독립3장 추첨에서 특정 등급이 하나 이상 나올 확률은 `1-(1-p)^3`; 특정 카드 획득/선택확률과 같지 않다. 선택 정책은 따로 쓴다.
- 가산/곱산 순서, 강화 후 현재 피해 적용, 지원·증강 합산, 추가발 수·동일 대상·과잉 피해, 둔화 갱신/비중첩을 확인한다. 스택이 실제 획득 가능한 시점도 기록한다.
- 예: 피해16·rate1에 실버 피해+2 한 번과 플래티넘 추가 투사체 한 번이면 무방어 정지 타깃 이상적 DPS=(16+2)×2=36. 모두 명중하고 두 카드를 이미 획득한 가정이다. 첫 증강만 있는10R 직후에 두 카드가 동시에 있다고 가정하지 않는다.
- 중첩식이 맞아도 현재 카드 풀/기회 수에서 가능한 빌드인지 별도 확인한다. 등급별 미선택 우선과 화면 중복 제외를 포함해 실제 도달 가능한 조합과 효과식만 보는 가상 조합을 분리한다. 복수 계열의 재선택은 각 등급 후보 소진 조건과 전체 획득 기회를 함께 계산한다.
- 1~10R은 첫 증강 전 빌드와 획득 직후 기획 시나리오를 분리한다. 11R 이후 자료가 없으면 증강 실전 체감/클리어 변화는 미검증이다. 시뮬레이션은 시드·구매 정책·배치·반복 수·중앙값/분위수·실패율을 표시한다.

## 재미 검증

시간만으로 지루함을 증명하지 않는다. 공격 기여0·여러 라운드 구매불가·유사 편성·강화해도 같은 발수·투자해도 같은 결과는 검토 신호다. 같은 배치에서 한 변수씩 바꾼 대조와1배속 사람 플레이로 확인한다. 첫 선택 시간, 적 없는 시간, 조작횟수, 성장 인지, 증강 기대, 실패 이유 이해와 강력한 빌드의 압도감도 기록한다.
