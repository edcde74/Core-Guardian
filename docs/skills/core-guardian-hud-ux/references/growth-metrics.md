# 성장 정보가 오해를 만들지 않게 하기

## 피해

명중 숫자는 실제 감소 체력이며 현재 승인된 초과피해 제외 규칙을 유지한다. 처치 직전 HP가3이면 강한 공격도3으로 보일 수 있다. 원래공격력·성장량과 이 숫자가 다름을 설명하고, 큰 숫자를 위해 초과피해를 표시하는 규칙을 바꾸지 않는다. 명중/골드/코어 피해의 색·아이콘·자리·겹침·수명·클릭통과를 함께 살핀다. 색만으로 대상을 구분하지 않는다.

누적 피해는 라운드 총효과이며 DPS가 아니다. 최대 기여자 대비 막대라면 총합 점유율로 쓰지 않는다. 매번 정렬이 바뀌는 목록의 추적성, 기여0인 대상의 행 존재 여부, 지원타워의 간접 기여 누락을 확인한다. 직접 피해가 없는 지원타워를 낮은 성능으로 판정하지 않는다.

## 스펙 증가량

구매 직전 현재값→구매 후값·차이·해당 능력치 단계·가격을 같은 영역에서 보여주는 안을 비교한다. 플레이어와 타워 개체/재화 종류를 명시한다. 기존 능력치만 사용하고 지원은 버프%와 범위로 설명한다. 지원+증강/강화의 적용 순서와 적용 대상을 확인한다.

예: 기술병 공격력10→12(+2,+20%)는 스펙 증가이며, 공격형25HP의 단독처치가3→3발이면 처치시간20% 단축이라고 표시할 수 없다. 피해12.5→15는 승인된 HUD 반올림 규칙에서13→15로 보일 수 있다. 원시 입력값과 실제 명중값/방어 적용을 구분하며 화면 표시 규칙을 임의로 재정의하지 않는다.

애니메이션은 실제 승인된 변경 뒤에만 발생해야 한다. 반복 구매 시 변화 누적/최종값, 실패 시 무변화, 다른 사건으로 텍스트가 덮이는지, 패널 접힌 상태에서도 어느 대상이 강해졌는지 보이는지 평가한다. 화면 중앙 모달·큰 폭발·모든 숫자 동시확대는 전투 시야 비용을 비교한다.

## 전투력/DPS

통합 전투력을 필수로 가정하지 않는다. 플레이어/단일/범위/지원은 타깃 수·사거리·가동률·방어·둔화·과잉피해·지원수혜가 달라 하나의 숫자가 역할을 숨긴다. 사거리/투사체 속도 강화는 명목DPS를 안 올려도 방어에 도움이 된다. 통합 점수 도입은 새로운 지표 정의이므로 계산/목적/검증 없는 공식을 임의로 넣지 않는다.

이론 단일DPS=명중별반올림피해×초당발사수. Multi 최대3명 지속 적중 상한과 실제 평균 타깃 수를 구분한다. 선택한 적의 방어·버프 상태 등 가정이 있어야 한다. 실전DPS를 표시할 때는 측정시간창·유효피해·범위밖시간과 근거 데이터가 있어야 한다. 분석표에서만 비교하거나 상세 패널에 조건부로 제안할 수 있고 상시 필수지표로 확정하지 않는다.

## 클리어 시간

실제 전투 시작→완료 시간, 준비 포함 전체 라운드 시간, 마지막 생성 시각, 시뮬레이션 예측을 분리한다. 기록 필드/이벤트가 없으면 **추가 계측이 필요한 UI 제안**으로 남긴다. 새게임 상태나 HUD를 바꾸어 임의로 재측정하지 않는다.

다른 라운드는 편성·출현시간·누수·배치·타깃이 달라 직전보다 빨랐다는 사실만으로 강해졌다고 증명하지 않는다. 같은 조건/동일라운드 반복 비교의 실제 결과가 있을 때만 단축량을 비교한다. 보상/코어손실/유효피해와 함께 종료 카드에 전투시간을 보여주는 안은 검토 가능하지만 클리어 속도로 추가 보상을 지급하는 새 게임규칙을 만들지 않는다.

## 평가 출력

각 제안에 데이터가 **이미 존재 / 계산 가능 / 추가 계측 필요 / 기획만 있음 / 미확인**인지 표시한다. 소스/과거화면/현재실행/해상도 계산/사람 체감은 다른 근거다. 와이어프레임 숫자는 예시·미적용이며 현재화면의 실측값으로 표기하지 않는다.
