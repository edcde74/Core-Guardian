# 코어 가디언 밸런싱 방향 합의 · 2026-10-19

상태: 사용자 방향 동의. 구체 수치·지급 라운드·구현은 미확정이다. 시작 Git HEAD는 `915bca5`다.

## 합의한 경험

1배속으로 준비·증강 선택까지 포함해 약 40분에 100라운드를 진행한다. 100라운드 완주는 충분히 어려운 도전으로 만들고, 플레이어가 성장 선택과 배치·이동으로 약점을 보완하게 한다. 강한 증강 빌드를 완성하는 재미와 보상은 유지한다.

사용자 체감 문제는 설치 사이 대기가 길고, 현재 전투가 쉽고, 10라운드마다 한 번인 증강이 드물다는 것이다. 이는 사람의 피드백이다. 기존 자동 계측은 별도의 관측이며 전체 이용자의 난이도·승률을 증명하지 않는다.

## 시간과 결정의 빈도

전체 2,400초를 100라운드에 배분하면 평균 24초다. 이는 준비·증강까지 합한 평균이며 매 전투의 제한 시간이 아니다. 비교용 시간 예산은 전투 28~30분, 준비 6~8분, 증강 선택 3~4분 중 합계 약 40분이 되는 조합이다. 예컨대 29+7+4분은 예산 예시이지 적용 수치가 아니다.

일반 라운드는 짧고 밀도 있게 만든다. 준비는 판단 후 빠르게 시작할 수 있게 하되 모든 플레이어에게 짧은 선택 시간을 강제하지 않는다. 설치·포탑 강화·플레이어 강화·저축 사이의 의미 있는 판단을 매 라운드 또는 1~2라운드마다 경험하는 것을 비교 목표로 삼는다. 매 라운드 포탑을 새로 설치해야 한다는 뜻은 아니다.

배속 기능은 미정이다. 1배속에서 재미와 리듬을 먼저 검증한다. 장시간 방치 구간을 배속 기능으로 해결한다는 전제로 설계하지 않는다.

## 증강 비교 후보

첫 3라운드에서 증강을 경험하고 이후 5라운드 단위로 선택하는 안을 비교 후보로 둔다. 정확한 지급 라운드 배열·보스와 겹치는 경우·보스 처치 의존 여부는 실험표에서 정한다. 일반 증강과 보스 별도 보상의 분리는 추가 검토안이다.

선택 횟수가 늘 때 기존 효과·확률·중복 선택·재화 보상을 그대로 채택하지 않는다. 강한 조합의 성장과 후반 적 위협을 함께 비교하며, 강한 빌드라는 이유만으로 일괄 하향하지 않는다. 카드 수치나 제한 시간 변경은 승인·적용하지 않았다.

## 검증과 결정 순서

1. 현재 CSV→전투 씬 참조→CombatData.Load→Session을 대조하고 기존 계측기를 재사용한다. 과거 문서 수치를 현재 실행값으로 가정하지 않는다.
2. 현행 기준을 보존한 비교표에서 전투 시간·첫 유효 구매 시점·구매 간격·배치와 이동·코어 손실·피해 기여·골드/수정 수지·증강 후보/선택을 분리한다.
3. 현재 구현 범위인 1~11R에서 1~2R 압박, 3~9R 성장/실패, 10R 보스, 11R 증강 후 성능을 먼저 비교한다. 이후 100R 전체 곡선은 별도 설계·구현·검증이 필요하다. 초반 결과만으로 100R 약 40분 달성을 주장하지 않는다.
4. 정상 전투 계측·정적 계산·사람 1배속 체감·주입 기능 QA를 구분한다. 자동 비교는 고정 정책/버전·대응 시드와 분포를 사용한다. 기존 미지정 시드 8회를 승률로 재분류하지 않는다.
5. 관측→원인 가설→한 변수씩 바꾸는 후보를 제시한 뒤 수치 적용을 결정한다. 목표 승률이나 새 비용·적 HP·간격을 임의로 정하지 않는다.

성공 판단에는 첫 성장 전 대기와 연속 무행동 구간이 줄었는지, 선택의 효과를 사람이 알아볼 수 있는지, 구매를 해도 배치·이동·보스 대응이 필요한지, 완성 빌드가 보상을 주는지, 전체 시간 예산이 맞는지를 포함한다. 현재는 모두 후속 검증 항목이다.
