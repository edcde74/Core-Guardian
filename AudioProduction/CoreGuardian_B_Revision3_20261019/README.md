## 다른 컨셉으로 제작

- 철거① 기계식 회수: 체결부 해제→금속 이동→회수. ② 마력 회수: 비음정 압력이 안으로 모여 소멸. ③ 석재 봉인 해제: 거친 마찰→무거운 분리.
- 골드/플래티넘① 무광 패: 짧게 쓸고 한 번 탁 안착. ② 중량 봉인: 거친 잠금이 풀리고 낮은 장치 몸통이 열림. ③ 마력 압력: 천천히 모인 공기가 넓게 풀리는 질감.
- 증강에 말렛/음정 음표/이전 bong 재료/오름차순 음정/추가 반동 타격을 사용하지 않았다. 새 필터 노이즈 폴리와 기존 장치 재료를 동작별로 다르게 조합했다. 플래티넘은 반복 타격 대신 몸통과 공기 길이를 늘렸다. 실버③은 수정하지 않았다.
- 음정 레이어를 제거했다는 제작 사실은 사용자의 무게감·차이 체감 승인과 별개다. 에이전트 직접 청취를 했다고 표현하지 않는다.
