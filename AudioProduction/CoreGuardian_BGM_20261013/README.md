# 코어 가디언 BGM 시안 3종

제작일: 2026-10-13 (Asia/Seoul). 사용자 요청에 따라 음악 파일만 제작했으며 Unity에 적용하지 않았다. `Assets`, 씬, 프리팹, 게임 코드, 오디오 설정을 변경하지 않았다.

세 곡 모두 16마디이며 완결형 엔딩 대신 첫 화성으로 돌아오는 진행을 사용했다. 마지막 음의 릴리스와 다중 지연 잔향을 시작 부분으로 순환시켜 루프 끝에서 잘리지 않게 했다. 전체 페이드아웃이나 무음 패딩은 사용하지 않았다. 최고역을 완만하게 줄이고 RMS를 -22 dBFS로 맞췄다. RMS는 LUFS 측정값이 아니며, 게임 효과음과의 마스킹을 실제로 검증한 수치도 아니다.

## 제작 방법 검토

1. **Python + 직접 합성 (선택)**: 음표·화성·리듬을 직접 작성하고 NumPy로 가산합성, FM, 잡음 타악, 엔벌로프, 순환 잔향을 계산한다. 외부 샘플 없이 재현 가능하고 루프 길이를 정확하게 통제할 수 있다. 사실적인 현악·관악 연주 질감은 제한된다.
2. **MIDI + FluidSynth + 사운드폰트**: 편곡을 DAW에서 손보기 쉽고 음색을 교체할 수 있다. 렌더러와 사운드폰트의 조건은 별개다. FluidSynth의 공식 FAQ도 입력 MIDI와 사운드폰트 조건을 확인하도록 안내한다. 이번에는 설치·사용·다운로드하지 않았다. https://www.fluidsynth.org/wiki/LicensingFAQ/
3. **MusicGen / AudioCraft**: 텍스트 기반 음악 생성 방법이다. 공식 모델 카드에 코드 MIT, 모델 가중치 CC-BY-NC 4.0으로 명시되어 있다. 상업 게임용 제작에는 비상업 가중치를 선택하지 않았으며 모델을 다운로드하거나 사용하지 않았다. https://github.com/facebookresearch/audiocraft/blob/main/model_cards/MUSICGEN_MODEL_CARD.md

## 사용 도구와 라이선스

- 실제 실행 환경: Python **3.12.14**, NumPy **2.3.5**. Python 표준 라이브러리 `wave`, `json`, `hashlib`, `pathlib`, `math` 등을 사용한다. 외부 신시사이저 프로그램, 플러그인, 샘플, 사운드폰트, 음악 생성 모델은 사용하지 않았다.
- Python: PSF License Version 2 및 포함 구성요소별 라이선스. 공식 조건: https://docs.python.org/3.12/license.html
- NumPy: BSD-3-Clause. 공식 조건: https://numpy.org/doc/stable/license.html . 설치된 2.3.5의 전체 라이선스 고지는 `numpy-installed-LICENSE.txt`에 보관한다.
- 도구의 허용형 라이선스는 상업적 도구 사용을 허용한다. Python/NumPy 자체를 재배포한다면 해당 소프트웨어의 고지 조건을 별도로 따라야 한다. 이번 결과물에는 런타임이나 라이브러리 바이너리를 포함하지 않았다.
- WAV는 이번 요청을 위해 새로 작성한 악보와 자체 합성 음색으로 생성했다. 기존 상업곡을 입력하거나 샘플링·전사하지 않았다. 외부 음악 에셋의 표시 의무, 로열티, 비상업 제한을 가져오지 않는다. 결과물을 공개 CC0 등으로 재라이선스하는 결정은 하지 않았다.
- 모든 기존 곡과의 유사성을 전수 대조한 결과나 독점 저작권 보장은 아니다. 음악적 독창성은 이번 악보를 새로 구성하고 특정 기존 곡을 모사하지 않은 제작 과정에 관한 설명이다.

## 파일과 재현

- 최종 WAV 3개: PCM signed 16bit little endian, 48,000Hz, 2채널 스테레오. 일반적인 Unity WAV 입력 형식으로 제작했다. Unity 실제 임포트·재생 검증은 요청 범위에서 제외했다.
- `compose.py`: 전체 악보, 음색 설계, 믹스, WAV 출력. Python과 NumPy가 있는 환경에서 `python compose.py`로 재현한다. 난수 시드를 고정했다. NumPy 버전·플랫폼 변경 시 마지막 비트까지 동일하다고 보장하지는 않는다.
- `*_score.json`: BPM, 조성, 박자, 마디, 각 음표·음색·팬·음량을 기록한 편곡 데이터. MIDI 파일은 아니며 직접 재편곡할 수 있는 자료다.
- `verify.py`: WAV를 다시 읽어 형식·길이·클리핑·DC·샘플 경계를 확인한다. 실행: `python verify.py`.
- `verification.json`: 측정 결과와 WAV SHA-256.

## 검증 결과와 남은 확인

세 곡 모두 30~60초, 48kHz/16bit/스테레오 PCM, 정확한 마디 길이, 클리핑 0, 미미한 DC 오프셋, 루프 경계 기준을 통과했다.

| 곡 | Peak dBFS | RMS dBFS | 끝→시작 최대 샘플 변화 dBFS |
|---|---:|---:|---:|
| 성채의 행진 | -11.35 | -22.00 | -58.49 |
| 수정 장치의 맥동 | -9.76 | -22.00 | -59.43 |
| 방어선의 긴장 | -11.00 | -22.00 | -67.39 |

경계 변화량은 주변의 일반적인 파형 변화보다 작다. 이는 샘플 연결 검사이며 청각적으로 완벽한 루프의 증명은 아니다. 마디 길이를 가장 가까운 샘플 수로 반올림해 시간 오차는 반 샘플 이하이다. 플레이어가 파일 자체를 반복하면 순환하지만 플레이어가 추가하는 재생 공백까지 보장하지 않는다.

직접 스피커로 청취하는 모니터링은 수행하지 않았다. 장시간 청취 피로도, 선율 선호, 실제 효과음과의 조화, Unity 실제 반복 재생은 미검증이다. 사실적인 오케스트라 녹음·전문 연주·최종 마스터링을 완료한 음원으로 취급하지 않는다. 사용자가 음악 방향을 선택한 뒤 해당 시안의 음색·타악·선율·음량을 다듬을 수 있다.
