## 취득과 사용 조건

- 공식팩: https://kenney.nl/assets/interface-sounds
- 공식다운로드: https://kenney.nl/media/pages/assets/interface-sounds/fa43c1dd4d-1677589452/kenney_interface-sounds.zip
- 제작자공식상업사용안내: https://kenney.nl/support
- 공식페이지와 동봉 `Originals/License.txt`에서 Creative Commons Zero(CC0),개인/교육/상업프로젝트 사용가능·출처표기의무없음을 확인했다. 원본 팩100개와 ZIP/라이선스는 AudioProduction에 보존한다.

기본 샌드박스의 다운로드 소켓이 차단돼 승인된 네트워크 권한으로 공식 ZIP을 취득했다. Python soundfile은 설치돼 있지 않아 변환/추가설치 없이 원본Ogg를 채팅에서 재생하도록 제시한다. Unity Assets/씬/저장음량/BGM/병행작업은 변경하지 않았다. 새Unity조회/Play/검사 없음.
