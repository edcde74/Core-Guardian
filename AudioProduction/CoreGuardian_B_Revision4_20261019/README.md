## 음량·청취 방식

선택한 짧은 모노 실버를 스테레오 비교본에서 양쪽 같은 PCM으로 들려준다. 그 기준을 반복 측정한 LUFS에 새6개를 맞추고 피크 여유를 남겼다. 스테레오 복제 시 측정 채널 에너지가 달라지는 점을 반영했으며 원본 실버 파일은 처리하지 않았다. production.json의 reference_target_lufs/후보별 측정값 참고. 음량 일치는 지각상 완전히 같은 크기나 특별함을 증명하지 않는다.

상단 효과음 세트는 소리 사이0.7초 간격이다. BGM 예시는 선택BGM2차③을 -9dB로 더한 청취용 합성으로 원본은 보존했다. 실제 게임 믹스/덕킹/증강 공개 타이밍 구현이나 승인으로 취급하지 않는다. 페이지 음량은 게임 저장음량과 별도다.
