## 반영한 설계

철거는 장치 몸통이 풀리고 회수되는 소리, Esc 취소는 짧고 작은 해제로 구분했다. UI3종은 앞의 음정/유리/벨 레이어를 없애고 짧은 체결과 종이 마찰만 쓴다. 일반 완료/최종승리/패배는 같은 재료와 G-B-D 정체성을 공유하는 세 세트다. 일반 완료는 짧게 정리하고, 최종승리는 긴장 뒤 풀리는 화음으로 확장하며, 패배는 하행으로 정리한다. 세트 듣기로 함께 비교한다. 최종승리는 마지막 라운드 클리어로 게임 전체 승리 종료되는 사건이다.

증강은 카드 쓸림→탁 안착과 낮은 충격을 중심으로 무게를 추가했다. 등급별3안이며 등급 자체를 택일하지 않는다. 선택 BGM3편은 전투BGM1에서 밀도를 줄인 별도 편곡이다. 20초 흐름 예시는 전투→선택음악 전환→골드 공개→전투 복귀를 담았다. 예시 시점/페이드 시간은 게임 규칙 승인이나 실제 연결이 아니다.

사용자가 롤체 증강음을 참고하라고 요청했지만 이번 제작에서 실제 롤체 음원을 직접 청취·대조하지 못했다. 카드 공개 비유를 중심으로 설계했으며 Riot 음원을 다운로드/추출/재사용하지 않았다. 롤체와 직접 비교한 결과로 표현하지 않는다.

## 멀티 발사 수

사용자가 **실제 발사 수에 맞춰 1·2·3발로 구분**을 승인했다. 선택②의 제작 재료를 바탕으로 0/85/170ms 펄스를 1·2·3개로 재구성한 비교본이다. 공통 게인을 적용해 단발마다 음량이 부풀지 않게 했다. 기존② 파일과 바이트 동일한 절단본은 아니다.

읽기 확인: Session은 최대3타깃에 타깃별 ProjectileState/발사 이벤트를 만든다. 현재 CoreGuardianCombatAudio는 포탑별35ms 중복 억제 뒤 항상 기존3연타 파일을 재생한다. 향후 연결 시 한 공격 묶음에서 실제 발사 수를 세어 해당 파일을 한 번 재생해야 하며 타깃마다 전체 파일을 재생하면 안 된다. 이번에는 설계/청취본만 제작했다. UnitAnimation/Glow는 발사 수별 연출 구현의 증거가 아니며 수정하지 않았다.
