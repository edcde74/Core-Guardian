# 포격형②의 선명도 조정 · 2026-10-18

사용자가 이전 포격형② 세 포신 연속 발사를 긍정 평가하고 ‘좀더 까랑까랑하게’, 게임 분위기에 맞추기를 요구했다. 번호 혼동을 피하려고 기존②를 기준으로 수정안 A/B만 만들었다. 최종 적용 승인 전이며 Assets 밖의 청취본이다.

- **원본②:** 기존0/85/170ms 세 포신 간격과 마력음.
- **A:** 원본 무게감을 더 남기는 방향. 기존 단일③ 마력 본체의 피치0.86/길이0.4초/발사시점 유지, Block_03의 짧은 금속성 어택을 밝히고 저역 일부를 정리한 층35%를 원본②와 혼합한다.
- **B:** 같은 리듬에서 선명한 어택을 더 드러내는 비교안. 더 열린 필터/Block_03 원본에 가까운 피치·비중의 층60% 혼합.

현재 전장의 따뜻한 고대 설비·황동 장치라는 테마를 해석한 제작 방향이다. 실제 황동/석재 녹음 출처를 주장하지 않는다. 새 실총/레이저/발진음/긴 금속 잔향을 추가하지 않았으며 이미 취득한 마력/Block 샘플만 가공했다. 에이전트의 직접 청취 승인이나 게임 내 믹스 검증은 아니다.

개별 `A_WarmClear.wav`, `B_BrighterAttack.wav`. 연속 `Reference_A_B.wav`는 **원본② 두 번 → A 두 번 → B 두 번**이며 긴 쉼으로 구분한다.
